# Roadmap — VOYNICH: The Living Manuscript

## Phase 0 — Project Bootstrap

Goal: 建立可持續開發的 Roblox 子專案。

Deliverables:
- `roblox-game/` isolation boundary
- GDD / world / gameplay / architecture docs
- Rojo project skeleton
- lint / formatting config
- content ID conventions
- save schema v1

Exit criteria:
- Roblox Studio 可透過 repo 同步專案
- 開發者能在不碰 `ip-bible/` 的情況下完成 Roblox 工作

## Phase 1 — Chapter 1: The Root

Goal: 驗證核心 loop。

Scope:
- Opening Archive
- Falling sequence
- Rosette Hub v1
- Herbal Wilds v1
- 10 plants
- Scanner
- Codex
- 3 puzzle families
- Root Chamber
- Astral teaser
- persistence

Exit criteria: 30–45 分鐘完整 playable vertical slice。

## Phase 2 — Social Research

Goal: 驗證合作研究是否比單人收集更有趣。

Scope:
- Research Party 1–4 players
- asymmetric observation
- party evidence sharing
- basic hypothesis board
- party chamber matchmaking

Exit criteria:
- 至少一個 puzzle 無法靠單人資訊直接完整解出
- 玩家有自然交換 observation 的需求

## Phase 3 — Astral Realm

Goal: 建立第二套完全不同的 gameplay language。

Scope:
- giant ring mechanisms
- sun / moon / zodiac / stars roles
- multi-user synchronization
- star Codex entries
- first cross-region evidence links

## Phase 4 — Study & Long-Term Retention

Goal: 建立重度玩家長期研究空間。

Scope:
- Study Room
- specimen display
- glyph board
- advanced hypothesis system
- personal research history

## Phase 5 — Green Baths + Apothecary

Goal: 擴大玩法多樣性。

Green Baths:
- fluid routing
- valve timing
- pressure / level

Apothecary:
- experiment combinations
- reaction logging
- community recipe evidence

## Phase 6 — Star Archive

Goal: 建立 endgame research loop。

Scope:
- glyph pattern tools
- co-occurrence analysis visualization
- community hypothesis sharing
- evidence support/conflict graph

注意：仍不提供 canonical translation answer。

## Phase 7 — Nine Rosettes Finale

Goal: 完成第一季主要世界弧線。

Scope:
- nine Rosette activation
- world-level connection puzzle
- final glyph reveal
- Season 2 hook

## Phase 8 — Live Operations

Goal: 建立可持續內容更新。

Scope:
- Lost Folio events
- temporary chambers
- seasonal cosmetic research sets
- server/global contribution
- new specimens / fragments

## Phase 9 — Commercialization

只有在核心留存成立後才擴大。

Allowed monetization focus:
- cosmetics
- Study Room
- Codex appearance
- private experiences
- non-competitive supporter pass

禁止把知識答案、Evidence 或研究優勢直接商品化。

## Metrics to Watch

MVP：
- first discovery completion rate
- 3-minute retention
- Chapter 1 completion rate
- average Codex opens / session
- puzzle retry rate
- party completion rate

Long-term：
- D1 / D7 retention
- discoveries per returning player
- Study Room engagement
- hypothesis creation rate
- co-op session ratio
- live-event return rate
