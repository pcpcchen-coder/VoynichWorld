# World & Lore — VOYNICH: The Living Manuscript

## 1. Core Fiction

遊戲中的核心假設不是「伏尼契手稿已被解讀」，而是：

> 手稿不是用來閱讀的，而是一個進入另一個世界的介面。

這是 Roblox adaptation 專用設定，只存在於 `roblox-game/`，不回寫既有 IP Bible。

## 2. Rosette as World Map

遊戲把九圓盤 / Rosette foldout 解讀為世界拓撲圖。

中央 Rosette 是玩家 Hub；周邊圓盤逐步亮起，代表不同研究領域與世界入口。

初期玩家只看見中央 Rosette，其餘區域被黑墨封鎖。

```text
?     ?     ?

   ?  ◎  ?

?     ?     ?
```

隨進度逐步變為：

```text
●  ●  ●
●  ●  ●
●  ●  ●
```

最終九個圓盤排列本身形成一個巨大 glyph，作為第一季終局伏筆。

## 3. Major Regions

### 3.1 Herbal Wilds

視覺：巨大植物、非自然根系、半透明葉脈、漂浮種子、墨線地形。

玩法：
- 掃描植物
- 找 leaf / root / flower / fruit
- 日夜觀察
- 採集 specimen
- 比對 glyph
- 建立 Codex entry

玩家不知道植物用途，只能提出 medicine / food / ritual / poison / unknown 等假說。

### 3.2 Astral Realm

視覺：無地面星空、巨大同心圓、月相、黃道、漂浮星盤。

玩法：
- Rotate Rings
- 調整 Sun / Moon / Zodiac / Stars
- 重建特定手稿星盤
- 2–4 人同步操作

成功後天幕裂開，開啟下一層星門。

### 3.3 Green Baths

視覺：綠色池體、巨大管路、閥門、透明輸液管、幾何浴池。

玩法：
- Fluid Routing
- Valve Timing
- Pressure / Level Management
- 多人同步控制

錯誤不一定直接失敗，可能觸發空間翻轉、管線爆裂或隱藏通道。

### 3.4 Apothecary

視覺：巨大玻璃器皿、藥草平台、瓶罐、流動光液。

玩法：
- 組合 specimen
- 控制順序 / 比例 / 時機
- 觀察反應
- 取得新的 glyph / evidence

沒有公開 recipe list，鼓勵社群交換實驗紀錄。

### 3.5 Star Archive

視覺：黑暗無限書架、漂浮 glyph、星形條目、深空圖書館。

玩法：
- glyph co-occurrence
- pattern grouping
- semantic hypothesis
- evidence conflict review

這裡是重度研究玩家的 endgame 系統之一。

### 3.6 Rosette World

世界級 hub + endgame overworld。

每完成一個研究領域，就亮起一個 Rosette；全部開啟後進入第一季 Finale。

**VOYNICH — The Living Manuscript**

## 5. World Language

世界元素避免傳統奇幻語彙，改以手稿本體語言描述：

- Death → Page Rejection
- Checkpoint → Anchor Glyph
- Dungeon → Chamber / Folio
- Monster corruption → Ink Corruption
- Quest item → Evidence / Fragment
- Encyclopedia → Codex
- Player home → Study

## 6. Environmental Storytelling

世界觀主要用環境敘事，不用大量 NPC 對話。

線索來源：
- 植物形態
- 管路方向
- 星盤排列
- glyph 位置
- 頁面破損
- 墨水流動
- 重複圖案
- Rosette 連線

## 7. Canon Boundary

Roblox lore 分成三層：

1. **Historical Reference** — 可追溯到真實手稿的元素
2. **Game Interpretation** — Roblox 為玩法所做的解讀
3. **Mystery Layer** — 故意不定義答案的部分

每份未來 lore 文件應標示層級，避免 Roblox adaptation 被誤認為既有 IP 的正式設定。
