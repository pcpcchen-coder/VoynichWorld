| 檔案 | 說明 |
|---|---|
| `index.html` | 可搜尋 HTML 逐頁導讀（單檔、離線可用） |
| `pages.json` | 逐頁分類資料（`scan_page` / `section` / `description` / `confidence` / `image`） |
| `assets/pages/` | 209 頁掃描衍生圖 `page-001.jpg` … `page-209.jpg` |

`pages.json` 與根目錄 `../data/voynich_pages_classification.json` 為同一份資料，
供程式再利用；`index.html` 已內嵌所需資料，離線雙擊即可開啟，不需載入 JSON。
修改分類時請同步更新這三處。
