# 序章〈味變〉實作筆記：與劇本的出入

劇本：`docs/script/ch00-prologue.md`；資料：`js/data/*.js`；引擎擴充見 `docs/ENGINE.md` §19。
以下逐條列出「劇本位置 → 實際做法 → 原因」。沒有列出的部分都照劇本逐字實作。

## 資料與 id

- **葉帖 id（§11、§14.5）**：劇本 `folio.f004` 等 → 引擎 id 用 `F-004`／`F-005`／`F-006`／`F-007`／`F-161`／`F-174`；條件鍵沿用劇本旗標 `folio.f004.c1`～`folio.f174.c3`。→ 引擎的葉帖選單以 id 排序並顯示 id，劇本自己也並列「F-004（folio.f004）」。
- **手技 id（§4.1）**：劇本沒有指定 → `skill.double_read`、`skill.steady_palm`、`skill.backwash`、`skill.triple_read`、`skill.desilt`（清淤）。
- **配方、商店 id（§10.2、§10.4）**：劇本沒有指定 → `rcp.p0.*`、`shop.p0.suo`。
- **輔助旗標**：劇本沒有、但實作需要的旗標一律用 `flag.prologue.` 前綴，例如 `talked_xibo／talked_sha／talked_congye`（巡檢「先對話再互動設施」）、`m0_04_seen`、`m0_06_started`、`dosage_done`、`brewed_*`、`treated_*`（F-174 調劑與對症）、`rounds_done`、`m0_10_started`、`terrace_seen` 等、`heard_a_east／heard_a_south／heard_b_*`（岔口三叢分別聽過）、`k_cut`（痂膜割開）、`east_pedal`（下層東通道單向小瓣）、`boss_done`、`old_shrine_seen`、`old_altar_seen`、`filter_cut_whole`、`slowarch_sweet_hurt`（F-007 補記行）。計數器照劇本用 `stat.prologue.mistreat_count`。
- **汲蟲淤塞「三符型」（§9.2 #4）**：同一個遭遇 id `enc.p0.drawmite_clot`，上層那一隻用地圖實體的 `override` 覆寫味序（腥焦腥）與獎勵（見識 18／隔離 6）。→ 劇本只給一個 id。
- **藥材樣本（§10.1）**：五種藥材 `cat:'sample'` 並加 `material:true`，不算「未入庫的診斷樣本」（撤離不會掉、入庫不換籤）。→ 劇本區分藥材樣本與診斷樣本，引擎原本只有一種 sample。

## 地圖（§5）

- 依草圖展開成實際尺寸：池站 40×30、棚屋 30×12、階梯泉 40×32、活土原 44×30、脈橋 48×20、上層 36×28、下層 36×28（7 張，與 §5.1 尺寸一致）。地形由 `tools/gen-prologue-maps.py` 產生 `js/data/maps-tiles.js`；`node tools/print-map.js <id>` 可印出含實體的預覽。
- **池站七座棚**：草圖只畫出四座（池守棚、記脈棚、湯棚、嫁接棚）→ 另加三座不可進入的小棚湊足「七座」。
- **活土原的低鳴鐘管草（§5.5 a）**：P2 要「擋住小徑」、P1 可繞過 → 在西半與東半之間種一道鐘管草／靛藍灌叢籬，只在小徑留一格口；P2 時遭遇對象站在那一格。
- **乾裂活土（§5.4「不可踩，踩上滑回邊緣並體力 −2」、S0-4）**：每一格 `x` 放一個踩踏觸發：體力 −2、提示「殼塌了一角——滑回邊緣」、傳回邊緣。S0-4 的五格落腳點是高草圖塊。
- **硫氣孔傷害**：§5.1 圖例寫 −3（引擎預設 −4）→ `meta.ventDamage: 3`。
- **下層活瓣水位（M0-14）**：以地圖 `patches`（條件式地形覆寫）實作；按活瓣後 warp 回同一張地圖重新載入。東通道口的「單向小瓣」做成踩踏觸發（旗標 `east_pedal`），之後東池永遠淺。
- **上層淹水階梯（M0-13）**：`patches` 在 `valve_upper_open` 之前把階梯四周變深水；下層的階梯入口在活瓣沒開時鎖住（提示「上去的階梯還淹在水裡」），避免從斜坡下來的玩家被傳進深水。
- **擋路的遭遇**：鹹殼滲口（一階棧道）、低鳴鐘管草、塌陷水囊、死潮、滲硫痂口、上層汲蟲淤塞在穩定後消失（`hideOnDone`），否則會永久擋住劇本說「通行」的路；因此這幾隻穩定後不能再互動讀描述。
- **封死管段 KKKK（§5.8）**：前廳西牆唯一的缺口由一個骨白「斷面」物件擋住，首領遭遇結束（`boss_done`）後消失＝裂口。
- **橋面「灌叢」（§5.6 i，可通行）**：引擎的灌叢物件會擋路 → 橋面上只用可通行的高草圖塊表現「沒人修剪」。
- **北口貨架**：用傳送點條件 `terrace_open` 擋住，鎖住時顯示「梭的貨架半擋著北口。／蒲嬤還沒點頭。」，沒有另畫貨架。

## 系統與演出

- **葉帖自動繪製（§11）**：`meta.autoDrawFolios`：三項齊備時，地圖空閒就播放各場次的繪製台詞（`before`）→ 顯影 → 之後的台詞（`after`，例如楔姨「妳把它畫胖了」）。F-007 依旗標切換名稱（`nameAlt`）與 A／B 版筆記；F-174 筆記依 `stat.prologue.mistreat_count` 顯示 N。
- **F-174 的條件**：c1（四種藥材都持有過）在 M0-06 拿到刺緣葉時設定（其他三種已在 M0-03 給過）；c2＝M0-07 四味各調過；c3＝四種藥各對症用過（處置藥的 `treatFlag`），或 P3 時味診台的「補記」。
- **F-004 取樣**：所有鐘管草汁採集點與低鳴鐘管草的獎勵都會設 `folio.f004.c2`；M0-03 給的巡檢藥料不設（照劇本「巡檢藥料不算」）。
- **「診斷」條件**：遭遇的 `allRevealed` 事件設旗標；穩定或隔離時也直接設（`meta.battleRules.isolateAutoRead: 10`＝隔離前自動補嚐、負荷 +10）。
- **首領與中頭目失敗不卡關**：慢拱失穩或體力歸零 → 回中島舊龕、全回復、下次失衡 40、不扣樣本；撤離也回舊龕。死潮失穩 → 原地重置為 45。五嘴失穩 → 楔姨扶正，原地重置。（引擎擴充 `softFail`。）
- **五嘴的補藥（M0-06「若藥用完」）**：遭遇規則：任一種藥用完時楔姨再遞一組（台詞只播第一次，之後照樣補）。
- **T-02「第一次選處置」**：做成五嘴遭遇開始時彈出（引擎的遭遇 `tutorial`）。
- **T-05 甜**：在乾癟池糖囊第一次讀出甜時彈出（`events.revealGlyph`）。T-11 用 `meta.battleRules.noisyTutorial`。T-09 掛在等級 2。
- **M0-05 巡檢**：劇本是「先與 NPC 對話，再互動設施」→ 對話設 `talked_*`，互動設施才算巡檢完成；沒對話前設施只顯示描述。三處完成時的旁白在第三處巡檢結束後播放，接著升級畫面與 T-09。
- **M0-07 劑量三選一**：味診台第一次（持有刺緣葉時）進入劑量選擇，「中」「濃」回到選項不消耗樣本；選「淡」後五種配方才出現在清單上（`hidden: dosage_done`）。
- **M0-10**：從北口回站時由 onEnter 播放；過場把珂潾移到人群邊，結束時直接開始汲蟲淤塞遭遇（「教學關閉後自動」）。撤離的話可以再走近 d。
- **M0-15**：走進前廳入口觸發過場並直接開始遭遇；撤離或失敗後走近慢拱再按確認即可重來。
- **M0-17**：池守棚房間的入口一列放觸發，進門往裡走就開始坦白（劇本「進入池守棚」）；也可以直接與蒲嬤對話。
- **S0-4 帶礫回程**：沒有做「礫跟在後一格」的跟隨，與礫對話後淡出、兩人回到小徑邊再接回程台詞。
- **S0-2 的「三口／兩口水」**：依本場是否誤治（引擎旗標 `last_mistreats`）選台詞。濾幕割過後中幅換成補丁外觀、池況湯只回一半體力並多一行文字，紗與蓴嬸的台詞切換版本。
- **蓴嬸的池況湯**：選項文字照劇本；回復用 `['heal','100%',0]`／`'50%'`（引擎擴充百分比）。
- **梭的存量（§10.4）**：商店項目 `qty`；縫苦第一次換入時跳出梭那句話。處置藥上限 9（`meta.medCap`）。
- **入庫換籤（T-07）**：`meta.bankReward`。採集點在種源龕或床休息後重生（`meta.gatherRespawn`），淨水點不限次數。
- **首次問候演出（§8.6「露出手腕、手背輕觸」）**：只在 M0-03、M0-05 紗的劇本台詞中照寫；沒有替每位居民另做一次問候演出。
- **支線在 P3 自動關閉（§8 開頭）**：沒有做「沒來得及」的關閉狀態；P3 起不再出現接取選項，已接的仍可回報。
- **章末（§13）**：13.1 旁白以黑底三頁播放，接著章末畫面：標題「霧階，這個長晨」、13.2 條件清單（`〔若 條件〕` 行）、四向度只顯示傾向文字（`hideDims`）、13.3 預告放在「待續」之後。連通度行只顯示數值與「進場 62」，沒有算增減。
- **全幅圖片**：M0-01 的「珂潾在初泉環診斷」沒有專屬圖檔，用 `assets/title.jpg`；奧芮殘葉沒有圖，以骨紙色底的旁白頁逐段顯示全文。
- **〔過場：…〕演出**：鏡頭、移動、淡入淡出、震動照做；音效描述（例如「低鳴甲／乙／丙」）用引擎既有音效近似；看得到的動作改成〔旁白〕頁。
- **補寫的短文字（劇本沒有給、但互動需要）**：站口告示板「站口告示板：潮汐曆摘抄與配給公告。」、池守棚潮汐曆、蒲嬤舊藥匣上鎖、上層活瓣按不動／已開、活瓣闔回、採集點的一行描述、乾裂提示、單向小瓣提示、味診台「補記」。都只用劇本已有的描述改寫，不新增劇情。
- **記脈棚繪圖桌（§5.3「互動可翻看已完成的葉帖」）**：沒有做成互動物件；已完成的葉帖在選單「葉帖」翻看。

## 難度

- 數值照 §4、§9。首領在等級 5、照「先嚐再治」打法可一次通過；即使失敗也只是回舊龕重來，不會結束遊戲。
- 主線不會卡死：首領、死潮、五嘴的失敗都會重置；中頭目選隔離時改走東支空管（割開痂膜）；活瓣任何狀態都能回到中島舊龕；所有必經的擋路對象穩定或隔離後都會讓路。
