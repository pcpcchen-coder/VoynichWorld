## 怎麼讀

- **先讀總綱**，尤其是 §2 核心系統、§4 章節總表、§5 線索鏈與旗標。
- 每個章節檔的結構相同：章首資訊 → 主題與環境母題 → 地圖與區域表 → 主線場次 → 支線 → 遭遇圖鑑 → 葉帖清單 → 章末狀態與時數核對表。
- 場次編號：`M3-07` 是第 3 章主線第 7 場，`S3-02` 是支線，`SF1-04` 是勢力中篇第一部。
- 關鍵場次寫出逐句對白，其餘場次是對白重點加摘要。各章末的時數核對表把每一場的分鐘數加總到該章預算。
- 後面的章節以「若 F3＝切除：……」這類條件對白回應前面章節的抉擇。

## 對白慣例

```
珂潾：先是鹹。等一下——苦在後面。不是這池，是上游。
燼：退。封口。記座標。再爭。
漣〔訊號：鹹—停頓—青光兩短一長—水壓向東〕（珂潾譯：上游……不，是「以前的」上游。）
穹母〔眾聲〕：我們不會要妳留下。我們只是讓妳知道，門沒有鎖。
```

- 漣不說人話，訊號由珂潾翻譯，而且她可能翻錯。
- 奧芮與燼的性別不指定，對白不用「他／她」。
- 沒有擊殺；遭遇的結束方式是穩定、隔離、驅離或撤離。

## 葉帖與手稿頁

全作 206 張葉帖，一一對應 `data/voynich_pages_classification.json` 的 206 個內容頁（`F-004` 即掃描頁 4）。
各章只使用總綱配給自己的頁碼，全部 206 頁都已分配且沒有重複。葉帖名稱與筆記是遊戲虛構，不描述「這一頁手稿真正畫的是什麼」。
真實手稿佚失的第 109–110 葉，在遊戲裡是永不揭曉的一張，不計入 206。
