## 2. 本章主題與一句話

**一句話**：珂潾第一次親手落下一道隔離線，才發現線不是一個按鈕——線的每一側都寫著名字，而她必須在自己讀不到的地方，把讀值交給別人。

**主題**：
1. **切除的重量**：隔離線不是壞人的工具。它是一份名冊，落線的人要自己把兩欄都念完。
2. **承受不是美德**：珂潾在信念崩解後，用「至少我還感覺得到」撐著自己。硫裂環的水會教她：感覺到一切的人，一樣會把同伴帶進毒裡。
3. **切除之後**：燼的灰袋是一種紀錄。燼要學的不是「不燒」，是燒完之後誰留下來照料。
4. **不讓任何一方單方面正確**：鉚的數字是對的；老葒不走也是對的；燼等過一次，等錯了；珂潾這次要燼再等一次。

### 環境母題

| 母題 | 表現 |
|---|---|
| **光** | 歐柯的橙光照在骨白乾區上會刺眼；青色只剩池底一線。病紅只出現在熱冠與獸體脈路，面積很小。防火帶是一條細而安靜的黑，**不冒煙**。 |
| **聲** | 這一環幾乎沒有聲音。沒有鐘管草互答，沒有汲蟲的沙聲。全環最後一叢還在低鳴的鐘管草在留燈聚落；它會在本章停下來。**最恐怖的不是爆炸，是聲音停了。** |
| **味** | 臭蛋味是基調。但真正的警訊是「味道停了」——濃到一定程度，鼻子與舌頭會先死。鹹（銅鏽）永遠先到；甜極稀少，嚐到甜要先懷疑自己。 |
| **觸** | 鹽霜、乾霧讓皮膚發緊；脆活土踩下去沒有回彈，只有一聲很輕的碎。 |

## 3. 新系統

### 3.1 毒氣與風向

- 探索地圖每格有 **味階** 0–4：

| 味階 | 感受 | 可停留回合 | 效果 |
|---:|---|---:|---|
| 0 | 無味 | 不限 | — |
| 1 | 淡臭 | 不限 | 感官負荷每 5 回合 +1 |
| 2 | 臭蛋味明顯 | 6 | 這段脈快死了；嚐味負荷 ×1.5 |
| 3 | 濃臭、眼睛刺 | 3 | 體力每回合 −2；讀值首位易被「鹹」覆蓋 |
| 4 | **啞**（聞不到了） | 1 | 體力每回合 −8；嚐味一律回報「無味」；只有試片與燼的讀風可信 |

- **風向**每 4–8 回合轉一次，把高味階的氣團推向下風格；氣比空氣重，會積在低處與坑口。站上風、走稜線、低處不停。
- **試片**（銅綠試片）：道具，遇硫變黑，速度代表濃度。它比珂潾的舌頭慢，但不會麻痺。
- **燼的同伴指令〔讀風〕**：預告接下來兩次風向變動；〔張膜〕在一格立臨時隔離膜，擋一次氣團。

### 3.2 隔離線搭建

五個工序，全部由玩家操作：**判線 → 釘索 → 張膜 → 灌灰 → 落封套**。

- **判線**：在格圖上以有限節數的隔離索連出一道線。節點必須落在還有回彈的活土上；所有味階 ≥3 的格子必須留在棄側。線越短越穩、越省灰，但會把更多還活著的東西劃到棄側。
- **名冊**：畫線的同時，畫面兩欄即時更新——**保**與**棄**。每一項都是當地人取的名字：池、老株、巢、獸徑、種源龕、住戶。名字不會因為被劃到棄側而消失，只會變成灰字。
- **落封套**不可逆，必須確認兩次。確認之間，名冊的棄欄會自動捲動一遍。玩家可以跳過，也可以讓珂潾逐一念出來（念完 `燼信` +1、錄 +1）。

### 3.3 活土內部搶修

多階段事件（M8-23～M8-27）：崩塌讓地表成為剖面。珂潾在水線以上解導管纏結，漣在水線以下導壓。**畫面上下分割**：上半是珂潾可讀的味序，下半是漣的訊號——珂潾只能翻譯，不能自己嚐。

### 3.4 「封感」指令

- 遭遇與探索中新增指令〔封感〕：珂潾封上掌套、含住遮味片，**主動關閉嚐味** 2–4 回合。
- 封感期間：感官負荷不再上升並每回合 −6；味階 3–4 的失真與「啞」對她無效；她**不能嚐味**。讀值改由同伴提供——漣回報水下味符（以訊號呈現，玩家依詞彙表判讀），燼回報風與「不可逆判定」。
- `封感＝生`：同伴讀值有一回合延遲。`封感＝熟`：無延遲，並解鎖〔交讀〕（指定本回合由漣或燼代為決定處置順序）。
- 設計意圖：玩家習慣了「自己讀最準」。這個指令要求玩家在最危險的格子裡，放棄自己最強的能力。

#### M8-01 ★ 鹽霜

- **地點／時段與潮汐**：斷霧坡，下行脈橋末段。長晨；稜月殘、珂月未升，低潮。
- **出場**：珂潾、漣。
- **目的**：章首。建立硫裂環的可感狀態、珂潾崩解後的狀態、第一口臭蛋味。
- **環境狀態**：霧在這裡有一條邊。一步之前，橋面是濕的；一步之後，皮膚發緊。橋面覆著一層白，不是水霜，是鹽。沒有鐘管草的聲音。很遠的骨白地面上有一條很細的黑線，不冒煙。

（黑畫面。筆記體字幕，珂潾的聲音。）

```
珂潾（筆記）：離開靛丘第十一天。沒有新葉帖。
珂潾（筆記）：不是沒有東西可以畫。是每畫一張，我都會想：這張離開這裡之後，還活多久。
珂潾（筆記）：種源庫第四列，四十匣裡死了二十九匣。我記得匣號。我本來以為記得就夠了。
```

（畫面亮起。脈橋。珂潾蹲下，用指腹抹了橋面的白，放到舌下。）

```
珂潾：鹹。
珂潾：……只有鹹。後面沒有東西。
珂潾：以前鹹的後面會有苦，苦後面有焦。那是一句話。這個不是話。這是有人說到一半，走了。
漣〔訊號：水壓貼地—短促兩次—內光收暗〕（珂潾譯：牠不下去。……不對，不是「不下去」。是「這裡沒有可以下去的東西」。）
珂潾：橋腹的殘水呢？昨天還有一線。
漣〔訊號：鹹—鹹—鹹—青光不亮〕（珂潾譯：三個鹹。牠通常只給我一個。我想牠的意思是：不要問第二次。）
```

（珂潾解下背上的淨水囊，替漣的水膜補水。淨水囊已經扁了一半。）

```
珂潾：靛丘的水剩半囊。到站之前，妳一半，我一半。
漣〔訊號：甜—極短—推回〕（珂潾譯：牠把我的那一半推回來了。……好。妳的皮比我的喉嚨急。）
```

（風從谷底上來。第一次出現味階提示：**味階 1**。）

```
珂潾：——聞到了。
珂潾：很淡。像蛋放太久。蒲嬤以前說，聞到這個就把小孩叫回屋裡。
珂潾：先報現象。風從東南下方來。味道隨風，不隨水。橋面無回彈。鹽霜厚度……一個指節的三分之一。
珂潾：好了。我報完了。
（停頓。）
珂潾：我報完了，可是我不知道要報給誰。
```

（漣把一隻蹼指按在她的腕內側——潾者少見的主動觸碰。）

```
漣〔訊號：水壓輕—一長—青光一點〕（珂潾譯：「這裡。」……牠是說牠在這裡，還是說報給牠？我分不出來。我決定兩個都算。）
```

（遠景：骨白地面上那條黑線旁，有一個很小的人影蹲下，在地上放了什麼，站起來，走了。珂潾沒有認出是誰。）

```
珂潾：黑的那條是防火帶。比我想的窄。也比我想的安靜。
珂潾：我以為這裡會一直在燒。
```

#### M8-02 ★ 灰口站檢疫門

- **地點／時段與潮汐**：灰口站外門。長晨轉午；低潮。
- **出場**：珂潾、漣、鉚、測線兵釺、池守礫。
- **目的**：鉚登場；F5 餘波第一回；建立「檢疫對潾者同樣適用」的不舒服事實。
- **環境狀態**：門不是門，是三道垂掛的孢子濾幕，中間夾著兩個洗掌槽。槽裡的水泛灰——灰水，不是髒水。門邊立著水位尺，最上面三道刻痕是乾的。

```
釺：停。掌套打開。兩手進第一槽，數到二十。
珂潾：這是燼灰水。濃度？
釺：不知道。主官調的。
鉚：千分之四。妳的掌心會麻一刻鐘，不會傷。記脈者，妳從靛丘來。
珂潾：是。
鉚：靛丘第四列種源庫的事，傳到這裡了。四十匣死二十九。
珂潾：……消息比我走得快。
鉚：壞消息都比人快。所以我修線。
```

（鉚走近。鉚看的不是珂潾，是漣。）

```
鉚：這個潾者，披層載了多少？
珂潾：牠有名字。漣。
鉚：漣。披層載了多少？
珂潾：我不知道確切的數。牠不讓我數。
鉚：那就是很多。釺，第二槽換淨水，加寬。
鉚：聽好。潾者從一口池游到另一口池，身上什麼都帶。孢子、胚芽、休眠囊——還有產硫的那些小東西。牠們不分好壞，沾上就帶。
鉚：我這條線擋得住風，擋得住水，擋不住一個有腳的池子。所以牠過線一次，洗一次。不是我不敬。
珂潾：洗掉的不只是產硫群。牠披層最外面那層是鐘潮環的——
鉚：我知道會洗掉什麼。我也知道不洗會帶進什麼。兩邊我都算過。妳要看數字，我給妳看。
```

（珂潾還要開口。漣已經自己走進第二槽。）


#### M8-03 第一口硫裂的水

- **地點／時段與潮汐**：灰口站味診台。午；低潮末。
- **出場**：珂潾、漣、池守礫、硯。
- **目的**：玩法銜接（本章第一次正式嚐味）；硯登場；呈現珂潾「至少我還感覺得到」的過度承受。
- **環境狀態**：味診台上排著三只淺皿，分別取自夾帶的上、中、下三口池。台邊的沖洗液是站上自調的，帶硫泉結晶的澀。棚頂的孢子濾幕一動也不動——沒有風，也沒有孢子可濾。

**對白重點＋摘要**：礫把三皿推到她面前，照規矩建議高稀釋、一次一皿。珂潾選了低稀釋，三皿連嚐。

```
礫：低稀釋嚐三皿？站上嚐味的一天只准一皿。
珂潾：我不是站上的。
硯：（在旁邊秤灰，沒有抬頭）負荷到七成，讀值會開始長假音符。妳現在幾成？
珂潾：六成四。
硯：那妳還有一皿的餘裕，不是三皿。
珂潾：三皿是同一句話的三個字。分三天嚐，我接不起來。
硯：接不起來可以問人。
珂潾：問誰？這裡誰嚐得到第三皿後面那個甜？
硯：（終於抬頭）沒有人。所以妳更不能壞掉。
```

- **玩法**：三連嚐味。味序設計——
  - 上池：`鹹—鹹—腥—焦`（死汲蟲已開始堵）
  - 中池：`鹹—苦—澀`
  - 下池：`鹹—澀—甜`（**仍有健康糖流**——夾帶還救得回來的唯一證據）
  - 若玩家硬嚐三皿，負荷必過 70%，下池讀值會多出一個假「苦」；玩家須以沖洗液重嚐或接受硯的建議改由礫的水位紀錄交叉驗證。這是本章第一次提示：**環境證據可以代替她的舌頭**。
- **〔條件：F4b〕**
  - 使用中：珂潾在第二皿前含了一小片縫苦。硯看見了：「妳的手不抖。嚐這裡的水，手該抖。」不追問。
  - 已戒：第三皿後她乾嘔。礫遞水。硯：「戒過的人在這裡最辛苦。妳要什麼跟我說，我秤得很準。」
  - 未用：第三皿後她乾嘔。灰窯工頭焠路過：「前線嚐味的都含一片。妳不含？」（伏筆，M8-15 回收）
- **抉擇與向度**：硬嚐三皿（錄 +1；負荷留到下一場）／聽硯的、分次嚐並對水位尺（播 +1；`燼信` 不變，但硯好感提升，支線 S8-01 獎勵加一成）。
- **取得**：F-100 的「採」「嚐」（排空池階的殼苔樣本在礫的皿邊）。
- **時間**：12 分

#### M8-05 臭泉廊

- **地點／時段與潮汐**：臭泉廊，一條沿裂隙排列的硫泉淺溝。午後偏晚；珂月升，小漲。
- **出場**：珂潾、燼、漣（留在廊口淨水槽）、硯、炟。
- **目的**：毒氣與風向教學；第一個環境型遭遇〈毒氣囊〉；泉唇草帶出「硫本來就在，是水不走了」。
- **環境狀態**：泉口邊緣結著硫黃色的殼。奇怪的是，泉口旁居然長著東西——一圈貼地的厚唇狀葉，深靛、發亮，是整條廊唯一濕潤的活物。低處的坑口上方，空氣看起來微微發皺。

**對白重點＋摘要**：燼發給每人三張試片，示範讀風——抓一撮骨白乾土，鬆手，看落點。

```
燼：三條規矩。上風站。稜線走。低處不停。
炟：低處為什麼不能停？
燼：氣比妳重。它往下坐。
炟：坐多久？
燼：坐到風來趕它。風不來，它就一直坐著等妳。
珂潾：（蹲在泉唇草旁）這個是活的。在泉口邊。它在吃硫。
硯：泉唇。這一環本來到處都是。它跟泉口的小東西合夥，把硫吃成糖。
珂潾：所以硫不是毒。
燼：這裡的硫一直在。以前水走得快，硫來不及坐下。現在水不走了。
珂潾：……不是多了什麼。是慢了。
燼：對。慢了。慢比毒難切。
```

- **玩法**：
  - **風向教學**：6×5 格的廊道，須在 12 回合內由廊口走到廊尾取樣，途中風向變兩次。低窪兩格為味階 3，其餘 1–2。
  - **遭遇〈毒氣囊〉**（環境型，見圖鑑 E-01）：坑口上方的氣團。不是生物，沒有味序；以「位置」解——上風處〔張膜〕擋一次，或等風轉把它推開。教學重點：**有些東西不能治，只能不站在它下風**。
  - 泉唇草完整四步（看、採、嚐＝`甜—鹹—甜`、畫）→ **F-103**。這是珂潾離開靛丘後畫的第一張葉帖。
- **小事件**：珂潾畫完泉唇草，盯著紙看了很久。

```
硯：十一天沒畫的人，第一張通常畫不好。
珂潾：妳怎麼知道十一天？
硯：妳的顏料盒，靛那格乾出一圈裂。我秤東西的，會看乾了多久。
珂潾：……畫得不好。
硯：留著。不好的那張以後最有用。它記得妳手抖的那天。
```

- **抉擇與向度**：無。
- **時間**：15 分

#### M8-06 ★ 味道停了

- **地點／時段與潮汐**：啞帶——臭泉廊盡頭一處下陷的舊池床。藍昏前；珂月高，潮平。
- **出場**：珂潾、燼、炟、硯（後方）。
- **目的**：味階 4「啞」的體驗；燼的受損感官第一次被正面說出；**燼正式同行**。
- **環境狀態**：一路的臭蛋味，在這裡突然乾淨了。空氣清得像健康池邊的清季早晨。池床裡躺著三隻翼膜攤開的霧篩鰩，沒有傷，像睡著。沒有任何聲音。

```
珂潾：（深吸一口氣）……散了。
珂潾：味道沒了。這裡是乾淨的。風把它帶走了——
燼：站住。
珂潾：我嚐得出來，零，什麼都沒有，連鹹都——
燼：站住。看妳的試片。
```

（珂潾低頭。胸前的試片全黑。）

```
珂潾：……黑的。
燼：多久黑的。
珂潾：我不知道。我沒看。我在聞。
燼：退。五步。上坡。現在。
```

（三人退上坡。味階計由 4 跳回 3——臭蛋味猛然「回來」，比先前更濃。珂潾彎腰咳。）

```
珂潾：回來了——味道回來了——比剛才濃——
燼：不是回來。它一直在。剛才是妳的鼻子先死。
珂潾：鼻子……
燼：濃到一個程度，聞不到。舌頭也是。這裡叫啞帶。那三隻鰩，也覺得這裡乾淨。
（珂潾看著池床裡的三隻霧篩鰩。）
珂潾：我剛才要走進去。
燼：對。
珂潾：我說「乾淨」。我說得很確定。
燼：對。妳確定的時候最像真的。所以危險。
```

（炟的試片掉在地上。炟去撿，手在抖。）

```
炟：隊長……那個，聞不到的時候，要怎麼知道？
燼：看試片。看同伴的試片。看地上有沒有躺著的東西。看聲音。
炟：聲音怎麼看？
燼：沒有聲音的地方，不要進去。
```

（燼轉向珂潾。很短的停頓。燼碰了一下自己臉側的疤——疤沿著脈紋斷掉的地方。）

```
燼：我每天都是這樣。
珂潾：什麼？
燼：聞不到。這一側，從這裡到掌心。濃的淡的，一樣。
燼：所以我用試片。用土。用硯的秤。用別人的鼻子。
燼：妳今天啞了二十息。我啞了很多年。活得下來。有方法。
珂潾：……妳從來沒說過。
燼：妳從來沒啞過。說了妳聽不懂。
```

（珂潾用沖洗液沖掌心，沖了三次。第三次她停下來。）

```
珂潾：我的舌頭是我唯一還信的東西。靛丘之後。
燼：我知道。
珂潾：剛才它跟我說乾淨。
燼：所以從現在起，妳不准一個人讀完。
燼：妳讀水。我讀風。漣讀下面。三個裡面兩個說退，就退。
珂潾：如果兩個說退的是妳跟漣，我說還能救呢？
燼：那就退。退了再吵。
珂潾：如果說退的是我跟漣，妳說要燒呢？
（停頓。）
燼：……那也退。
燼：規矩兩邊都算。不然不叫規矩。
```

> **系統提示：燼正式加入隊伍。** 同伴指令解鎖：〔讀風〕〔張膜〕〔不可逆判定〕。
> 〔不可逆判定〕：燼判斷目前對象／管段是否已過回復點。判定為「已過」時，穩定的成功率歸零，玩家只能隔離、驅離或撤離。**燼的判定有 10% 機率偏向「已過」**（燼的錯誤信念：把不確定視為最壞情況）；`燼信` ≥8 時此偏差消失。

- **玩法**：短暫的「啞」體驗——味階計顯示 0、嚐味回報「無味」、但體力持續下降；玩家須自行注意試片圖示。
- **取得**：硫泉結晶（沖洗液加強配方）→ **F-191**。

#### M8-10 空背撞線（中頭目一）

- **地點／時段與潮汐**：第三線工區北段，一條舊獸徑。午後；乾霧濃。
- **出場**：珂潾、燼、漣、炟；背園照料者芡（支線 S8-05 委託人）。
- **目的**：線截斷的不只是毒，還有路。中頭目〈空背〉。
- **環境狀態**：先聽見的是胸腔低聲——拱背獸的聲音，但只有一個音，沒有群體回答。牠從乾霧裡走出來，背拱還在，背園沒有了：拱架之間是曬白的殘根。牠沿著舊徑走，走到索前，沒有停。

**對白重點＋摘要**：

```

珂潾：牠在走舊遷徙徑。徑被我的線切了。
```

  - **驅離**：快，但牠會折回病核方向。芡不說話。
- **不可擊殺**：燼明講「牠倒在線上，屍體會餵硫，線就廢了」。
- **抉擇與向度**：穩定（播 +1、`燼信` +1）／引導（播 +1、連通度 +2）／驅離（焚 +1、連通度 −2）。

#### M8-14 腥廊

- **地點／時段與潮汐**：窄線保側下方的導管廊。午；無風（地下）。
- **出場**：珂潾、燼、漣、炟。
- **目的**：線立起來了，夾帶上池的水位仍在掉——硫不是從面上來的。追到源頭：一條更深的管。
- **環境狀態**：管壁上本該有流動的青色亮點。現在亮點都停在彎道，堆成一層灰白的泥。腥味重到像含著一口舊池水。廊底傳來刮擦聲——有東西在啃。

**對白重點＋摘要**：

```
珂潾：汲蟲。都在彎道。牠們死的時候還排著隊。
燼：方向？
珂潾：頭全部朝下游。……牠們不是被毒追上的。是水先停了，牠們還在等水。
漣〔訊號：水壓向下—很深—鹹—一長拖尾—青光指西北〕（珂潾譯：下面還有一條。比這條老。水往那邊被「喝」走……我想是「喝」。牠用的是池子乾掉時的那個訊號。）
燼：線下面有管。
珂潾：線下面有管。我們架的線，擋的是面上的。
```

```
硯：舔泉獸。站上養的。牠的差事是把龕水槽的礦殼舔開，水才流得進龕。
```

#### M8-22 ★ 燼開口（燼的過去·三）

#### M8-23 ★ 塌陷

- **出場**：珂潾、燼、漣、硯、炟、老葒、穗、礫。

```
燼：退！稜線！數人！

珂潾：漣的橇——在我這裡。

燼：坑底味階？
珂潾：試片……三。邊上三，底下我不知道。

燼：珂潾。上面妳的。下面不是妳的。
```

#### M8-24 下降與讀剖面

- **地點／時段與潮汐**：塌腹坑壁。長晨；風由燼在坑緣報讀。
- **出場**：珂潾（繫繩下降）、燼（坑緣持繩）、漣（由坑底積水入）、炟、硯。
- **目的**：搶修階段一。把「土壤即器官」做成可讀的關卡。
- **環境狀態**：坑壁貼近看是一層一層的：最上是乾裂的殼，往下是還濕的海綿層，再往下是管束。斷管口在滴糖液，一滴很久。幾隻還活著的汲蟲貼在管壁上，亮點很暗，但在動。

**對白重點＋摘要**：珂潾邊降邊報層位，燼每四回合報一次風。她在囊壁上找到三處接口：兩處被纏結勒住，一處在水線下。

```
珂潾：第一層，殼，死的。第二層，海綿，還有回彈，慢。第三層——管。三束。
珂潾：汲蟲。活的。牠們頭朝囊。牠們在等水。
燼：風，西。坑口有氣在坐。六回合後我張膜，那一回合妳不要抬頭。
```

- **玩法**：垂直探索（坑壁 4 層 × 5 格）。每層讀一次味序以定位三束管的身分：
  - 甲束（糖）：`甜—澀`　乙束（水）：`澀—焦—澀`　丙束（訊號）：`苦—苦—鹹`
  - 活的汲蟲群是方向標：頭朝向＝該通的方向。
- **取得**：儲水囊剖面完整四步 → **F-107**。
- **時間**：12 分

#### M8-25 ★ 纏結

- **地點／時段與潮汐**：塌腹坑腰，水線上方。午；燼報風。
- **出場**：珂潾、漣（水線下）、燼（坑緣）。
- **目的**：搶修階段二。跨介質合作——珂潾必須把自己讀不到的部分交給漣。
- **環境狀態**：水線是一條很清楚的界。上面，她的手在三束管之間；下面，漣的光在濁水裡時隱時現。兩個人隔著一層水面，誰也嚐不到對方那一半。

> **畫面**：上下分割。上半＝珂潾的味序與三束管；下半＝漣的訊號列。

```
珂潾：乙束壓在甲束上面。我先鬆乙——
漣〔訊號：水壓急推—兩次—青光橫掃〕（珂潾譯：不。不是那條。牠在下面看到的順序跟我不一樣。）
珂潾：從上面看是乙壓甲。
漣〔訊號：鹹—焦—水壓向上頂—停〕（珂潾譯：下面是反的。甲在下面繞了乙一圈。我鬆乙，甲會勒得更緊，勒斷。……我想是這個意思。）
珂潾：我想確認。我伸手下去摸一次——
燼：（坑緣）不准。水下味階四。妳伸手就是嚐。
珂潾：我只要一息。
燼：妳上次的一息，是漣的兩層皮。
（停頓。珂潾的手停在水面上方一指。）
珂潾：……漣。妳說。我照做。
漣〔訊號：青光一短—水壓輕托—甜（極淡）〕（珂潾譯：牠回了一個甜。很淡。在這種水裡牠還擠得出一個甜給我。）
珂潾：好。妳說第一條。
漣〔訊號：水壓向東—一長—停〕（珂潾譯：丙。先丙。訊號那條。）
珂潾：丙是訊號管，不是水。先鬆它沒有用——
（她停住。吸氣。）
珂潾：先丙。
```

（她鬆開丙束。水下，漣同時在另一端托住。丙束一鬆，另外兩束自己彈開半圈——丙束是結心。）

```
珂潾：……它是結心。從上面看不出來。
燼：下一條。
珂潾：漣，下一條。
```

- **玩法**：**雙讀解結**。六步解結；每一步，上半畫面給玩家一個「看起來合理」的順序，下半漣的訊號給真正的順序，兩者有三步相左。玩家每一步選〔照自己的讀〕或〔照漣的〕。
  - 照漣的 6/6：囊壁無損，M8-27 灌注量 100%。
  - 自讀一步錯：一束管受損，須以靛乳疏通（多耗 2 回合、灌注量 −15%）。
  - 另有一步是**漣錯了**（第五步：漣的訊號把「舊水路」當成現在的——翻譯不確定性）。此步燼會在坑緣報「上游壓沒到，等一息」，玩家若同時參考燼，可避開。設計意圖：**不是「漣永遠對」，是「三個讀在一起才對」。**
- **取得**：纏結導管束完整四步 → **F-108**。
- **抉擇與向度**：全程照同伴的讀（播 +1、`燼信` +1）。
- **時間**：15 分

#### M8-26 ★ 喘囊（中頭目三）

- **地點／時段與潮汐**：塌腹坑底，儲水囊前。午後；坑口有氣團。
- **出場**：珂潾、漣、燼（降至坑腰）、炟（坑緣持繩）。

```
珂潾：它在痙攣。它想自己灌回去，可是它吸的是坑底的水——
燼：味階四。到了。
珂潾：我還能嚐一次，我——
燼：珂潾。
（她看了一眼手腕上的試片。全黑。）
珂潾：……封感。

珂潾：我關了。我在。妳們說。
燼：風，下一次吐之後有兩息的空。那兩息，處置。
漣〔訊號：澀—澀—苦—水壓收縮—停〕（珂潾譯：澀、澀、苦。牠說囊「渴到發瘋」。）
珂潾：池糖液，兩次。然後縫苦——
（她停了一下。）
珂潾：硯！縫苦，微量，妳秤，妳丟下來。我不碰。
硯：（坑緣）半片的四分之一。下去了。
```

- **遭遇〈喘囊〉**（E-11，海綿型儲水共生體痙攣）：味序 `澀—澀—苦—焦—澀—鹹`；特殊行為「吐」——每兩回合味階 +1（上限 4），味階 4 時珂潾自嚐一律回報「無味」，**只有封感下由漣報讀才可繼續**。「吸」的回合若漣在囊口，`漣濁` +10。
  - 以〔交讀〕（`封感＝熟` 才有）可讓漣或燼直接決定本回合處置。
  - **達標條件**：封感狀態下連續 4 回合處置正確 → `封感＝熟`、**F-204** 完成。未達標仍可過關（`封感＝生`），但灌注量 −15%。
- 過關：囊停止痙攣，囊壁慢慢鬆下來，像一個終於喘過來的人。
- **抉擇與向度**：封感達標（錄 +1、`燼信` +1）。
- **時間**：15 分

#### M8-27 ★ 把水送回器官

```
珂潾：乙束通了。壓到了。漣，接口在妳那邊，我這邊對不到——
漣〔訊號：水壓平穩上推—一長—青光穩〕（珂潾譯：牠接住了。牠說……「放手」。）

漣〔訊號：水壓平穩上推—一長—青光穩〕（珂潾譯：同一句。牠不改。）
（珂潾鬆手。囊沒有偏。漣在下面托得很準。）
珂潾：……好。是妳的。
```

```
珂潾：我想記住封著的時候是什麼樣子。
```

#### M8-33 喉脈入口

**對白重點＋摘要**：


## 6. 支線任務（11 條｜210 分）

**S8-01〈半匙又一撮〉｜灰衡者的劑量工作｜20 分**
- **委託人**：硯、灰窯工頭焠。**起因**：M8-12 後。第三線每一步的灰量都要依當段土的含水重秤；焠嫌慢，主張全線灌一匙整。
- **步驟**：取五段土樣 → 嚐含水（澀的深淺）→ 在秤上配五種劑量 → 回線上驗第一排根。治療窗小遊戲：低＝擋不住、中＝藥、高＝毒死保側第一排根。
- **關鍵對白**：焠：「一匙整，省三個人半天。死一排根而已。」硯：「那一排根是線內的。妳要保的那邊，被妳自己毒死第一排，妳管這叫保？」
- **抉擇**：照硯的分段秤（錄 +1；線承壓 +1）／照焠的整匙（焚 +1；省時，M8-13 前一段根死，名冊「保」欄有一項轉灰）。
- **獎勵**：**F-190**〈燼灰劑量階〉、燼灰 ×5、見識。

**S8-02〈檢疫棚第三夜〉｜撤離與檢疫｜25 分**
- **委託人**：霧濾師栒。**起因**：從棄側撤出的十四人已在棚裡隔離三夜，孢子濾幕只夠再撐一夜；其中一家帶著一匣未驗的種源不肯交。
- **步驟**：逐人嚐掌（三人掌上帶鹹）→ 驗匣（匣內一半已硫染）→ 決定放行名單 → 修濾幕（張膜玩法變體）。
- **關鍵對白**：那家的母親：「匣裡是我們池的縫葉幼軸。交給妳們，妳們會燒。」栒：「一半已經染了。妳抱著睡了三夜，妳的掌也鹹了。」
- **抉擇**：分匣——染的燒、淨的由珂潾接蒂暫養（播 +1、錄 +1；耗淨水）／整匣燒（焚 +1；那家人不再跟任何人說話）／放行整匣（融 0、播 +1；兩天後灰口站味診台多一個鹹，連通度 −1）。
- **獎勵**：遮味片 ×3、池糖籤、見識。

**S8-03〈它還在叫〉｜留在線內不肯走的人｜25 分**
- **委託人**：老葒。**起因**：M8-13 後。老葒請珂潾替留燈叢「記音」——四百多天的音高，她只記在腦子裡。
- **步驟**：連三個時段（長晨、藍昏、深夜）陪聽並記錄音高與水位 → 發現靜潮那一刻草會停一息 → 替老葒把紀錄刻上一截舊根管。
- **關鍵對白**：老葒：「妳們記脈的總說記下來就留得住。妳現在還信嗎？」珂潾：「不信了。」老葒：「那妳還記？」珂潾：「記了，停的時候才有人知道它叫過多久。這跟留不留得住，是兩件事。」
- **抉擇**：把刻好的根管〔留在草邊〕（播 +1）／〔交給老葒帶走〕（錄 +1；`留燈` 傾向撤離）／〔由珂潾收入葉帖〕（錄 +2；老葒：「拿去。反正妳們什麼都要拿。」）。
- **獎勵**：F-138 前半資料（主線亦可得）、老葒的聽土片（裝備：腳下脆活土預警 +1 格）。

**S8-04〈殘階站的水位尺〉｜線外被放棄的池站｜25 分**
- **委託人**：荇（殘階站最後的池守，十九歲）。**起因**：M8-11 落封套後，玩家自己的線把殘階站劃在棄側。荇沒有走，仍每天刻水位尺。F5＝潛越破線時須由釺陪同越線。
- **步驟**：越獸口至殘階站（味階 2–3，風向路線）→ 看荇的水位尺（每天一刻，一直往下）→ 取乾霧絨樣本 → 決定。
- **關鍵對白（全文）**：

```

珂潾：是。
荇：我在哪一欄？
珂潾：棄。
荇：（點頭）我想也是。我的池比留燈的淺。要是我畫，我也這樣畫。
```

**S8-05〈七花走的那條路〉｜20 分**

**S8-07〈分痛〉｜15 分**

**S8-08〈十二匣〉｜20 分**

- **關鍵對白**：焠：「燒過的地會自己長回來？」珂潾：「不是長回來。長的是別的東西。原來的不在了。但這裡不是空的。」

**S8-10〈引火繩〉｜炟的個人支線｜15 分**
