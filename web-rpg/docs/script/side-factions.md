# 第一部〈焚脈者的悔〉

## 1. 章首資訊

| 項目 | 內容 |
|---|---|
| 視角 | 燼——當時是第七窄切組入隊第二年的組員，不是隊長；尚未灼傷 |
| 時間 | 主線約六年前，清季將盡。五階段（味變→霧退→流慢→封脈→乾化）的說法才剛在前線流傳，程序還沒被寫死 |
| 地點 | 硫裂環外緣·礫口種源站，與周邊的上礫池站、礫口主導管夾點 |
| 時數 | 3h（180 分鐘），無支線 |
| 進場狀態 | 第七窄切組六人滿編；礫口種源站五批種源已送出一批 |
| 離場狀態 | 窄切組存二人（燼、硯）；種源站全毀，站內四人存一；上礫池站三十一名居民全數撤出；送出種源兩批又一匣 |
| 葉帖 | 無。旁註 4 則（見 §8） |

## 2. 主題與一句話

**一句話**：每一個「再等一下」都有站得住腳的理由；來不及，是這些理由加起來的樣子。

**主題**：延遲不是懦弱造成的，是責任感造成的。本篇不回答「當時該不該早切」——早切，種源站一樣會死，只是人會活；
而等待確實多送出一批種源、撤完一整座池站。火在本篇不是解答：最後那一次切除擋住了硫化越線，也殺了點火的人。

**脈況階段**：流慢 → 封脈（本篇發生於兩者之間的半個日夜）。

**環境母題**：
- **光**：清季的橙色斜光、乾霧（不濕的霧，帶礦粉）；藍昏時病紅第一次比青光亮。
- **聲**：鐘管草的喘鳴；缺口風的哨音；最後是聲場變空。
- **味**：燼在本篇仍能辨味，但只到一般人的程度——「鹹」和「臭」分得出，「苦在焦前還是焦後」分不出。所以靠試片。

## 4. 燼的指令組（本篇專用）

資源：**體力**／**氣**（濾巾飽和度，取代感官負荷；毒氣中每回合上升，滿即昏厥）／**程序值**（照程序完成步驟累積，可換取隊友支援）。

| 指令 | 作用 | 備註 |
|---|---|---|
| **讀風** | 舉風絮與試片竿，得知本回合與下一回合風向、毒氣濃度色階（白→黃→褐→黑） | 取代嚐味。試片有延遲：顯示的是「半刻前」的空氣 |
| **架隔離膜** | 在兩格之間拉起半透膜，擋氣不擋人；每張膜撐三回合 | 膜數有限，由煦補給 |
| **管段夾** | 預夾（掛上不收）／收夾（截流）。收夾後下游三回合內失壓 | 收夾是不可逆操作 |
| **燼灰中和** | 撒灰降一格硫化色階；劑量由硯秤給，過量會結殼堵管 | 每場灰量固定 |
| **撤離秩序** | 指定誰先走、走哪條承重線；活土每格每回合只承兩人 | 不能叫人跑 |
| **不可逆判定** | 查五證：①汲蟲亮點 ②活土回彈 ③鐘管草音 ④試片色 ⑤隔膜。過三證即報「不可逆」 | 判定是報告，不是命令——下令的是隊長 |

> 設計註：燼沒有嚐味。玩家習慣了珂潾「一口就知道」，在這裡要改用竿子、色階和數步子。
> 所有讀值都比現實慢半拍——這是本篇的機制核心。

## 5. 場次

### SF1-01〈零頭〉（框架開場，全文）

- **地點／時段**：縫林環，窄切組夜營（主線第 4 章之後的某一夜）。慢流沼澤的水面幾乎不動，縫葉的五種葉在無風裡各自垂著。
- **出場**：燼、硯。
- **目的**：只給一個物件——灰袋——然後進入六年前。不讓珂潾出場，避免與第 4 章對白衝突。

營火不大。焚脈者的火向來不大。

你坐在上風處，把一塊巴掌大的菌絲氈對摺、再對摺，用牙咬住一角，單手打結。左手不太聽話——它從來沒有再聽話過——所以結是右手打的，左手只負責壓住。

硯在火的另一邊秤灰。小銅匙，刮平，倒進罐，記一筆。再一匙。

```
硯：今天這片，一共四兩六錢。
燼：嗯。
硯：帳上記四兩五。
燼：零頭呢。
硯：（把匙尖上那一點遞過來）在這。
```

你攤開氈袋。硯把匙翻過來，灰落進去，輕得沒有聲音。

```
硯：六年了。你還是只要零頭。
燼：帳上記得進去的，帳會記。
硯：記不進去的呢。
燼：（收緊袋口）放回去。
```

沼澤那頭有鐘管草在校音，慢半拍的那一株又慢了。你把袋子收進胸前的內層，那裡還有三個空的。

第一個不是在這裡縫的。

〔畫面：火光縮成一點。乾霧。風哨聲。字卡：**硫裂環外緣·礫口｜六年前**〕

- **玩法**：無。**時間：4 分**

### SF1-02〈風不等人〉

- **地點／時段**：礫口（環脊缺口）。清季午後，退潮初。橙光斜進缺口，乾霧貼著地面走，霧裡有礦粉，吸進去舌根發澀。
- **出場**：燼、烽、鍛、硯、鑄、煦。
- **目的**：介紹六人編制與各自職司；讀風教學；建立烽與燼的師徒感；埋「缺口風在潮轉時回頭」。

```
烽：停。竿子舉起來。不是那樣——你當它是旗啊？風絮要過頭頂，試片朝自己。
燼：朝自己我怎麼看風？
烽：風不用看。風你用後頸感覺。試片才要看。來，報。
燼：風絮……偏內海。試片白。邊緣有一點黃。
烽：「一點」是多少？
燼：一指寬。
烽：好。記住，試片告訴你的是半刻前的空氣。你現在吸的這一口，它還沒寫上去。
煦：（悶在濾巾裡）所以這塊巾才要一直戴著。悶死了。
烽：悶死比毒死慢。
鍛：烽。
烽：是，隊長。——燼，缺口的風有個脾氣。潮往裡漲，風跟著往內海吹；潮一轉，風會回頭。回頭之前會停一下。
燼：停多久？
烽：看它高興。我數過最短的是七口氣。
燼：七口氣能做什麼？
烽：能把濾巾拉緊，然後開始後悔剛才沒走。（笑）風不會騙人，燼。風只是不等人。
```

鍛走在最前面。她不回頭，只抬起兩根手指——前進，間距兩步。活土在腳下回彈得慢，像踩在一塊泡過頭的菌餅上。

```
鍛：聽。
硯：鐘管草。三株……不，四株。不同步了，有一株在喘。
鍛：鑄。
鑄：主導管在左下。地面比兩旁低半掌，塌過。
鍛：記。走承重線，一格兩人，不要並排。煦，膜包不要落地。
煦：是。
鍛：燼。
燼：在。
鍛：到站以後你跟烽。嘴閉上，眼睛打開。那裡是記脈院的站，人家的規矩先於我們的。
```

- **玩法**：讀風教學三題——（1）舉竿讀風絮與試片；（2）依風向選上風承重線下坡；（3）烽出題：「試片白、後頸發涼、鐘管草喘」，要玩家判斷該信哪一個（答：都記下，但先信後頸——風已經變了，試片還沒寫上去）。
- **抉擇**：無。**時間：12 分**

### SF1-03〈人家的規矩〉

- **地點／時段**：礫口種源站上層 → 下層種源龕。退潮中。晾帖棚下一排排對摺的犢皮攤著吹風，空氣裡有靛藍顏料的澀與一點點不該有的銅鏽鹹。
- **出場**：燼、鍛、硯、烽；駐站記脈者**菀**；種源護送者**荻**；上礫池站池守**老磯**。
- **目的**：菀登場——有能力、有理由、不是障礙物。交代五批種源、為什麼不能「扛了就走」。鍛與菀第一次議事。

菀站在水位尺旁等你們。四十上下，袖口有一圈一圈的礦物水痕，掌套開著。她先露出手腕內側——脈紋平穩，只是很淡，是很久沒睡的那種淡——然後伸出手背。

鍛脫下封閉手套，用手背碰了一下。

```
菀：記脈院礫口駐站，菀。站裡四個人，上面池站三十一個。你們來得比我寫信時估的早。
鍛：第七窄切組，鍛。信上說味變三旬、流慢七日。
菀：流慢九日了。汲蟲在彎道開始堆。我每個潮次嚐兩回：先是鹹，苦在後面，很穩。還沒有焦。
硯：「還沒有」是妳的舌頭說的，還是試片說的？
菀：都是。（遞過一疊試片，按時序用繩串著）退潮讀的偏黃，滿潮讀的回白。它還在喘氣，還沒有斷氣。
硯：（一張一張對著光看）……串得很仔細。
菀：我是記東西的人。
鍛：直說。我們的程序是：上游找夾點，五證過三就切。切了，主導管在妳站底下這一段會失壓。
菀：我知道。支導管會跟著斷，種源龕兩個潮次內開始死。
鍛：妳信上要我們等。
菀：我信上是請你們先來看。看完再說等不等。——下來吧。掌套封上，裡面的東西不認識你們的手。
```

下層是半埋在活土裡的一條拱道。壁是活的，摸上去溫，微微滲汁。一格一格的龕裡泡著種莢匣，匣水是淡青的，有細小的亮點在游——汲蟲，健康的。

```
菀：五批。第一批是乾得起的——孢子、休眠囊——前天已經跟舟走了。
菀：第二批是活匣。不能離水，不能離牠們。（指匣裡的亮點）你把種子拿走，把汲蟲和菌團留下，到了靛丘那邊就是一匣漂亮的死東西。
燼：整匣搬不行嗎？
烽：（低聲）嘴。
菀：沒關係，問得對。整匣搬可以，一匣連水四十斤。上面那片活土現在回彈多慢，你們進來時踩過了。
鑄：一格兩人，不能負重並行。扛不出去。
菀：所以走種源渠。渠要半潮以上才浮得起匣。——這是第一個我請你們等的理由，不是我捨不得。
鍛：第三批。
菀：最裡面那一龕。鐘管草的管器官幼體，固氮囊群，還有本院訂的一匣回退實驗材料。它們泡得深，要滿潮，龕道進了水，才抬得出來。
硯：也就是說，妳要一個半潮，再加一個滿潮。
菀：我要的是一個潮次。半潮走第二批，下一個滿潮走第三批。第四、第五，我已經在帳上劃掉了。
```

她說「劃掉」的時候沒有停頓。你注意到她的拇指在掌套裡按了一下食指的指節，按得很用力。

```
老磯：（從拱道口探身）菀，上面的集水槽今天又退了一指。孩子們問還能不能下池。
菀：不能了，磯叔。跟他們說池在換水。
老磯：我說了三天「換水」了。
菀：那就說第四天。
鍛：（對老磯）池守。三十一個人，能走的幾個？
老磯：要看妳說的「走」是多快。
```

- **玩法**：自由探索上下層。可與荻對話（他在替第二批活匣換水：「我不怕你們。我怕的是你們總是對的。」）；可查看水位尺（刻痕顯示每日高潮位下降一指）；可查看菀的試片串（教學：色階隨潮汐來回，尚未單向變深）。
- **抉擇**：無。**時間：14 分**

### SF1-04〈五證〉

- **地點／時段**：主導管夾點，上游四百步的導管洞。退潮近底。洞裡比外面暖，壁上有汗一樣的水珠；臭蛋味很淡，要停住呼吸才聞得到，一聞到就又沒有了。
- **出場**：燼、硯、鑄。
- **目的**：教學「不可逆判定」；第一次遭遇（初期燼冠與死汲蟲團）；看見那片正在長的隔膜——日後一切希望與災難的來源。

```
鑄：這節。管壁露出來一臂長，上下游都是彎。夾在這裡，回水最少。
硯：先別碰。燼，五證。一樣一樣報，不要替我省字。
燼：一，汲蟲亮點。（手掌遮光貼近管壁）……有。稀。十口氣裡過去四點。
硯：健康的管是多少？
燼：數不完。
硯：記「稀」。成立。二。
燼：活土回彈。（踩，數）一、二、三、四——回來了。四口氣。
硯：過六口才算。不成立。三。
燼：鐘管草。不同步，有喘鳴。沒有到單音。
硯：不成立。四。
燼：試片。（抽出竿子）黃。偏褐的那種黃。
硯：黃就是黃，偏什麼是你想出來的。不成立。五。
燼：隔膜。（往上游彎道探燈）……有東西。管裡面，白的，像一層沒長完的皮。
```

硯把燈接過去，看了很久。

```
硯：牠自己在封。
鑄：綠脈自己切？那還要我們幹嘛。
硯：長完了才叫切。現在是半張。（敲管壁，聽）膜後面的水是滿的，不流。膜前面的在流。
燼：這算成立還是不成立？
硯：我當灰衡者十九年，沒有人教過我半張膜怎麼記。
燼：那怎麼報？
硯：照看到的報。五證得一，一證存疑。——你來報，隊長問的是在夾點的人。
```

**遭遇一：彎道燼冠（初期）與死汲蟲團**

- 健康原型：攀在導管洞口的一株矮生縫葉近緣株（三葉型）。野化狀態：冠部泛紅、略熱，尚未增生。
- 本遭遇無味序。改用「色階序」：洞內三格空氣的試片色為〔黃／褐／黃〕，褐格是死汲蟲團堆積的低彎。
- 流程：**讀風**（洞內氣流向下游，穩）→ **架隔離膜**隔開褐格 → 硯秤出二錢灰 → **燼灰中和**撒於低彎（褐降為黃）→ 鑄**預夾**（掛上不收）。
- 錯誤示範：若玩家想多撒灰，硯會攔下。

```
硯：二錢。
燼：再多一點不是更保險？
硯：多一錢，灰在彎道結殼，你就替脈枯把管堵上了。藥跟毒差一個刮平的匙面。
燼：那株紅的呢？燒掉？
硯：它現在才微熱。燒一株微熱的東西，你得到半錢灰和一個燒過的洞口。先記座標。
鑄：夾掛好了。沒收。
硯：好。誰在這裡，誰的手離夾最近，記住是哪一隻手。
```

- **抉擇（小）**：離開前，玩家可選是否替那株微紅的縫葉近緣株**搭一小片遮膜**（耗一張膜）。搭→旁註〈1-A〉措辭改變，錄 +1；不搭→膜數多一張，SF1-10 多一回合餘裕。

### SF1-05〈第一次等〉（全文）

```
鍛：報。
燼：夾點在上游四百步，已預夾。五證得一，一證存疑。汲蟲稀，成立。回彈四口氣、鐘管草未單音、試片黃，三項不成立。隔膜……半張，在長。

硯：意思是綠脈可能自己會把這一段封掉。封成了，不用我們動火，站跟下游的連結還在。封不成，那半張膜後面憋著的東西比沒有膜更糟。
菀：十一年。這條管我嚐了十一年，它在滿潮沒有破過一次。
硯：妳嚐的是沒病的十一年。
菀：對。所以我沒有說它不會破。我說的是：現在切，是你們替它決定它封不成。
烽：風我讀過了。往內海，穩。就算上游冒氣，也是從缺口出去，不進這個窪。

煦：隊長，還有池裡那個。
鍛：哪個。
```

```
鍛：燼。你在夾點。你說。
```

### SF1-06〈不能叫人跑〉

- **地點／時段**：上礫池站。退潮底到初漲。集水槽邊的孢子濾幕收了一半，曬架上還晾著誰家的菌毯。孩子們赤腳，活土在他們腳下回彈得比在大人腳下快。
- **出場**：燼、煦、老磯、池站居民（**阿穗**——九歲、**磯嬸**、不肯走的**老蓼**）。
- **目的**：「撤離秩序」玩法主場；讓玩家知道這次等待換到了什麼——三十一個具體的人。

- **玩法（撤離秩序）**：俯視格盤，三條承重線通往窪口。規則：每格每回合只承兩人；負重者算兩人；孩童必須與一名成人同格；跑步＝該格下一回合塌陷（不可叫人跑）。十二回合內全數出窪為佳。
  - 事件一：阿穗跑回去拿水位尺的備用刻板（「池守說那是池的生日」）。玩家可派煦去追（少一人維持膜線）或讓老磯喊她回來（多耗兩回合）。
  - 事件二：一格活土回彈降到六口氣——第二證在撤離途中「成立」了一格。玩家要改線。
  - 事件三：老蓼。

```
老蓼：我不走。我在這池邊坐了六十個清季。
燼：這段脈可能要切。切了，池會退到底。
老蓼：池退到底，我也在底。
煦：（小聲）用抬的？
燼：抬就是負重，一格。後面七個人要多等三回合。
老蓼：小孩，你不用算給我聽。我聽得懂。
燼：……那我不算。妳告訴我，妳走了，這裡有什麼會沒人做？
老蓼：（很久）晨霧來之前，要有人把濾幕的東角放下來。不然孢子進不來，池會餓。
燼：東角。我記了。我們的人在這裡的每個早上都會放。
老蓼：你們是來切它的，還替它放濾幕？
燼：還沒切以前，它是活的。
老蓼：（撐著膝蓋站起來）扶我。不要抬。我自己的腳記得這條路哪裡軟。
```

〔她走在最後，一步都沒有踩錯。全盤唯一不需要玩家指定路線的人。〕

- **結果**：三十一人全數出窪（固定）。回合數只影響燼的程序值與 SF1-08 可得的對話。
- **抉擇（小）**：是否答應每個早晨放下濾幕東角。答應→ SF1-08、SF1-09 各多一個必須執行的小步驟（各耗一回合），旁註〈1-B〉出現；不答應→老蓼由磯嬸勸走，旁註〈1-B〉不出現。
- **向度**：答應 錄 +1。
- **時間：16 分**

### SF1-07〈你們切的是管〉

- **地點／時段**：種源渠。半潮。水爬上渠壁第二道刻痕，淡青色，還帶著甜——連你都嚐得出來的那種甜。一隻潾者從站池滑進渠口，半透明的背冠在橙光裡亮了一下，往下游去了。
- **出場**：燼、菀、荻、烽（脊上，遠聲）。
- **目的**：搬第二批；菀與燼的長對話——記脈者的立場用搬東西的手說出來；本篇兩個人唯一一次單獨談話。

- **玩法（浮匣）**：十二只活匣要從龕口下到渠裡、推到舟邊。活匣不能傾斜超過一掌、匣水不能濺出（汲蟲會跟著水走）、渠岸每格只承兩人。燼負責在岸上「讀風」並回報渠面有無氣泡（有＝上游在排氣）。全程渠面無泡。

```
菀：手放低。匣角不要碰壁，壁也是活的，會記仇。
燼：妳都這樣跟東西說話？
菀：我跟東西說話，跟你們說程序。兩種我都講得不好。
燼：妳講得比我們隊上的人多。
菀：因為我只剩一個潮次可以講。（把一只匣推進水裡，看它浮穩）……你剛才在上面問，整匣搬行不行。
燼：我多嘴。
菀：不是。我是想告訴你為什麼我沒有生氣。你們來，看到的是一條管。病了，會傳，所以夾住，燒掉，記座標。很乾淨。
燼：不乾淨。
菀：（看你一眼）好。不乾淨，但清楚。我這邊不清楚。這一匣，你看到種莢，對不對？
燼：還有蟲。
菀：還有水裡你看不到的菌，還有這株跟隔壁那株長在一起時才會開的一種囊。我搬的不是種子，是牠們之間的關係。關係沒辦法裝匣，只能整段一起端走。所以慢。
燼：慢到什麼時候算太慢？
菀：我不知道。這是真話。你們有五證，我沒有。我只有每個潮次嚐兩回，然後寫下來。
燼：寫下來不能讓它不死。
菀：不能。寫下來是讓下一個站的人少等一個潮次。——或者多等，如果我寫的是「等了，結果它自己封好了」。
燼：妳希望是哪一個？
菀：我希望我寫的是真的。
```

荻在舟上接匣，數到十二，舉手。舟離岸時他沒有回頭，只是把一隻手伸進水裡，像在跟什麼東西告別。

```
菀：十二匣。荻會送到靛丘。你們等的這半個潮次，換到這個。
燼：還有三十一個人。
菀：還有三十一個人。（封上掌套）——第三批要滿潮。我去跟你們隊長說。
燼：她會問我。
菀：我知道。所以我先跟你說了。你不用替我講話，你照你看到的講。
烽：（脊上，遠遠地喊）半潮——風往內海——穩！
```

- **抉擇**：無。**時間：14 分**

### SF1-08〈刮平的匙面〉

### SF1-09〈第二次等〉（全文）

- **地點／時段**：夾點導管洞 → 種源站上層。次日清晨，漲潮過半。乾霧沒有來——連乾霧都沒有。空氣清得可以看見脊線上每一塊石頭的邊，老磯說這種早晨以前叫「好天」。
- **出場**：燼、硯、鑄、鍛、菀、烽、煦。
- **目的**：第二個「再等一下」。讀數在線上，不在線下；這一次等，是在程序的灰色地帶裡等。

```
硯：五證。照昨天的順序。
燼：一，汲蟲亮點。十口氣……一點。稀。成立。
硯：二。
燼：回彈。（踩，數）……五口氣。
硯：沒過六。不成立。三。
燼：鐘管草。喘鳴變長了。還是沒有到單音，有一株在單音的邊上。
硯：邊上不是到。不成立。四。
燼：試片。褐。
硯：這次是褐。成立。五。
燼：隔膜。（探燈）……比昨天厚。白的面積多了，大概七成。中間還有一道縫，縫裡在滲。
鑄：夜裡我聽見它長。像有人在很遠的地方撕濕的皮，倒著撕。
硯：五證得二，一證存疑。存疑的那一證，比昨天更往「牠自己會封」那一邊。
燼：也可能更往「憋得更滿」那一邊。
硯：（看你）說下去。
燼：昨天妳敲管壁，膜後面是滿的。今天七成膜擋著滿潮的壓，比半張膜擋著半潮的壓——我不會算。
硯：我會算。半潮我算得出，滿潮我算不出來。我沒有這條管的舊帳。
```

回到站上。菀已經在水位尺旁，手裡是新的一串試片。

```
菀：今晨兩回。鹹，苦，苦的尾巴上有一點點焦——一點點，退得很快。站池這邊沒有。焦只在上游樣。
鍛：到焦了。
菀：到焦的邊了。我不替它說好話：比昨天壞。但隔膜也比昨天厚，這個你們自己看到了。
鍛：妳的要求。
菀：到滿潮。龕道進水，第三批十四匣，抬出來要一刻半。然後你們收夾，我不會再說一個字。
硯：隊長。兩證成立，一證存疑。程序是過三才切。把存疑算成立，是三；算不成立，是二。
鍛：妳怎麼算。
硯：我不算。半張的膜不是膜，七成的膜我沒見過。我只能說：灰我備好了，今天的量是昨天的三倍。
烽：風往內海，穩。我昨夜跟今晨各讀六回。滿潮後才會轉。
鍛：「才會」。
烽：……照十一年的潮曆，才會。
菀：鍛隊長。我說一件跟種源無關的事。你們現在收夾，膜後面那一管水就沒有去處了。它會找最薄的地方出來。最薄的地方是我站底下的支導管。
硯：這是真的。
菀：等到滿潮，膜若長滿，它就被封在上游，哪裡都不去。這不是我想保站才說的。
鍛：我知道不是。
```

鍛這次沒有看水位尺。她看的是你。

```
鍛：燼。夾點是你讀的。存疑那一證，你怎麼記。
```

> **抉擇 B（第二次「等」）**
>
> - 〔等到滿潮〕「記存疑。兩證。等到滿潮，第三批出龕，膜若滿了就不必切。我回夾點，手放在夾上。」
> - 〔只等一刻〕「記存疑，但我不要等到滿潮。給菀一刻，把最深那一龕能封的活匣封好、人上來。一刻後收夾。」
> - 〔現在收夾〕*（灰色，不可選）*——**「現在收，膜後的水會從站底出來；下層有四個人。你說不出口。」**

```
（選〔等到滿潮〕）
燼：記存疑。兩證。我建議等到滿潮。我回夾點，手放在夾上，一有變我收。
鍛：一有變你喊，我收。夾點我跟你去。鑄也去。
燼：隊長——
鍛：你提的等。你讀風。夾我來。
鍛：硯，灰衡台。煦，下層口架膜，三張都帶。烽——
烽：我下去抬匣。風交給燼了，昨晚說好的。
鍛：（停了一口氣）好。滿潮。出一匣報一匣。

（選〔只等一刻〕）
燼：給一刻。封得了的封，人上來。一刻後收夾。
菀：一刻夠我封六匣，抬不出來。
燼：抬不出來就留在龕裡。封好的匣，站死了以後也許還能撐幾個潮次，有人回來拿。
菀：（很慢）……你這個想法不壞。我沒想過「以後回來拿」。
鍛：一刻。烽下去幫封，煦下層口架膜，硯灰衡台。燼讀風，夾點我跟鑄。一刻到，不管封幾匣，全部上來。
〔此線：一刻將盡時，潮比曆上早了半刻——水已進龕道，匣浮了起來。菀在下面喊：「浮了！現在抬得出去！」
　烽：「隊長，就差抬！」鍛看水位尺，看你。玩家再得一次選擇：〔讓他們抬〕／〔照說好的，上來〕。
　選〔上來〕者，烽與護送者已各抬著一匣在龕道中段，轉身需要時間——SF1-10 的潮轉仍在他們出龕前到來。
　兩線自此匯流。旁註記錄的是：玩家試過把等待縮到最短。〕
```

- **向度**：〔等到滿潮〕播 +1、錄 +1；〔只等一刻〕焚 +1；一刻線中再選〔讓他們抬〕播 +1。
- **時間：14 分**

### SF1-10〈七口氣〉（轉折，全文）

- **地點／時段**：礫口脊上 → 種源站上層。滿潮前後。水位尺的最高刻痕濕了。站池滿得發亮，鐘管草的花冠全開，是這兩天裡最像健康的一刻。
- **出場**：燼（脊上讀風）、煦（下層口）、硯（灰衡台）、菀與烽與兩名護送者（下層）、鍛與鑄（夾點，遠）。
- **目的**：兩個合理的假設同時失效。

你站在烽昨天站的地方。風絮在竿頂朝內海飄，穩得像畫上去的。試片是褐，沒有更深。

下面傳來報數。

```
煦：（喊）第一匣出龕！
煦：第二匣！
硯：（灰衡台，遠）潮位到頂刻——過頂刻半指。
煦：第三匣！烽哥說裡面水到腰了，好抬！
```

你數到第五匣的時候，後頸不涼了。

不是變熱。是沒有了。推了你兩天的那隻手，從背上拿開了。

風絮垂下來。

> **〔計時事件：七口氣〕** 畫面不出現任何提示字。只有風絮垂著、呼吸聲、與一個指令欄。
> 玩家可用的指令：**讀風**（再讀一次，耗兩口氣，試片仍褐——它還沒寫上去）／**喊**（立即）。
> 沒有「等」的按鈕。但什麼都不按，就是等。

```
（選〔喊〕——無論在第幾口氣）
燼：風停——！！風停了！下層上來！全部上來！
```

你的聲音在缺口裡撞了一下。然後你聽見另一件事：你聽見自己的回音。

你聽得見回音，是因為別的聲音沒有了。

鐘管草不喘了。一株都不喘了。喘了兩天的那個聲音，像有人把手掌按在所有管口上。

```
硯：（遠，第一次聽見這個人用喊的）鐘管草——！隊長！失聲了！
```

腳底傳來一下。不是震，是一下——像活土整塊嚥了一口。上游，夾點的方向，脊線後面，一股白氣貼著地冒出來，不往天上走，往窪裡淌。

風回頭了。

你低頭看試片。褐。還是褐。它要再過半刻才會寫上黑。

```
燼：（往下跑，沿承重線，一格一格——你沒有踩錯）煦！膜！下層口架膜！
煦：架了！一張！——燼，裡面的水變色了！
燼：什麼色？
煦：本來是青的！現在——（咳）——現在像泡過鏽的！
```

〔插入（一格畫面，無聲）：夾點。七成的隔膜，中間那道縫。滿潮的壓。縫開了。〕

- **玩法**：計時事件後接「架隔離膜」急行：燼從脊上到下層口共九格，每格需判斷承重與氣色；途中可用**燼灰中和**壓低兩格（灰量由 SF1-08 校準決定）。若 SF1-04 沒有替縫葉搭遮膜，此處多一張膜可用。
- **固定結果**：無論第幾口氣喊、無論多快，燼到下層口時，龕道裡仍有五個人（菀、烽、兩名護送者；煦在口上）。
- **時間：14 分**
