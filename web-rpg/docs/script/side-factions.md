# 第一部〈焚脈者的悔〉

## 1. 章首資訊

| 項目 | 內容 |
|---|---|
| 視角 | 燼——當時是窄切組的**判線手**，不是隊長；尚未灼傷 |
| 時間 | 主線**三年前**，清季將盡。那時硫裂環的第一線還站著 |
| 地點 | 硫裂環第一線前方·**淺龕站**（種源站），與站下的淺龕下池、上游坐氣窪、主管夾點 |
| 時數 | 3h（180 分鐘），無支線 |
| 進場狀態 | 窄切組五人滿編（隊長鍛）；淺龕站九人，龕冊登記四十一個譜系 |
| 離場狀態 | 窄切組五人回來一人（燼）；站上九人無人生還；四十一個譜系成灰；下池十九名居民事前撤出；切除延後一個潮次後完成 |
| 葉帖 | 無。旁註 4 則（見 §8） |

## 2. 主題與一句話

**一句話**：站長說可以空手走。說「再一個潮次」的人，是看過四十一格龕之後的你。

**主題**：延遲不是懦弱造成的，是看見造成的。本篇不回答「當時該不該照判就切」——照判就切，四十一個譜系一樣會死，只是十三個人會活。
火在本篇不是工具也不是解答：它是一盞照著人搬東西的灰油燈。最後那一次收夾擋住了硫越線，晚了一個潮次。

**脈況階段**：流慢 → 封脈。**環境母題**：
- **光**：清季的橙色斜光；龕室裡的灰油燈，火苗先是黃的。
- **聲**：站上的水鐘（一個潮次敲三鐘）；鐘管草的喘鳴；最後是聲場變空。
- **味**：燼此時還嚐得出東西，但只到一般人的程度——分得出鹹和甜，分不出「苦在焦前還是焦後」。所以靠試片與程序。

## 4. 燼的指令組（本篇專用）

資源：**體力**／**氣**（濾巾飽和度，取代感官負荷；毒氣中每回合上升，滿即昏厥）／**程序值**（照程序完成步驟累積，可換取隊友支援）。

| 指令 | 作用 | 備註 |
|---|---|---|
| **讀風** | 舉風絮與試片竿，得知風向與毒氣色階（白→黃→褐→黑） | 取代嚐味。試片顯示的是「半刻前」的空氣 |
| **架隔離膜** | 在兩格之間拉起半透膜，擋氣不擋人；每張撐三回合 | 膜數有限 |
| **管段夾** | 預夾（掛上不收）／收夾（截流） | 收夾不可逆 |
| **燼灰中和** | 撒灰降一格硫化色階；過量會結殼堵管 | 劑量由灰衡者秤給 |
| **撤離秩序** | 指定誰先走、走哪條承重線；活土每格每回合只承兩人 | 不能叫人跑 |
| **不可逆判定（判線）** | 查五證：①汲蟲亮點 ②活土回彈 ③鐘管草音 ④試片色 ⑤隔膜。過三證即「不可逆」，據此畫線 | 判線手判，隊長下令 |

> 設計註：玩家習慣了珂潾「一口就知道」，在這裡要改用竿子、色階和數步子。所有讀值都比現實慢半拍——這是本篇的機制核心。
> 唯一一次用舌頭，是在龕室裡（SF1-06），而且不是為了診斷。

## 5. 場次

### SF1-01〈掃剩的〉（框架開場，全文）

- **地點／時段**：縫林環，窄切組夜營（主線第 4 章之後的某一夜）。慢流沼澤的水面幾乎不動，縫葉的五種葉在無風裡各自垂著。
- **出場**：燼、硯。（不讓珂潾出場，避免與第 4 章對白衝突。）

營火不大。焚脈者的火向來不大。

你坐在上風處，把一塊巴掌大的菌絲氈對摺、再對摺，用牙咬住一角，單手打結。壞的那一側的手不太聽話——它沒有再聽話過——所以結是好的那隻手打的，壞的那隻只負責壓住。

硯在火的另一邊秤灰。舊秤盤，盤緣磨出一圈亮。一撮，記一筆。再一撮。

```
硯：今天這條線，四兩六錢。
燼：嗯。
硯：帳上記四兩五。
燼：零頭呢。
硯：（把秤布攤過來）在這。掃剩的。
```

你把氈袋撐開。灰落進去，輕得沒有聲音。你在繩上打結：短，短，長。今天線裡那株你認得的東西，是這個拍子。

```
硯：三年了。你每條線都要掃剩的。
燼：帳上記得進去的，帳會記。
硯：記不進去的呢。
燼：（收緊袋口）放回線上。
```

沼澤那頭有鐘管草在校音，慢半拍的那一株又慢了。你把新袋子放在腳邊，明早出發前會擱在線頭。

內袋裡還有一只。舊的，布磨得發亮。那一只的繩上沒有結，也沒有放回去過。

〔畫面：火光縮成一點。乾霧。風哨聲。字卡：**硫裂環·第一線｜三年前**〕

- **時間：4 分**

### SF1-02〈風不等人〉

- **地點／時段**：第一線稜線。清季午後，退潮初。橙光斜過稜線，乾霧貼著地面走，霧裡有礦粉，吸進去舌根發澀。
- **出場**：燼、鍛（隊長）、烽（風哨）、鑄（灰衡者，年長）、焙（膜夾手，最年輕）。
- **目的**：五人編制；讀風教學；烽與燼的交情；埋「風轉之前會停一下」。

```
烽：停。竿子舉起來。風絮過頭頂，試片朝自己。判線手自己不會讀風，判出來的線是歪的。報。
燼：風絮偏內海。試片白，邊緣一指寬的黃。
烽：好。記住，試片告訴你的是半刻前的空氣。你現在吸的這一口，它還沒寫上去。
焙：（悶在濾巾裡）所以這塊巾才要一直戴著。悶死了。
烽：悶死比毒死慢。
鍛：烽。
烽：是，隊長。——燼，這條稜線的風有個脾氣。潮往裡漲，風往內海吹；潮一轉，風會回頭。回頭之前會停一下。
燼：停多久？
烽：我數過最短的是七口氣。
燼：七口氣能做什麼？
烽：能把濾巾拉緊，然後開始後悔剛才沒走。（笑）風不會騙人。風只是不等人。
```

鍛走在最前面。她不回頭，只抬起兩根手指——前進，間距兩步。活土在腳下回彈得慢，像踩在一塊泡過頭的菌餅上。

```
鍛：聽。
鑄：鐘管草。四株，不同步，有一株在喘。
鍛：記。走承重線，一格兩人，不要並排。焙，膜包不要落地。
鍛：燼。
燼：在。
鍛：線前面有一座記脈院的站。線怎麼畫，看管，不看站。判完再看站。
燼：知道。
鍛：你上一條線判得準。準的人容易想再準一點。——走。
```

- **玩法**：讀風教學三題（舉竿；選上風承重線；烽出題「試片白、後頸發涼、鐘管草喘，信哪個」——答：都記，先信後頸）。
- **時間：12 分**

### SF1-03〈線看管，不看站〉

- **地點／時段**：上游坐氣窪 → 主管夾點。退潮近底。窪是一塊比四周低一人高的死脈地，試片竿伸進去，下半截褐、上半截白，中間一條很平的線，像水面。
- **出場**：燼、鑄、焙、烽（稜上）。
- **目的**：「不可逆判定」教學；判線——玩家親手把淺龕站畫在棄側；埋坐氣窪。

```
鑄：看見沒有。氣比風重，坐在低處。風從這邊推，它就坐著不動。
燼：風要是換邊？
鑄：就會找路往更低的地方淌。這附近更低的只有站那個窪，中間隔一道土梁，地面上過不去。
燼：地面下呢。
鑄：下面是主管，滿的，走水不走氣。——五證。一樣一樣報，不要替我省字。
燼：一，汲蟲亮點。十口氣過去兩點。稀。
鑄：成立。二。
燼：回彈。（踩，數）七口氣。
鑄：過六。成立。三。
燼：鐘管草。喘鳴，有一株到單音了。
鑄：一株不算一片。不成立。四。
燼：試片褐。
鑄：成立。五。
燼：隔膜。管裡有，硬的，長滿了。牠自己已經封了上游這一截。
鑄：成立。五證得四。這一截不可逆。線要畫在哪？
```

- **玩法（判線）**：俯視剖面圖。玩家沿主管往下游逐節檢查「可夾點」：需管壁外露、上下游皆有彎、活土承得住兩人。
  最近的一處在站的**上游三十步**——但那一節回彈九口氣，夾不住；下一處合格的夾點在站的**下游兩百步**。
  玩家拖動判線標記，系統只在合格夾點亮起。標記落下的瞬間，地圖上淺龕站的圖示從青轉為骨白：**棄側**。

```
焙：（看圖）……站在線外面。
燼：站底下那一截管，上游夾不住。夾在下游，站就在棄側。
焙：站上的池還是青的欸。鐘管草也只有一株單音。
鑄：線看管，不看站。隊長說過了。
燼：（把判線籤插進土裡，寫上自己的名字）判線手，燼。五證得四。夾點在站下游兩百步。
鑄：判得對。
燼：我知道對。
鑄：知道對，手就不要在籤上停那麼久。
```

**遭遇一：窪緣燼冠（初期）**——健康原型為一株三葉型縫葉近緣株；冠部泛紅微熱。無味序，用「色階序」〔黃／褐／黃〕：讀風→架膜隔開褐格→鑄秤二錢灰→中和→焙在夾點**預夾**。

```
燼：再多撒一點不是更保險？
鑄：多一錢，灰在彎道結殼，你就替脈枯把管堵上了。藥跟毒差一個刮平的匙面。
```

- **抉擇（小）**：是否耗一張膜替那株微紅的近緣株搭遮膜。搭→錄 +1，旁註〈1-A〉措辭改變；不搭→SF1-11 多一張膜。
- **時間：16 分**

### SF1-04〈不能叫人跑〉

- **地點／時段**：淺龕下池。退潮底。集水槽邊的孢子濾幕收了一半，曬架上還晾著誰家的菌毯；孩子們赤腳，活土在他們腳下回彈得比在大人腳下快。
- **出場**：燼、焙、下池居民十九人（九歲的**阿禾**、不肯走的**老茨**）。
- **目的**：「撤離秩序」主場。這十九人在判線當下就撤，**不是**日後等待的理由——讓玩家先做對一次。

- **玩法**：格盤三條承重線通往線後。每格每回合只承兩人；負重者算兩人；孩童須與成人同格；跑＝該格下一回合塌陷。
  事件：阿禾跑回去拿水位尺的備用刻板（「那是池的生日」）；一格回彈突然變慢須改線；老茨。

```
老茨：我不走。我在這池邊坐了六十個清季。
燼：線畫了。這段脈要切。切了，池會退到底。
老茨：池退到底，我也在底。
焙：（小聲）用抬的？
燼：抬就是負重，後面七個人要多等三回合。——妳告訴我，妳走了，這裡有什麼會沒人做？
老茨：（很久）晨霧來之前，要有人把濾幕的東角放下來。不然孢子進不來，池會餓。
燼：東角。記了。還沒切以前，我們的人每個早上會放。
老茨：你們是來切它的，還替它放濾幕？
燼：還沒切以前，它是活的。
老茨：（撐著膝蓋站起來）扶我。不要抬。我自己的腳記得這條路哪裡軟。
```

- **結果**：十九人全數撤到線後（固定）。**抉擇（小）**：是否答應放濾幕東角——答應→錄 +1，SF1-09 多一個小步驟，旁註〈1-B〉出現。
- **時間：14 分**

### SF1-05〈判了就切〉

- **地點／時段**：淺龕站上層。初漲。浮基隨水微微起伏；站柱上刻著一張很舊的管圖，刻痕裡積著鹽。水鐘剛敲過，餘音在池面上走得很遠。
- **出場**：燼、鍛、鑄、烽、焙；站長**菀**；站員**荻**（護送者）、**老磯**（守槽人）、**粟**（學徒，十六歲）等九人。
- **目的**：菀登場——有能力、不求情。站上每個人「還沒搬完」的理由都是真的。

菀在水鐘旁等你們。四十上下，袖口有一圈一圈的礦物水痕。她先露出手腕內側——脈紋平穩，只是很淡，是很久沒睡的那種淡——然後伸出手背。鍛脫下封閉手套，用手背碰了一下。

```
鍛：窄切組，鍛。線判了。夾點在妳站下游兩百步。
菀：（沒有看圖，看的是你插籤的那隻手）站在棄側。
鍛：是。
菀：下池的人？
燼：十九個，撤到線後了。
菀：好。（轉身，對站員）都聽見了。判了就切，我們空手走。
粟：站長！十七格那一系只有我們有——
菀：我知道哪一系只有我們有。我比妳多知道二十年。
荻：現在渠裡有水。活匣浮得起來。一個潮次，我一個人就能走十匣。
菀：一個潮次後你人在不在渠裡，要看風。風不歸我管。
老磯：槽獸還在後廊。牠不會跟人走，龕水槽不舔開，牠不離槽。
菀：那就留牠。牠是站上的，站在哪牠在哪。
（她轉回來。）
菀：鍛隊長，他們說的每一句都是真的。四十一個譜系，活的，離了彼此就是一匣漂亮的死東西，所以沒辦法抓了就跑。真的。可是真的也不夠。九個人排在四十一格前面。我們空手走。
鍛：一刻收拾。
菀：用不到一刻。帳冊我帶，其他不帶。
```

你應該在這時候轉身去夾點。程序上，判線手還剩一件事：棄側登記——寫下線外放棄了什麼。照例是抄龕冊。

```
燼：站長。棄側登記。
菀：龕冊在這。四十一系，名目、來處、共生配方。你抄，抄完還我。
燼：我要進去看。
菀：（停了一下）登記不需要看。
燼：我判的線。我要知道我判掉的是什麼。
鑄：燼。
鍛：（看了你大概五口氣那麼久）一刻。我跟你進去。
```

- **玩法**：可與站員各談一句（荻：「我不怕你們。我怕的是你們總是對的。」粟在偷偷往袖裡塞一只小匣，被菀按住手）。可查看站柱舊管圖（一條標著「廢·乾」的細線從上游低處通到站底——此時只是一行刻字）。
- **時間：14 分**

### SF1-06〈全部打開〉（全文）

- **地點／時段**：龕室。漲潮中。室內沒有天光，壁上每隔三格掛一盞灰油燈，火苗是黃的、短的、不動的。牆是骨白的活壁，一格一格，四十二格；格裡泡著種莢匣，匣水淡青，有細小的亮點在游。後廊深處有一種規律的、濕的聲音——一隻瘦長的四肢獸伏在龕水槽邊，一下一下地舔礦殼。
- **出場**：燼、菀、鍛；粟（遞試味片）；舔泉獸。

```
菀：掌套封上。裡面的東西不認識你的手。
燼：四十二格。龕冊寫四十一。
菀：最裡面那格是空的。上一季本院有人來，把寄存的三件取走了。
```

空龕口繫著一片薄籤。籤角畫著一株小草，根的位置開了一朵花。你看不懂那是什麼意思。籤上的字你認得幾個：「已取」。

```
燼：為什麼取走？
菀：那個人說，活的東西不該放在龕裡。
燼：妳同意？
菀：我是守龕的。我同不同意，龕都在這。（走到第一格）你要看哪幾格？
```

> **抉擇 A（第一次：你要怎麼看）**
>
> - 〔「全部打開。我要看。」〕
> - 〔「一格一格。看一格，關一格。」〕——菀：「那要兩個鐘。」鍛：「沒有兩個鐘。」→ 回到上一項。
> - 〔「不看了。抄冊子。」〕*（灰色）*——游標停留時顯示：**「你已經站在裡面了。」**

```
燼：全部打開。我要看。
菀：全部打開，就得在一個潮次裡關回去或搬走。開著，會乾。
燼：開。
菀：（看鍛）
鍛：判線手要看。開。
```

菀從第一格開始。她開龕門的手法是往上托半寸再外拉，鉸縫一點聲音都沒有。四十一扇門，一扇一扇，全部開著。匣水的氣味湧出來——你戴著濾巾都聞得到——是甜的。

粟遞來一疊試味片。菀在每一格沾一下匣水，稀釋，點在片上，遞給你。

```
菀：你們焚脈者的舌頭我知道，分得出鹹跟甜，再細就不行。夠了。每一系的鹹甜拍子都不一樣，像敲門。
菀：第一格。靛丘來的矮鐘管，管器官幼體。
```

你把試味片貼上舌尖。甜，甜，鹹。長、長、短。

> **玩法〈敲門〉**：節奏記憶。每格播放一段 2–5 拍的長短拍（長＝甜，短＝鹹），玩家跟著按一次。共四十一段，分五組，組間是菀的話。
> 不計分、不會失敗；按錯只會讓菀再點一片。系統**不告訴玩家**這些拍子之後還會用到。

```
菀：第九格。縫林的六葉型，全環只剩這一株母本。開花要隔壁第十格的固氮囊在場，所以兩格算一系半。
燼：（短、長、短、短）
菀：第十七格。粟剛才說的。這一系沒有別處的抄本。
燼：為什麼不早分出去？
菀：分過三次。離了這面牆的菌，到別處都長成別的東西。不是我們不肯，是牠不肯。
燼：（長、長、長、短）
菀：第二十六格。這一格其實不值錢，到處都有。我留著，是因為牠在的時候旁邊四格都不生病。
燼：登記上怎麼寫？
菀：寫「常見」。
```

到第三十格左右你不再問了。你只是把片貼上舌尖，讓拍子敲進來。三短一長。兩長。短長短長。你發現自己記得住——不是用腦子，是舌根自己在跟。

鍛站在門口，沒有進來，也沒有催。

後廊的舔聲沒有停過。

```
菀：第四十格。
燼：（長、短、短）
菀：第四十一格。最後一個。這個是——
```

水鐘響了。就在外面，很近，整個龕室的匣水都跟著起了一圈細紋。菀的話被蓋過去。你把最後一片貼上舌尖的時候，鐘的餘音還在牙根裡震。

〔玩法註：第四十一段拍子**與鐘聲同時播放**，畫面不顯示長短符號，也不要求玩家跟按。它確實播了。玩家聽過。〕

```
鍛：一刻到了。
燼：……
鍛：燼。
```

你轉過身。四十一扇門開著，四十一匣淡青的水，燈火黃黃地照在上面。

- **向度**：無（抉擇 A 的差異記入旁註）。**時間：18 分**

### SF1-07〈再一個潮次〉（全文）

- **地點／時段**：龕室門口 → 上層。漲潮過半。風從背後來，往內海，穩。站池是青的，鐘管草只有一株在單音。站在這裡，看不出這是一座已經被判掉的站。
- **出場**：燼、鍛、菀、鑄、烽、焙、荻、粟。

```
鍛：登記完了。菀站長，帶人走。焙，去夾點。
菀：（對站員）走。
```

沒有人動得很快。荻的手還放在一只活匣上。

```
燼：隊長。
鍛：說。
燼：風。烽，風怎麼樣？
烽：往內海，穩。我從到這裡讀了八回。潮轉前不會變。
燼：窪裡的氣？
鑄：坐著。風不換邊它不動。地面上隔著土梁，過不來。
燼：試片？
焙：站這邊，黃。沒到褐。
燼：站長。四十一系整套搬，要多久？
菀：（很慢）你問這個做什麼。
燼：要多久。
菀：九個人，渠裡有水，一個潮次。——我沒有求你。我說了空手走。
燼：我知道妳沒有求。
```

> **抉擇 B（第二次：玩家親口說出來）**
>
> - 〔「再一個潮次。搬得完。」〕
> - 〔「半個潮次。搬最要緊的。」〕——菀：「半個潮次搬不了活的，只會搬出死的。要嘛空手，要嘛整個潮次。」→ 選項重新出現，只剩第一項與灰色項。
> - 〔「照判。現在切。」〕*（灰色）*——**「四十一扇門開著。你看過了。你說不出口。」**

```
燼：再一個潮次。搬得完。
（沒有人說話。水鐘的鐘錘在風裡輕輕碰了一下鐘壁。）
鑄：五證得四，線已經判了。判了不切，是壞規矩。
燼：線沒有改。夾點沒有改。只改時辰。風穩，氣坐著，試片黃。一個潮次，九個人加我們五個，搬得完。搬完就切。
鑄：你是拿讀數在講，還是拿剛才看到的東西在講？
燼：……都有。
鑄：至少你老實。
菀：鍛隊長。我再說一次，免得日後有人記錯：站方沒有請求延後。
鍛：我聽見了。
```

鍛從內袋取出線冊，翻到今天這一頁。她寫字很慢，一筆一筆。

```
鍛：延後要記由。
（你看見她寫的字。）
燼：隊長，不是站方——
鍛：「站方請求延後，以撤出龕內種源。判線手同意。」
燼：是我說的。
鍛：判線手的名字，要留著判下一條線。冊上寫「判線手自請延後」，你下一條線，沒有人敢讓你判。
菀：（看了那一行）寫站方吧。我不介意。本來就是我的龕。
燼：這樣不對。
鍛：對不對，搬完再爭。——烽，上稜，風絮不離眼，一變就哨。鑄，灰備三倍。焙，夾點預夾，手不離夾。
鍛：燼。
燼：在。
鍛：你說搬得完。你下去搬。
```

- **向度**：選第一項 播 +1、錄 +1；先選第二項再回第一項 另加 焚 +1（旁註記錄：你試過把它縮短）。

### SF1-08〈你們切的是管〉

- **地點／時段**：種源渠與龕室之間。藍昏。歐柯落下去以後，站池邊的鐘管草花冠接手照明——亮了，但青光很薄；龕室門裡透出來的灰油燈光，反而比它黃、比它暖。
- **出場**：燼、菀、荻、粟、老磯；鍛（也在搬）。
- **目的**：玩家親手搬自己說「搬得完」的東西；菀與燼唯一一次長談。

- **玩法（浮匣）**：活匣連水四十斤，不能傾斜超過一掌、匣水不能濺（汲蟲會跟著水走）、渠岸每格只承兩人。一系往往不只一匣，要和牠的鄰格一起走。進度條以「系」計：○／41。本場結束時固定為 **11／41**——比玩家預期的慢。

```
菀：手放低。匣角不要碰壁，壁也是活的，會記仇。
燼：妳都這樣跟東西說話？
菀：我跟東西說話，跟你們說程序。兩種我都講得不好。
燼：十一系。照這個走法——
菀：照這個走法，一個潮次剛好。我說一個潮次，不是說有餘。
燼：妳說空手走的時候，就知道是剛好。
菀：我知道。「剛好」是不能拿九個人去賭的數。所以我說空手走。
燼：那我說搬的時候，妳為什麼不攔？
菀：（把一只匣推進水裡，看它浮穩）因為我守了牠們二十年。有人替我說出那句話，我沒有攔的力氣。這是我的錯處，不是你的。
燼：是我說的。
菀：是你說的。也是我沒攔的。兩件都是真的，日後不要只記一件。
（渠水很靜。一只匣漂過去，裡面的亮點聚在迎水的那一面。）
菀：你們來，看到的是一條管。病了，會傳，所以夾住，記座標。很清楚。
菀：我這邊不清楚。這一匣你看到種莢，對不對？還有蟲，還有水裡看不見的菌，還有牠跟隔壁那格長在一起時才會開的一種囊。我搬的不是種子，是牠們之間的關係。關係沒辦法裝匣，只能整段端走。所以慢。
燼：最後那一格。妳說牠是什麼，鐘蓋過去了。
菀：第四十一？（笑了一下，很累的那種）等搬到那一格，我指給你看。用說的說不清楚。
```

〔若玩家往後廊走：舔泉獸抬頭看了一眼，回去舔。老磯：「不用管牠。龕水槽的殼一個鐘長一層，牠不舔，水進不了龕。牠比我們九個都準時。」〕

- **時間：14 分**

### SF1-09〈第一個鐘〉

- **地點／時段**：灰衡台 → 稜線。長夜。水鐘敲了第一鐘。乾霧沒有來，空氣清得看得見稜線上每一塊石頭的邊。進度 **19／41**。
- **出場**：燼、鑄、烽、鍛、焙（夾點換班）。
- **目的**：喘息；鑄的劑量課、烽的第二課；第三次「等」。五人最後一次同場。

```
鑄：手。壞習慣那隻。你用順手撒灰，我看到了。
燼：順手順。
鑄：順的手容易多給。（把銅匙放在你掌上，按住手腕）刮。再刮。停。這是一錢。記住匙面平的時候手腕的角度。
燼：你每一匙都這樣量？
鑄：十九年，每一匙。灰救得了一小段脈，也堵得死一小段脈。差別不在灰，在量的人那一下有沒有刮平。
燼：我今天沒有刮平。
鑄：你今天多給了一個潮次。多了沒有，要潮水說，不是我說。
```

```
烽：（稜上）風穩得讓人想睡。第二課：看到那片紅的沒有。
燼：燼冠。下午是一株。
烽：現在是一片。它發熱，熱會自己造一點貼地的風，風絮讀不到，要用腳踝。——還有，你下午在下池跟那個老人家說，沒切以前每個早上放濾幕東角？
燼：說了。
烽：我們是來切脈的。
燼：還沒切以前，它是活的。
烽：（看了你一會兒）這句你留著。別讓這行把它磨掉。
```

回到站上。十九系在渠裡，二十二系還在牆上，門都開著。鍛把你叫到水鐘下。

```
鍛：第一鐘。十九。照這個數，第三鐘前搬不完四十一。
燼：差三、四系。
鍛：你說搬得完。
燼：……加快。
鍛：活土不能加快。你自己排過撤離線。
```

> **抉擇 C（第三次）**
>
> - 〔照原訂，搬到完〕「人手輪換，不停。差的三、四系，最後一刻再看。」
> - 〔只搬只存於此的〕「改。剩下二十二系裡，只有九系別處沒有。先搬那九系，其餘放棄。第二鐘後就能切。」

```
（選〔只搬只存於此的〕）
菀：（聽完，點頭）九系。十七、九跟十、三十一到三十四、三十八，還有四十一。這個單子我閉著眼都開得出來。
菀：其他十三系，我去跟牠們說。
燼：說什麼？
菀：說對不起，說別處還有你們。——第二鐘後收工。

（選〔照原訂〕）
菀：那就不要停。荻，換手。粟，妳去睡半個鐘。
粟：我不睡。
菀：妳十六歲。去睡。
```

〔兩線都在第二鐘時仍有人在龕室深處。差別只記入旁註。若 SF1-04 答應了老茨：鍛看了看天色，「晨霧前。你答應人家的。去放，放完回來。」〕

- **向度**：照原訂 播 +1；只搬九系 焚 +1。**時間：12 分**

### SF1-10〈第二個鐘〉（轉折，全文）

- **地點／時段**：渠邊（或下池濾幕東角，依 SF1-04）。長夜將盡。水位尺的最高刻痕濕了，站池滿得發亮，鐘管草的花冠全開——這是兩天裡最像健康的一刻。
- **出場**：燼；烽（稜上）；其餘人在龕室與渠之間。

你把一只匣推進渠裡，直起腰。（或：你把濾幕的東角放下來，薄薄的孢霧在暗裡亮了一下。）

水鐘響了。第二鐘。

你下意識數了一下：二十九系。（或：九系裡的七系。）再一鐘。差一點——真的差一點就搬得完。

鐘的餘音還沒散，你的後頸不涼了。

不是變熱。是沒有了。推了你一整夜的那隻手，從背上拿開了。

> **〔計時事件：七口氣〕** 畫面不出現任何提示。只有垂下來的風絮、呼吸聲，與指令欄。
> 可用指令：**讀風**（再讀一次，耗兩口氣；試片仍是黃——它還沒寫上去）／**喊**。
> 沒有「等」的按鈕。但什麼都不按，就是等。

```
燼：風停——！風停了！龕室裡的人上來！全部上來！
烽：（稜上，哨：三長）
```

你的聲音在窪裡撞了一下。然後你聽見另一件事：你聽見自己的回音。

你聽得見回音，是因為別的聲音沒有了。鐘管草不喘了。一株都不喘了，像有人把手掌按在所有管口上。

風回頭了。從內海來，推在你臉上，是溫的。

你舉竿。稜線那邊，坐氣窪的方向，你等著看白氣翻過土梁——

沒有。土梁上什麼都沒有。地面上什麼都沒有。試片：黃。

你有一口氣的時間以為沒事。

```
粟：（龕室裡，很遠，聲音是悶的）站長——燈。燈藍了。
```

你朝龕室的門看過去。門裡那排灰油燈，你看了一整夜，火苗是黃的、短的。

現在最靠地面的那一盞，火苗是藍的，而且拉得很長。往下拉。像在舔地上的什麼東西。

站柱上那張舊管圖。那條刻著「廢·乾」的細線，從上游的低處，通到站底。乾的管不走水。

乾的管走氣。

```
燼：出來——！！
```

〔畫面全白一格。沒有爆炸聲。聲音設計：一口很大的、往內吸的氣，然後是四十一匣水同時沸起來的細響。〕

- **固定結果**：無論第幾口氣喊，氣是從地下來的；風停之前它已經貼著龕室地面積了一層。喊得早，只多跑出來匣，沒有多跑出來人。
- **時間：14 分**

### SF1-11〈回去拉人〉

- **地點／時段**：站上層 → 龕室門。火不大——焚脈者都知道，硫氣的火是貼地的、藍的、安靜的；燒起來的是灰油，然後是龕壁。濾巾裡每一口氣都是臭的，三口以後就聞不到了。聞不到才要怕。
- **出場**：燼；鍛、烽、鑄、焙；菀與站員。
- **目的**：救援玩法；灼傷。玩家會用盡所有指令，然後不夠。

- **玩法**：從渠邊到龕室門十二格。每回合「氣」上升；**讀風**判斷哪一格是藍火前緣；**架隔離膜**替自己擋三回合；**燼灰中和**壓低前方一格的氣（撲不了火）。沿途的固定畫面，玩家只能經過：
  - 烽從稜上衝下來，比你先進門。沒有出來。
  - 鑄抱著整罐灰往門裡潑，潑完，坐下去，像在歇腳。灰罐還握在手裡，匙面是平的。
  - 焙從夾點跑回來——違了「手不離夾」——在門口架起最後一張膜，回頭喊：「燼！膜三回合！」
- 到門口時，膜只剩一回合。

```
（龕室。四十一扇門開著。火沿著地面走，一盞一盞地把燈接過去。）
燼：隊長！
鍛：（在第三格龕前，半跪，背上壓著一段塌下來的龕梁）這裡。
燼：（頂起梁）站長呢？
鍛：十七格。
（你看過去。菀在第十七格前面，側躺著，一隻手還托在匣底，往上托半寸的那個手勢。粟在她旁邊。她們都很安靜。）
燼：我去——
鍛：氣。看你的氣。
〔玩家可嘗試往第十七格走：每走一格，「氣」暴增，畫面邊緣發黑；走到第三格，鍛的聲音：「燼。退。」再走即昏厥，由鍛拖回——兩人都出不去的失敗畫面，然後退回本格。〕
燼：（把鍛拉上背）
鍛：退。封口。記座標。再爭。
燼：隊長，我——
鍛：再爭。先退。
```

你轉身的那一刻，門邊第一格龕的灰油燈座燒穿了。朝著那一格的那一側——臉頰、頸側、前臂、手掌——先是亮，然後沒有感覺，然後才是痛。你沒有鬆手。焙的膜在你們身後落下來。焙在膜的裡面。

後廊深處，那個規律的、濕的聲音還在。

- **時間：16 分**

### SF1-12〈夾〉（延遲的切除）

- **地點／時段**：主管夾點 → 上風稜線。破曉前到入夜。風從內海來，乾的。從稜線看下去，站還有形狀，龕室的門洞是暗紅的，一格一格。
- **出場**：燼、鍛。

```
鍛：（被放在上風處，呼吸裡有水聲）夾。
燼：隊長，妳的——
鍛：夾點沒有人。焙回來了。判了的線還沒切。去。
```

- **玩法（單手收夾）**：夾點預夾已掛。收夾原需雙手——壞的那一側握不住。玩家以好的那隻手與膝蓋分三段壓桿，每段之間「氣」與痛都在漲。沒有時限。收到底，管壁發出一聲很悶的響，下游試片在一刻之內由黃回白。
  **線守住了。晚了一個潮次。**

入夜。你回到稜線。鍛還醒著。

```
鍛：夾了？
燼：夾了。下游回白。
鍛：座標。
燼：站下游兩百步。判線手，燼。五證得四。……延後一個潮次。
鍛：線冊在我內袋。拿去。
燼：我要改那一行。
鍛：不准。
燼：是我說的。站長沒有求。她說了兩次。
鍛：我知道是你說的。菀也知道。知道的人夠了。冊子是給下一條線看的，不是給你贖的。
燼：下一條線我不會等。一口氣都不等。
鍛：（很久）……那也會死人。只是死在帳的另一邊，你看不到的那一邊。
燼：看不到的我不管。
鍛：你今天就是管了看得到的。
（風把她的濾巾吹開一角。你替她壓回去。壞的那隻手壓不住，換了一隻。）
鍛：燼。
燼：在。
鍛：四十一格。你都看了。
燼：看了。
鍛：那就要有人記得是什麼。帳冊燒了。……別的，再爭。
```

她沒有再爭。稜月升到最高的時候，你把線冊收進內袋，那一行字沒有動。

- **向度**：無。**時間：12 分**

### SF1-13〈我只說我秤過的〉

- **地點／時段**：冷卻後的淺龕站。三個潮次後。浮基塌了一半，龕牆是骨白的，四十一扇門都還開著，鉸縫裡結了連成一線的鹽霜。後廊最深的幾格燒合成一片硬殼，舔泉獸伏在殼前，還在舔。
- **出場**：燼、**硯**（首次登場）。
- **目的**：硯入場；分袋；打結——玩家發現龕室裡的拍子還在手上，除了一個。

```
硯：灰衡者，硯。調來秤的。秤龕灰，秤能認的東西，分袋。
燼：判線手，燼。
硯：我知道你是誰。紀錄我看過了。我只管我秤的，紀錄以外的事，你不用跟我說。
燼：……好。
硯：灰分不出誰是誰。我照龕位分，四十一格，四十一袋。只能照位置。人的另外分，能認的認。
燼：十三個。
硯：十三袋。那一隻呢。
燼：站上的。第十四個。牠還活著，不用袋子。不准趕。
硯：我是來秤的，不是來趕的。
```

- **玩法〈打結〉**：硯每秤完一格，把袋子遞來。玩家替繩打結——畫面不給提示，但手柄／按鍵會先輕輕震出那一格的拍子，玩家跟著打：長＝甜，短＝鹹。四十格，四十次，都震得出來。
  第四十一袋遞過來。**沒有震動。** 玩家可以等，可以亂按（結會自己鬆開）。等多久都沒有。

```
硯：這一條。
燼：（把一點龕灰放上舌頭。壞的那一側什麼都沒有。換到好的那一側：灰。只是灰。）
燼：……想不起來。鐘響的時候她正在說。
硯：那就空著。空著也是照實。
```

空龕口那片薄籤還在，燒捲了一角。你把它翻過來。日期是上一季。「寄存三件，已取。」站上沒有人在等這個人。這個人和這一夜無關。

你發現自己希望有關。你把籤繫回空龕上。

- **時間：12 分**

### SF1-14〈放不下去的那一袋〉（結尾，全文）

- **地點／時段**：龕牆下 → 上風稜線。藍昏。風是乾的，把乾霧吹薄了一點。舔聲沒有停。
- **出場**：燼、硯。

五十四只袋子。你沿著龕牆一只一只放下去，放在牠們原來那一格的正下方。壞的那一側彎不下去，所以每一只都是單膝跪著放的。

四十只有結。一只只有繩。

十三只有字。你放一只，唸一個。

```
燼：菀。荻。磯。粟。苧。芫。莒。葙。蕎。
燼：鍛。烽。鑄。焙。
```

硯站在三步外，沒有跟著唸，也沒有低頭。等你唸完，硯把秤布提起來，抖了抖。布上還有一層——每一格掃不乾淨、混在一起、分不出是哪一格的。

```
硯：掃剩的。秤不上去，帳記不進。照規矩撒回原地。
燼：給我。
硯：（看了你一眼，把秤布攤過來，然後轉過身去看別的地方）我沒秤過的，我不知道有。
```

你把那一小撮收進最後一塊氈裡，繫上繩。你想打一個結。哪一個拍子都不對——它是每一格，也哪一格都不是。

繩上沒有結。

你沿著牆走了一遍，想找個地方放它。四十一格前面都有袋子了。十三個名字前面也有。你站在空龕前，站了一會兒。

你把它收進內袋，貼著還有感覺的那一側。

```
硯：那一袋不放？
燼：不知道該放在誰前面。
硯：那就帶著。帶到知道為止。
（稜線。風。）
硯：這一組，現在幾個人。
燼：一個。
硯：一個不叫組。
燼：所以還沒有下一條線。
硯：有的。線不等人補齊。（把秤收進匣裡）我算東西很慢。每一匙都刮。
燼：我不會再等了。一口氣都不等。
硯：我聽說了。所以我來問缺不缺人。
燼：……為什麼。
硯：我算過。一個算得慢的，放在一個不敢再等的旁邊，剛好。
```

你沒有回答。硯也沒有等你回答，自己把匣子背上了。

```
燼：硯。
硯：嗯。
燼：以後每一條線，秤完掃剩的，我要。
硯：做什麼。
燼：繫一個結，放回線上。帳記得進去的，歸帳。記不進去的，要有地方放。
硯：結怎麼打。
燼：線裡有什麼我認得的，就打牠的拍子。
硯：認不得的呢。
燼：（手在內袋外面按了一下）認不得的，我已經有一袋了。
```

〔若 SF1-04 答應了老茨：最後一個畫面，你下到淺龕下池。池退到了底。你走到濾幕架前，把東角放下來。沒有孢霧。你還是放了。〕

〔切回縫林環夜營。火快熄了。你把今晚那只新袋子擱在線頭，短、短、長。內袋裡那一只沒有動。字卡：**〈焚脈者的悔〉完**〕

- **時間：10 分**

## 2. 主題與一句話

**一句話**：沒有人推我。每一步都有人接住我，所以我一直往前走。

**主題**：融不是騙局。它治好了菱的手、讓菱睡著、讓一座一個人撐不住的池多活了一季，後來又讓三百隻掌救起一整片黑水。
代價不是誰拿走的，是分攤的時候一起被攤薄的：痛、疲倦、然後是「這是我的」這件事本身。本篇不判定結尾是悲劇還是救贖——兩個結局都有人過得很好。

**脈況階段**：霧退（霧冠環）→ 流慢（燈沼環）。**環境母題**：
- **光**：霧冠是橙光裡退後的霧線；燈沼是黑水與燈蛾，光成了句子。
- **聲**：一個人刷水位尺的聲音 → 許多人同時呼吸的聲音。
- **味**：澀後回甜——菱的「岸味」。

**文體規則（實作與配音必守）**

| 階段 | 場次 | 人稱與句法 | 介面 |
|---|---|---|---|
| 我 | 01–04 | 「我」開頭的短句；所有格多（我的池、我的手） | 三條資源都標「我的」 |
| 我，有雜訊 | 05–07 | 仍是「我」；偶爾插入不屬於菱的記憶，菱會更正自己 | 「負荷」改標「我們的」（可逆） |
| 我們，偶爾我 | 08–11 | 主語漸漸省略；句子變長、用頓號並列；更正越來越慢 | 「體力」併入；說話者名牌由「菱」變「菱（我們）」 |
| 依結局 | 12–14 | 〔留一條〕回到短句，但「我」讀起來像外語；〔交出去〕全用「我們」，句子很長、很平 | 「記得」清單只剩一條／清空 |

## 4. 菱的指令組與資源

資源：**我的體力**／**我的負荷**（掌痛與失眠；滿即無法讀池）／**我的記得**（一張清單，開場七條；不是數值，是條目）。

| 指令 | 作用 | 變化 |
|---|---|---|
| **讀** | 用自己的掌心讀池；負荷大增 | 後期變灰：不是被禁，是「沒有人再單獨讀」 |
| **借** | 借匯流中他人的感受器讀遠處的池；零負荷，但讀值帶著那個人的口音 | 借得越遠，回來的句子越不像自己說的 |
| **分** | 把負荷分攤給同池的人 | 自 SF2-08 起自動發生 |
| **扛** | 替別人接一份痛；得到一小段對方的記憶 | 清單上出現不是「我的」的條目 |
| **遮** | 打遮味結：把清單上一條記憶留在岸上，不進池 | 緩融派的規矩；在大匯流池仍可用，但每個結都有重量 |
| **岸** | 說出岸味——退出暗號 | 永遠可按。SF2-10 會看到它被按下之後發生什麼 |

## 5. 場次

### SF2-01〈第三只杯〉（開場，全文）

- **地點／時段**：懸露池站。晨。霧線停在脈橋下面兩層，沒有上來。橙光直接照在池面上，太亮了，池不喜歡這樣。
- **出場**：菱。

我的池在漏。

不是漏水。水位尺第七刻，跟昨天一樣，我刷過了。漏的是別的東西。我把手放下去，掌心貼水，數到十。

先是鹹。我等苦。苦來得比上一旬早。

我把手抽出來，在膝上擦乾。掌心的紋裂了三道，昨天是兩道。我的手讀病水讀了一年多，它在用它的辦法告訴我夠了。

集露杯十二只，沿著橋索掛一排。第一只和第二只上個霧季就封了。今天早上第三只是乾的，杯底有一圈白。我把封膜拿出來，量好，貼上，壓邊。我的手很會做這個。這是我的手最近唯一越做越好的事。

封膜的時候我發現我在等一個聲音。

栒刷水位尺的時候會哼東西。同一句，哼了十一年，第三個音永遠低半個。我糾正過，栒說那是池教的，池的版本就是這樣。後來我不糾正了。後來濾幕壞了三天，栒在幕邊守了三天，孢霧進了肺。

現在水位尺是我刷。我不哼。

站上原本十四戶。霧退一層，搬走幾戶。現在是我，和橋那頭的老檗，檗的手也壞了，嫁接刀握不住。我們每天隔著橋互相露一下手腕：還在，還平。這樣就算問候過了。

我把第三只杯的封膜壓好，在池曆上寫：*杯三，封。苦早於上旬。掌，三道。*

寫完我看著「掌，三道」看了很久。池曆不是記這個的。我沒有劃掉。

> **介面教學**：畫面右側出現三條——**我的體力**（六成）、**我的負荷**（八成，紅）、**我的記得**（清單，七條，可展開）：
> ①栒哼錯的第三個音　②水位尺第七刻的缺口是我十九歲磕的　③池在藍昏會打一個嗝　④封第一只杯那天我沒哭　⑤老檗欠我一把刀　⑥我的岸味還沒有（空）　⑦這座池的名字不是「懸露」，是栒取的另一個，只有我們兩個叫
>
> **玩法**：晨間例行——刷尺、**讀**池（負荷 +15%，超過九成，畫面出現假味符：玩家讀到一個「焦」，再讀一次又沒有了）、封杯。
> 教玩家：一個人讀一座病池，讀值會開始騙你，而且沒有第二個人可以問。

```
老檗：（隔橋喊）菱！手！
菱：（舉腕）平！
老檗：騙人！你腕子我看不清，你掌心我可看見了，紅的！
菱：你的呢！
老檗：我的不紅了。我去了下索節。
菱：那個匯流室？
老檗：去了三回。你罵我吧。
菱：……我沒力氣罵。有用嗎？
老檗：我昨天握住刀了。
```

- **時間：10 分**

### SF2-02〈掌背，不是掌心〉

- **地點／時段**：下索節匯流室。藍昏。一間掛在兩條橋索之間的膜室，中間一池溫水，水面有很細的青光順著一個方向走。六個岸位，坐了四個人，沒有人說話，呼吸是齊的。空氣裡什麼味都沒有——有人把味遮得很乾淨。
- **出場**：菱、澄、老檗、匯流室常客（年輕霧濾師**霏**等）。
- **目的**：第一次接。可逆、局部、真的有用。

```
澄：先看手腕，再碰手背。這裡的規矩跟外面一樣，一樣都不少。
菱：我只是來看看。
澄：看看最好。坐岸位，腳不用下水。我說規矩，你聽完可以走，走了下回再來也行。
澄：一，根絲只接掌背，不接掌心。掌心是你讀世界的地方，那裡我們不碰。
澄：二，一條根絲一個潮次，到時候它自己鬆。不用誰同意，它就是會鬆。
澄：三，你有不想放進池裡的東西，先打遮味結，留在岸上。我教你打。沒有人會問結裡是什麼。
澄：四，每個人取一個岸味。你在池裡任何時候放出那個味，整池的人把手抽開。不問為什麼。
菱：有人放過嗎？
霏：我。第一回，半刻就放了。大家抽手，澄給我一杯沖洗液，我回家睡覺，隔天又來。
菱：為什麼又來？
霏：因為我放了，他們真的抽手了。
澄：你的岸味要自己選。選一個你不會不小心發出來的。
```

> **抉擇（小）：岸味**——〔澀後回甜〕（預設；栒醃的池梅是這個味）／〔自訂：三味符任排〕。之後全篇以此為準。清單⑥填上。
> **玩法**：打遮味結教學——從清單選至多三條留在岸上。系統建議①與⑦。玩家可以一條都不遮。

根絲搭上掌背的時候是涼的，像有人把一片濕葉子放在那裡。然後——

我的手不痛了。

不是麻。痛還在，我找得到它，可是它不只在我手上了。它像一池水倒進六只杯，每一只都只有一點點。坐我對面那個我不認識的人皺了一下眉，然後對我點點頭：收到了。

我一年多來第一次把手掌整個攤開。

```
菱：……你們每個人都分到了？
老檗：分到了。你那手真夠嗆。
菱：對不起。
霏：不用。上一旬是我的肺，你明天就會分到我的。
澄：這不是施捨，菱。這是輪流。
```

那一夜我在岸位上睡著了。沒有夢到濾幕。

> **介面**：「我的負荷」由八成降到兩成，標籤短暫閃成「我們的負荷」，一個潮次後變回「我的」，數值回到五成——沒有回到八成。
- **向度**：融 +1。**時間：14 分**

### SF2-03〈借來的舌頭〉

- **地點／時段**：懸露池站 ↔ 匯流室。清季。霧線又退了一層；匯流室的人第一次上到我的站來，橋板在他們腳下回彈，他們走得很小心，一格兩人。
- **出場**：菱、霏、老檗、澄。
- **目的**：「借」的教學；融帶來的不只是鎮痛，是能力——一個人做不到的診斷。

- **玩法**：菱的池苦味來自下游某處回滲，一個人沿橋索逐池**讀**下去要三天、負荷必爆。改用**借**：霏坐在下游第四池、老檗在第七池，各接一條根絲，菱在自己的站上同時「嚐」到三處。
  三段味序並排顯示，玩家比對到達順序，定位回滲點在第五、第六池之間的一段橋腹導管。借來的讀值帶口音：霏的鹹偏金屬、老檗的苦會拖尾——玩家要學會扣掉口音。

```
菱：第四池先鹹後苦。第七池……只有苦，沒有鹹。那鹹是在中間丟掉的。
霏：（從很遠的地方，聲音卻在我手背上）你剛才用的是我的舌頭欸。感覺怎樣？
菱：你早上吃了太鹹的菌餅。
霏：（笑）被發現了。
老檗：五跟六中間那段橋腹，我年輕時嫁過一個接口。我帶刀去。我現在握得住刀了。
```

三個人，一把刀，一匙靛乳，半個潮次。回滲停了。我的池在藍昏打了一個嗝，跟以前一樣。

我在池曆上寫：*苦退。五六間舊接口重嫁。*我想了一下，在後面加了三個名字。池曆以前只有我跟栒的字。

```
澄：池站是你的，菱。我們只是借手給你。
菱：我知道。
澄：我說這句是因為有人會忘。借久了，會分不清哪隻手是自己的。到那時候你跟我說。
菱：到那時候我分得清要跟你說嗎？
澄：（沒有馬上回答）……這是個好問題。我沒有好答案。所以才有岸味。
```

- **向度**：播 +1（修復）、融 +1。**時間：16 分**

### SF2-04〈輪到我〉

- **地點／時段**：匯流室。霧季初，難得起了一場真的霧，膜室外面白成一片，裡面的青光顯得更暖。
- **出場**：菱、老檗、霏、澄。
- **目的**：「扛」——互惠；第一段不屬於菱的記憶。

- **玩法**：老檗的手痛發作。菱選擇**扛**（或讓別人扛——但輪到菱了）。扛的份量可選一成／三成／五成。扛得越多，回來的東西越多。

我接了三成。老檗的痛跟我的不一樣，我的是裂，檗的是鈍，像握了一輩子刀柄的那種鈍。它進來，坐下，沒有很難受。

然後我想起靛丘的清季，丘坡上的色素礦在太陽下會有一種乾的甜味。

我沒有去過靛丘。

```
菱：檗。你去過靛丘？
老檗：十六歲，學嫁接。怎麼？
菱：坡上的礦，曬過以後是甜的。
老檗：（愣住，然後笑得很慢）……我四十年沒想起那個味了。你替我想起來了。
菱：它現在也在我這邊了。
老檗：那好。我這邊快放不住了，你那邊替我留一份。
```

> **介面**：清單出現第⑧條：**靛丘的礦曬過是甜的**——標籤不是「我的」，是一個小小的「檗」。
> 玩家可展開清單，看到七條「我的」與一條「檗」排在一起，字體一模一樣。

那一晚回站，我刷水位尺的時候覺得坡上應該有礦。我的站沒有坡。我站了一會兒才把這件事放回它該在的地方。

沒有不舒服。老實說，有點像家裡多了一個人。

- **向度**：融 +1。**時間：12 分**

### SF2-05〈封池〉

- **地點／時段**：懸露池站。霧季——名義上的。霧線退到橋下四層，再沒有回來。水位尺露出了第一刻以下從來沒人見過的那一段，上面沒有刻痕，因為沒有人想過要刻到那裡。
- **出場**：菱、澄、霏、老檗、種源護送者（過場）。
- **目的**：失去。融在這裡做了它最好的一件事：讓一個人不必獨自封掉自己的池。

- **玩法**：封池程序（池守的本行，玩家已熟）——清龕、把種源交給護送者、放乾殘水前讓最後一隻潾者離池、收濾幕、封十二只杯裡剩下的九只。每一步都可以自己做（耗「我的體力」）或讓同池的人**分**。分到第三步時，負荷條的標籤從「我的」變成「我們的」，這次沒有變回來。

```
菱：第十二只我自己封。
霏：好。我們在這。
（我量膜，貼上，壓邊。我的手很穩。六個人的手都很穩。）
菱：……我哭的時候你們是不是都——
老檗：都濕了。六雙眼睛。你只要哭六分之一就夠了，剩下的我們哭掉了。
菱：這樣對嗎？這是我的池。
澄：是你的池。我們哭的是你的池。
菱：栒要是在，會說我偷懶。
澄：栒是誰？
（我發現我沒有跟他們任何人說過栒。那一條一直打著結。）
菱：……以前跟我一起守站的人。
澄：（點頭，沒有再問）
```

我在池曆最後一頁寫：*池，封。*然後我寫了那個只有兩個人叫的名字。然後我把池曆闔上，沒有交給護送者，放進自己懷裡。

那天晚上我沒有回站。沒有站可以回了。匯流室有第七個岸位，本來是空的。

> **文體開始變化**：自此場起，旁白偶爾出現不屬於菱的句子，菱會更正——「我十六歲學嫁接的時候——不，那是檗。」
- **向度**：融 +1、錄 +1（池曆留存）。**時間：14 分**

### SF2-06〈門沒有鎖〉

- **地點／時段**：下索節匯流室。清季。來了一位客人，身上有長夜濕地的味道：黑水、花蜜、一點點燈蛾翼粉。
- **出場**：菱、澄、霏、老檗；**煦**（燈沼環同息埠的穹流派接引者）。
- **目的**：兩派的差異由兩個好人說出來。沒有人招募，沒有人挽留。

```
煦：我不是來帶人的。我是路過，聽說這裡有一池緩融的，來露個手腕。
澄：歡迎。岸位坐。
煦：（看池）六個人。七個。掌背。一個潮次自己鬆。
澄：是。
煦：很乾淨。我以前也在這樣的池裡坐過。
澄：後來呢？
煦：後來我們那一環的霧退到底了。六個人分得了一個人的手痛，分不了一整環的霧。我往下走，走到同息埠。那裡的池有三百隻掌。
霏：三百？
煦：三百隻掌同時讀一片濕地。哪一池先苦、苦往哪裡走、哪裡還來得及，一口氣就知道。你們修一段橋腹要三個人半個潮次，我們那裡是呼吸一次。
菱：（我聽見自己問）根絲接哪裡？
煦：岸位接掌背，跟這裡一樣。再往裡，接掌心。最裡面接頸側。沒有人會叫你往裡。
菱：會自己鬆嗎？
煦：不會自己鬆。你想走的時候，站起來，走。門沒有鎖。
澄：沒有岸味。
煦：三百個人，記不了三百個味。也不需要——誰難受，整池都知道，整池一起讓他好起來。
澄：「讓他好起來」跟「讓他走」不是同一件事。
煦：（很溫和）對。不是同一件事。我們覺得前一件比較好。你們覺得後一件比較要緊。我不覺得誰錯。
```

煦住了一夜就走了。走之前跟每個人碰了手背，碰到我的時候說：你的手以前很痛。現在是我們的了，你知道嗎，連我都分到一點。

我知道。我分不出那是安慰還是別的。

```
菱：澄。我想去看看。
澄：我知道你會想。你的池沒有了，這裡七個人裡面，你是唯一沒有站要回的。
菱：你不攔我？
澄：我不留你，也不送你。我只做一件事：你的岸味，我替你記著。澀後回甜。
菱：那裡用不到。
澄：用不到最好。
```

> **抉擇**：〔去同息埠〕（主線推進）。玩家可先在匯流室多留幾個潮次（自由活動；老檗還了那把刀——清單⑤劃掉，變成「檗還了刀」）。
- **時間：12 分**

### SF2-07〈下行〉

- **地點／時段**：霧冠→燈沼的水路。長夜。水是黑的，看不見底，只看得見燈蛾——牠們不是亂飛，是一段一段地亮，像有人在遠處慢慢說話。
- **出場**：菱、霏（同行）、一隊往同息埠的旅人。
- **目的**：借眼導航；「我」開始打滑。

- **玩法**：池舟夜行。菱不懂燈蛾光語；同舟有一位燈沼出身的旅人。全舟以一條長根絲相連（掌背），菱**借**那位旅人的眼睛，光點就成了句子：〈此路淺〉〈病紅，繞〉〈花在左〉。借的時候畫面色調偏向對方的習慣——更青、更低。

舟尾有人在咳，我們把那口氣分了，他就不咳了。有人餓，剛吃過的人把飽分過去一點。我看見左前方的燈蛾在說〈繞〉——

不是我看見的。是船頭那個人看見的。我的眼睛只看見一團光。

我更正了。更正花了大概一口氣的時間。上個月更正不用時間。

霏靠在我旁邊睡著了。霏夢見濾幕，一張很大的、完好的濾幕，孢霧穿過去的時候會響。我也夢見了。醒來我想：這是我這兩個霧季以來，第一次夢見沒有壞的濾幕。

是霏的夢。我知道。我還是很感謝。

- **向度**：融 +1。**時間：12 分**

### SF2-08〈同息〉

- **地點／時段**：同息埠·大匯流池。藍昏不分晝夜。一座淺而廣的黑水池，池緣是活的，溫的；三百個人或坐或半躺，從岸位一圈一圈往裡。根絲在水下亮著極淡的青，像一張攤開的葉脈。整座池在呼吸，是真的在呼吸：三百個胸口，一起，一落。
- **出場**：菱、霏、煦；穹母〔眾聲〕。
- **目的**：深匯流的好處，全部是真的。穹母第一次出現。

```
煦：岸位。掌背。跟你們那裡一樣。坐多久都行，不想往裡就不往裡。
菱：往裡是什麼感覺？
煦：我說不出來。不是我嘴笨，是往裡以後「我說」這件事變得不太準。你坐著就知道一點。
```

根絲搭上掌背。

先是飽。我一整天沒吃東西，可是三百個人裡總有人剛吃過，那個飽像溫水一樣漫過來。然後是暖。然後是我的手——我已經很久沒有想起我的手了——這一次連「找得到的痛」都找不到了。

然後是安靜。不是沒有聲音。是三百個人的擔心加起來除以三百，每個人只剩下一點點，那一點點輕得可以放在水面上漂。

```
穹母〔眾聲〕：（不是從哪一個方向來的。是坐我左邊的老人說了第一個詞，池對面的孩子接了第二個，中間有一個音不是人的喉嚨發的）
穹母〔眾聲〕：妳——你——守過一座池。
菱：……是。
穹母〔眾聲〕：我們知道封杯的手勢了。剛才。從你的手背。謝謝。南岸有十一只杯該封了，我們一直壓不好邊。
菱：我可以教——
穹母〔眾聲〕：不用教。已經會了。
（池的另一邊，我看不見的地方，四十個人同時抬起手，做了一個量膜、貼上、壓邊的動作。是我的手勢。連我壓邊時小指會翹起來都一樣。）
穹母〔眾聲〕：你的池沒有白守。它現在在三百雙手裡。
```

我哭了。我只需要哭三百分之一。

> **介面**：「我的體力」併入一條很長的「我們的體力」，菱的那一段只是其中一小格，會亮。說話者名牌變為 **菱（我們）**。
> 清單一次多了十幾條別人的記得，字體與「我的」完全相同；「我的」七條旁邊的小標籤開始變淡。**遮**住的條目仍清楚。
- **抉擇**：位置——〔留在岸位〕／〔往裡一圈，接掌心〕。兩者都可；接掌心者，SF2-09 的作業更順、清單上「我的」標籤淡得更快。
- **向度**：融 +1（接掌心再 +1）。**時間：14 分**

### SF2-09〈三百隻掌〉

- **地點／時段**：同息埠外·病黑水池群。長夜。九座相連的黑水池，其中三座的螢光花過亮——那是霧退後花在喊，不是花在開。一隻潾者困在第六池，背冠的光收得很小。
- **出場**：菱（我們）、霏、煦、匯流者們；潾者一隻。
- **目的**：集體真的做到了個體做不到的事。這是本篇裡融最光彩的一刻，必須寫得讓玩家服氣。

- **玩法**：全景診療。不再是單一味序，而是九座池的九條味序**同時**展開在畫面上——三百隻掌各讀一小段。玩家的指令變成調度：把「讀得準的人」移到訊號最亂的池、把負荷超標的人換下來（**分**是自動的，玩家只需看那條很長的共用條不要見紅）、指定四十雙手同時**封杯**以截住回滲。
  一個人要做一旬的事，在這裡是半個潮次。第六池的水路重開，潾者滑出去，背冠亮了一下。

我們找到苦是從第三池來的、往第六池去、在第五池的彎道丟了鹹。我們封了十一只杯，手勢是懸露池站的手勢。我們把潾者困住的那道淤口清開了，清的時候四個人的手一起下去，沒有人覺得冷，因為冷分掉了。

牠滑出去的時候，從我們身邊過，停了一下。牠的光打了一個我們之中有人讀得懂的拍子。那個人懂，所以我們懂：〈謝〉，然後是另一個拍子，短，重複了兩次。

懂的那個人遲疑了。我們感覺到那個遲疑，像水裡一塊比較涼的地方。

```
菱（我們）：牠第二句說什麼？
煦：（在池的另一邊，但聲音在手背上）牠說……〈太多〉。或者〈太近〉。潾者的詞，我們翻不準。
菱（我們）：牠不舒服？
煦：牠出去了。牠現在很好。我們救了牠。
```

這是真的。我們救了牠。九座池裡六座的光回到該有的亮度。我——我們——很久沒有把一件事做得這麼好了。

那塊比較涼的地方，一口氣以後就不涼了。分掉了。

- **向度**：播 +1（修復）、融 +1。**時間：14 分**

### SF2-10〈哼對了〉（轉折，全文）

- **地點／時段**：大匯流池。長夜裡不知道第幾個藍昏。池面平，三百個胸口一起一落。南岸有人在封杯。
- **出場**：菱（我們）、匯流者們、煦。

我們在南岸封杯。四十雙手，量膜，貼上，壓邊。壓邊的時候手會跟著一個拍子走——壓，壓，停，壓——我們不知道這個拍子從哪裡來，只知道跟著它邊會壓得很平。

池對面有一個人把拍子哼了出來。

很輕。一句。四個音。

我們覺得好聽。我們之中有很多人小時候聽過這一句，是霧冠那一帶哄池的老調子。有人跟著哼，然後更多人。三百個喉嚨，同一句，很準。

第三個音很準。

我

我停下來。

我的手還在壓邊，我叫它停，它慢了一拍才停。

第三個音不是那樣的。第三個音要低半個。低半個才對。不對——低半個是錯的，栒哼的是錯的，我糾正過，栒說那是池教的。

池裡沒有人見過栒。那一條我打著結，結沒有鬆，我檢查了，結好好的。漏出去的不是結裡的東西。是我的手。我的手聽了十一年，壓邊的時候自己帶著那個拍子，拍子進了四十雙手，有人替它填上了音。填的是對的音。是大家都記得的那個版本。

三百個人在哼栒的調子，哼得比栒好。

我想走。

> **〔指令欄只亮一個鍵：岸〕**

我放出我的岸味。澀，然後回甜。栒醃的池梅。

在下索節，這個味一出來，六隻手會同時抽開。

這裡有三百個人。澀到了他們那裡。坐我左邊的老人輕輕「啊」了一聲，池對面的孩子皺了一下眉——有人在澀。整池都知道了。整池做了他們一向做的事，做得很溫柔、很快：把它分掉。

我的澀除以三百。

然後回甜到了。回甜也是我放的，它是岸味的後半。三百個人嚐到甜，鬆了一口氣：好了，那個人好一點了。

```
匯流者（左）：剛才誰在澀？
匯流者（遠）：不知道。過去了。
匯流者（孩子）：後面是甜的。好好吃。
煦：（手背上的聲音）菱？是你嗎？還難受嗎？
```

我想說是我、我不是難受、我是要走。這句話在我嘴裡的時候還是我的。它離開嘴，進到水裡，就變成一件大家一起擔心的事，然後變成一件大家一起擔心過的事。

沒有人按住我。我的腿是我的。根絲在掌背——我接了掌心的話，在掌心——拔掉就好。門沒有鎖。

> **〔長按：拔掉根絲〕**
> 按住期間，提示文字每兩口氣改寫一次，玩家**沒有放開**它也會變：
> 「拔掉根絲」→「我想拔掉根絲」→「我們之中有人想拔掉根絲」→「我們之中有一點想走，像一池水裡的一滴澀」→「好一點了」
> 平靜一波一波地來。不是誰送來的。是三百個人此刻本來就有的平靜，照例分了我一份。

我為什麼要走。

因為第三個音。

第三個音怎麼了。它很準。

它不該準。

為什麼不該。

因為——

因為有一個人，哼了十一年，低半個。

（那個人我們沒見過。那個人聽起來很好。我們也想記得那個人。可以嗎。）

> **放開按鍵（多數玩家會在這裡放開，或發現自己已經放開）**

手停在根絲上。沒有拔。我們坐回去。南岸還有三只杯沒封，拍子還在，壓，壓，停，壓。我們覺得剛才好像有什麼事，像夢快醒的時候抓著的那個東西。澀後回甜。很好吃。

> **按到底（少數玩家）**

根絲離開掌背的時候沒有聲音。

我的手痛回來了。全部。一年半的份一次回來，我跪了下去。飽沒有了，暖沒有了，三百分之一的安靜變回一個人的吵。我爬到門邊。門真的沒有鎖。門外是黑水，燈蛾在說我看不懂的話，我沒有眼睛可以借。

我沒有池可以回。

```
煦：（走過來，蹲下，遞一杯味覺沖洗液。沒有碰我）要走的話，我送你到舟邊。天亮有一班往霧冠的。
菱：……霧冠沒有霧了。
煦：我知道。要坐回去也行。不坐也行。門邊這塊地是乾的，你坐多久都可以，我叫人送餅來。
菱：你們把栒哼對了。
煦：栒是誰？
（我張開嘴。我記得我很生氣。我記得是為了一個音。我花了三口氣才想起來是哪一個音。上個月不用。）
```

> 兩條路線都接 SF2-11。〔放開〕者名牌維持「菱（我們）」，清單上「我的」標籤全部淡去，只剩打結的條目清楚；
> 〔按到底〕者名牌變回「菱」，獨坐門邊，負荷紅、體力低，清單不變——但第⑧條以後那些別人的記得也還在，拿不掉。
- **向度**：放開 融 +1；按到底 錄 +1。**時間：16 分**

### SF2-11〈我替你記著的〉

- **地點／時段**：大匯流池岸邊／門邊。主線第 6 章期間。黑水上起了一點真的霧，燈蛾的句子變短了。
- **出場**：菱、**澄**（自霧冠來訪）、霏（已在深位，只以水紋出現）。
- **目的**：緩融派的規矩在這裡還剩什麼；澄不是救兵。

```
澄：菱。
菱（我們）：……澄。你怎麼會——
澄：下索節的池上個月封了。霧退到索底。七個人散了，檗託我帶話：刀很好用。
澄：我來同息埠看看。我還沒有往裡坐。我在岸上走了三圈，才找到你。你坐的地方不一樣了。
菱（我們）：我們在這裡很好。
澄：我相信。我是來還一樣東西。（在我面前蹲下，沒有接根絲，只是開口說）澀，後面回甜。
（那個味沒有進水。它是用說的。它只到我這裡。）
澄：你的岸味。我說過替你記著。幾個藍昏以前，我在來的舟上嚐到它——很淡，淡到我以為是誰在吃池梅。然後我想：那是有人在放岸味，放在一個沒有人會抽手的地方。
菱：……是我。
澄：我知道。所以我現在抽手。（把雙手從膝上拿開，掌背朝上，放在我看得見的地方）一個人抽，算不了什麼。規矩是這樣寫的，我照做。
菱：遲了。
澄：遲了。而且我只有一雙手。我不跟你說這樣就夠。
菱：你要帶我回去？
澄：回哪裡？下索節沒有池了。我可以陪你坐到你知道自己要什麼。這個我會，別的我不會。
菱：他們沒有做錯事，澄。他們救了九座池裡的六座。他們把我的手治好了。
澄：我知道。我的池做不到。這就是我睡不著的地方。
```

> **玩法**：澄陪坐。玩家可展開清單，一條一條「認」——每點一條，菱說出它是誰的。認對（是我的／是檗的／是霏的）標籤變清楚；認錯或答不出，標籤維持淡。這不是測驗，沒有分數；但玩家會發現自己也記不清第⑪條以後是誰的了。
- **時間：12 分**

### SF2-12〈重量〉

- **地點／時段**：大匯流池。靜潮——三月互抵，池面平得像沒有水。三百個呼吸放得很慢。
- **出場**：菱、穹母〔眾聲〕；澄（岸上，聽）。
- **目的**：穹母第二次出現。不威脅、不索取，只說事實。

```
穹母〔眾聲〕：池裡有一顆石頭。
菱：是我的結。
穹母〔眾聲〕：是。我們不知道裡面是什麼。我們不會拿。打結的人自己不解，沒有誰解得開。這一點緩融的人教得對。
菱：那為什麼說它？
穹母〔眾聲〕：因為你該知道它多重。水繞過石頭。繞過去的地方，我們分不到你，你也分不到我們。你那一格裡的痛，只有你。你那一格裡的冷，只有你。三百個人裡，你是唯一還會獨自醒來的。
穹母〔眾聲〕：我們難受。不是氣你。是水裡有一塊地方，我們伸手，沒有人接。
菱：交出來以後，它會變。
穹母〔眾聲〕：（停頓。這一次是很多個聲音各自想了一下）會。我們不騙你。兩個版本放不進同一池水，水會把它們調成一個。調出來的那一個，三百個人都會記得，記得很久，比一個人能記的久得多。
菱：調出來的那一個是準的。
穹母〔眾聲〕：是準的。
菱：我要的是不準的那個。
穹母〔眾聲〕：我們知道。我們給不了。我們只能告訴你：留著它，你會一直有一點痛、一點冷，坐在岸位，往裡不了。沒有人會趕你。門沒有鎖，岸也沒有鎖。
澄：（岸上，很輕）這是我聽過最誠實的勸說。我還是不喜歡它。
穹母〔眾聲〕：澄。我們記得妳——你——坐過岸位。你的結還在。我們也沒有拿。
```

- **時間：10 分**

### SF2-13〈最後一條〉

- **地點／時段**：大匯流池岸位。靜潮將盡。池面開始有最細的紋。
- **出場**：菱、澄。
- **目的**：最後的抉擇——是否保留一段私人記憶。保留有代價，交出也有。

清單現在很長。大部分我已經說不出是誰的，也不太需要說。它們都很好：靛丘曬過的礦、一張完好的濾幕、某個人第一次握住嫁接刀、南岸的十一只杯。

只有一條的標籤還清楚。**①栒哼錯的第三個音。**

〔若玩家全篇從未打過遮味結：此條此時自動浮現為清楚——「不是我遮的。是它一直對不上池裡的那個版本，所以進不去。」穹母稱之為石頭，道理相同。〕

```
澄：我明天回霧冠。還有兩個小池沒封，有人要我去看。
菱：你不勸我？
澄：我勸過的人，後來有的謝我，有的恨我。現在我只把規矩說完整：結是你的。解不解，沒有對錯，只有你要哪一種日子。
菱：你呢。你的結裡是什麼？
澄：（笑）那就是結的意思。
```

> **最後抉擇**
>
> **〔留一條〕** 把①留在岸上。
> 代價（選前明示）：「我的負荷」會以一小格的形式永久回到介面上，只屬於菱，無人分攤；菱留在岸位，不能往裡；池裡關於封杯的那個拍子仍會被哼成準的，菱每次聽見都會知道。
>
> **〔解開〕** 讓①進池。
> 代價（選前明示）：一個潮次之內，第三個音會變準——在所有人那裡，也在菱這裡；清單不再分「我的」；說話者名牌改為 **我們**。這一項**不可逆**，系統要求長按，長按期間沒有任何文字改寫。

- **向度**：留一條 錄 +1、播 +1；解開 融 +2。**時間：12 分**

### SF2-14〈尾聲〉（結尾，兩版全文）

- **地點／時段**：大匯流池。之後的某一個藍昏。

**〔留一條〕版**

我坐岸位。

我的手有一點痛。一小格。早上最痛，藍昏好一些。沒有人分它。我試過分出去，它不走，它跟結綁在一起。

南岸在封杯。他們哼那一句。準的。我聽。我在心裡把第三個音往下按半個。按得住。目前按得住。

霏在深位。霏不上岸了。有時候水面有一道紋朝我這邊來，我把手背放進水裡，紋碰到我，停一下。我不知道那還算不算霏。我當它是。

澄走了。走之前碰了我的手背。澄說：你現在是這座池最小的一個岸。我說：岸是做什麼的。澄說：讓想上來的人知道哪邊是上。

我有一個池曆。最後一頁有一個名字。只有兩個人叫的那個。現在只有一個人叫。

「我」這個字我最近說得不太順，像隔了一個霧季沒回去的家鄉話。我每天說幾次，練著。

```
〔若主線 F6＝接受〕有一個年輕的記脈者來過。她很吵——不是嘴，是舌頭，隔著水都聽得見她在嚐每一樣東西。池給了她一次安靜。她坐著的時候，我的那一小格痛，替她多痛了一下。我沒有跟她說。
〔若主線 F6＝婉拒〕有一個年輕的記脈者來過。她很吵——不是嘴，是舌頭。池要給她安靜，她沒有收。她走的時候經過岸位，看了一眼我掌背的根絲，又看了一眼我膝上的池曆。我想她看得懂哪一樣是我的。
```

我不知道這樣算留下來，還是算沒走成。

我的手有一點痛。那一點是我的。

〔字卡：**〈融脈者的極樂〉完**〕

**〔解開〕版**

結鬆開的時候沒有聲音，池面起了一圈很細的紋，從岸位往裡走，走到對岸，又走回來，然後我們都知道了：有一個人，在一座掛在橋索上的小池邊，哼了十一年同一句調子，一邊哼一邊刷一把水位尺，尺的第七刻有一個缺口，是另一個人十九歲的時候磕的，那座池在藍昏會打一個嗝，那座池有兩個名字，一個寫在冊子上，一個以前只有兩個人叫，現在有三百個人叫，我們覺得這樣比較不孤單，我們想不出誰會反對。

那句調子我們本來就會。我們哼給那個人聽，四個音，每一個都很準，那個人的手不痛了，連找都找不到了，那個人坐進來一圈，又一圈，水是暖的。

我們之中有一位從霧冠來的客人沒有坐進來，站在岸上聽了很久，離開的時候帶走了一本池曆，我們讓客人帶走，因為紙上的東西我們已經有了，而客人似乎比較需要它。客人走到門邊，回頭說了一個味道，澀的，後面回甜。我們嚐到了。很好吃。我們不記得它是做什麼用的。

```
〔若主線 F6＝接受〕有一個年輕的記脈者來過，舌頭很吵，我們給了她安靜，她收下了，她安靜的那一會兒我們也跟著安靜，我們很久沒有那麼安靜，我們謝謝她。
〔若主線 F6＝婉拒〕有一個年輕的記脈者來過，舌頭很吵，我們給她安靜，她沒有收，我們不明白，可是門沒有鎖，沒有收的人也可以再來，我們把那一份留著。
```

南岸的杯封完了。邊壓得很平。壓，壓，停，壓。第三個音很準。我們很好。

〔字卡：**〈融脈者的極樂〉完**〕

- **時間：12 分**

## 2. 主題與一句話

**一句話**：教學生「不知道就不要寫成答案」的人，為一個只出現過一次的現象，走進了回不來的地方。

**主題**：執不是固執於對，是固執於「必須由我去」。茯的拒絕每一條都站得住；奧芮的離開也不是英雄行為——
它建立在一個錯誤信念上：只要風險由自己一個人擔，就不算傷害留下的人。本篇讓玩家親手做三件日後珂潾要一一解開的事：
瞞她、拆散筆記、畫錯器官。

**環境母題**：
- **光**：清季的靛丘沒有霧，色素礦在斜光下一層一層：靛、青、骨白。什麼都看得很清楚，這是它殘忍的地方。
- **聲**：回退池的滴水；評議棚的銅片（發言前敲一下）；最後是線前，沒有鐘管草。
- **味**：「沒有尾的甜」——還沒決定要成為什麼的味道。全篇只出現一次。

## 5. 場次

### SF3-01〈第七盤〉（開場，全文）

- **地點／時段**：回退池室。清季，晨。沒有霧。光從丘坡斜進來，照得每一只淺盤的水面都看得見底。池水一滴一滴從導管殘段的斷口落下來，每一滴之間隔得剛好夠人起疑。
- **出場**：奧芮。

*清季第三旬，第二日。回退，第七輪。*

六盤是做的。一盤是不做的。

做法同前六輪：縫林寄來的五葉型縫葉，五種葉各取一指甲蓋的組織，加一盤五葉癒合縫上的；斷糖，微量靛乳，等一個潮次。我要它們忘掉自己是哪一種葉。

如果原脈是一批種子——院裡這樣教，我也這樣教了二十年——那麼每一種拼裝體底下都該壓著同一個底。把後來縫上去的東西一層一層退掉，五種葉該退回同一個味道。找到那個味道，就知道要去找什麼樣的種子。

結果同前六輪。

第一盤，薄寬葉：死。乾淨的死，水是清的。
第二盤，羽狀：死。
第三盤，厚蠟質：沒死，冠部泛紅，摸起來微熱。指甲蓋大的一株燼冠。我用膜罩住，記座標，習慣了。
第四、第五：死。
第六盤，癒合縫：五種組織互相把糖抽乾，然後一起死。這一盤我每次都多看一會兒。

沒有一盤退回去。組織離了整株，不是回到更早的樣子，是直接壞掉。七輪，四十二盤，一致。

我寫：*回退，失敗。*

然後是第七盤。對照。刺緣葉的組織，什麼都不做，只接池水養著，放在最角落，為的是證明「不處理就不會變」。

它變了。

盤心有一小塊，米粒大，顏色淡了。刺緣葉該有的那種暗青沒有了，也不是病的那種紅。就是淡。我封上掌套，取樣，稀釋到我的舌頭受得了的程度。

我的舌頭老了，一次只讀得出一個味。

甜。

刺緣葉不該是甜的。刺緣葉是苦在前、澀在後，孩子都嚐得出來。而且這個甜後面什麼都沒有。健康的甜有尾巴，長長的，像水足的時候導管打開的那種涼。這個沒有。它甜一下，就停在那裡，像一個人張了嘴還沒決定要說什麼。

我寫：*第七盤（對照）：局部退——*

我看著「退」字。

> **〔介面教學：把握〕** 右側的「把握」條從兩成跳到五成。筆記上，「局部退——」後面自動浮出兩個淡淡的字：**「成功」**。
> 指令欄亮起：**劃掉**。

我把它劃掉。重寫：

*第七盤（對照）：局部變淡。味：甜，無尾。成因不明。這一盤我什麼都沒做。*

什麼都沒做的那一盤，是唯一有事的那一盤。我教了二十年書，知道這種事叫什麼。

它叫髒。

```
珂潾：（門外，先敲了兩下門框，露出手腕）老師。我洗過手了，遮了味。可以進來嗎？
奧芮：掌套。
珂潾：封著。
奧芮：進來。不要看角落那一盤。
珂潾：……您這樣說我一定會看。
奧芮：我知道。所以先去把自己的眼睛矇上。今天教設盲。
```

- **時間：10 分**

### SF3-02〈盲樣〉

- **地點／時段**：味診台。午前。台面是一整塊洗得發白的礦板，上面一排七只小碟，碟底的標記我用蠟抹掉了。風很乾，沖洗液的杯沿結了一圈鹽。
- **出場**：奧芮、珂潾（十七歲，入院第四年）。
- **目的**：「設盲」「借舌」教學；年輕的珂潾——天賦已經在，耐心還沒有。奧芮需要她的舌頭，並且知道這一點有多危險。

- **玩法**：玩家替七只碟**設盲**（抹標、擲籤打亂、另記一份封起來的對照表），再**借舌**。若未設盲就借舌，珂潾會讀出奧芮「希望」她讀到的東西——系統會讓玩家先犯一次這個錯：

```
（未設盲的示範）
奧芮：這一碟。我覺得它有點甜。
珂潾：（嚐）……有。甜。
奧芮：那是清水。
珂潾：（臉紅到頸側，脈紋都亮了）可是我真的——
奧芮：妳真的嚐到了。妳的舌頭沒有說謊，是我先在妳耳朵裡放了一個字。妳的舌頭比我好四倍，所以別人放進去的字，在妳那裡也會響四倍。記住這件事。日後會有很多人想往妳耳朵裡放字，包括我。
```

```
（設盲後）
珂潾：第一碟。苦，然後澀。刺緣葉，普通的。
珂潾：第二碟。一樣。
珂潾：第三碟——（停）
奧芮：不要看我。看碟。
珂潾：先是……甜。可是不對。甜應該有後面。這個沒有後面。它不是斷掉，斷掉會有一個缺口，我嚐得出缺口。它是——還沒有。
奧芮：還沒有什麼？
珂潾：還沒有決定。老師，它不是任何一種葉。它是還沒當葉子之前的東西。
奧芮：這句是妳嚐到的，還是妳想到的？
珂潾：……前半句是嚐到的。「還沒當葉子之前」是我想的。
奧芮：那就只寫前半句。
珂潾：可是後半句比較重要！
奧芮：後半句比較好聽。好聽的東西要多放三旬再寫。
```

她寫了。她在「甜，無尾」後面留了一個空格，沒有填，可是我看得出她用指腹在那個空格上按了一下——她把想的那半句用化學通道留在皮上了。紙面上沒有字。

我沒有拆穿她。那是我教的另一個壞習慣。

- **抉擇（小）**：是否告訴珂潾第三碟來自對照組。告訴→她當晚自己跑去看池水來源（SF3-03 多一段對白）；不告訴→把握 +5%。
- **時間：14 分**

### SF3-03〈什麼都沒做的那一盤〉

- **地點／時段**：回退池室，池底。退潮。水位落下去以後，池壁露出那截導管殘段——本院最老的一截，比院舍老，比院門老，管壁厚得像骨頭，上面一層一層的癒合紋。
- **出場**：奧芮、珂潾（視前場）、池室雜役（過場）。
- **目的**：「反證」教學。奧芮老老實實去找「這只是髒」的證據，找到了三個——而每一個都沒有讓把握下降。

- **玩法（反證調查）**：玩家提出「若第七盤只是污染，會看到什麼」，逐項去查：
  1. **水**：第七盤放在角落，接的是老殘段直接滴下來的水；前六盤用的是濾過的池水。→ 變因一。
  2. **池曆**：那個潮次有一隻潾者從院池經過交接，游過回退池的進水口；濾幕雜役記了一筆「黏液殘留，已沖」。→ 變因二。
  3. **潮汐曆**：那一夜是靜潮。→ 變因三。
  4. **樣本**：第七盤的刺緣葉組織，與前六盤是同一株。→ 排除。

```
珂潾：三樣。老管的水、潾者的黏液、靜潮。哪一樣是原因？
奧芮：妳說呢。
珂潾：……我不知道。可能是一樣，可能是兩樣一起，可能三樣都要。也可能都不是，是第四樣我們沒想到的。
奧芮：很好。這是今天唯一能寫進葉帖的句子。
珂潾：老師，妳看起來不像覺得「很好」。
奧芮：因為我找到三個理由說它是髒的，可是我的把握沒有變少。這是壞兆頭。妳日後要是發現自己這樣，就去找一個會罵妳的人。
珂潾：誰會罵您？
奧芮：院長。
```

> **介面**：三項變因各自成立時，「把握」本應下降——系統讓它**上升**，並在筆記邊浮出一行淡字：
> 「不是組織自己會的事。是被周圍允許的事。」玩家可**劃掉**。劃掉後它會在下一場換一種說法再浮出來。
> 這行字日後會變成線索④頁邊的那一句。本篇不讓玩家阻止它成形，只讓玩家看見它是怎麼長出來的。

- **時間：16 分**
