## 2. 主題、一句話與環境母題

**一句話**：最響的那一個口，不一定在喝水。

**主題**：
連結不只是「管子通不通」。橋記得水以前的走法，人記得不痛的感覺，外站記得每一張葉帖該有的名字——
記憶可以是路標，也可以是一個只剩拍子、沒有水的口。本章讓珂潾第一次看見「分攤」確實止了別人的痛，
也第一次看見「記得」和「活著」不是同一件事。

**脈況階段**：霧退。
水還在，但霧的清甜尾變短；晨霧邊界一天比一天低；霧線以上的發光菌落與螢光花為了被看見而越燒越亮；
燈蛾被過亮的光拖離花群，飛到脫水。沒有硫味——那是下一階段的事——這裡的病是**渴**與**過亮**。

**環境母題**

| 通道 | 健康 | 霧退中 |
|---|---|---|
| 光 | 歐柯的橙光只到樹幹中段，以上是青色霧光，成片呼吸般脈動 | 霧線下移；霧線以上的青光變成不脈動的白青，樹幹上留一圈一圈的「霧痕」 |
| 聲 | 滴露聲密得聽不出單顆；脈橋有低而慢的纖維摩擦，像睡著的人翻身 | 滴露數得出來；橋的摩擦聲在繃緊時拔高，像弦 |
| 味 | 霧入口是涼、微甜、長尾（「水足」訊號），可以數到七 | 甜尾數到四就斷，尾端接一絲澀 |

## 3. 本章新系統（承接總綱 §2）

### 3.1 垂直探索

霧冠環的地圖不是平面，是四層：**落露底**（根座與活土）、**中冠**（聚落與大部分脈橋）、**退霧線**（晨霧邊界，每日位置不同）、**冠頂**（雲上）。
層與層之間以樹幹內的攀槽、懸索與斜橋相連；同層之間以脈橋相連。每座橋有三種狀態：

| 橋況 | 掌讀手感 | 通行 |
|---|---|---|
| **鬆** | 波來、波去、回彈乾脆 | 正常通過 |
| **繃** | 波尾拖澀，回彈慢半拍 | 必須踩在兩波之間；負重過多會被橋「吐」回岸（體力 −，不致命） |
| **閉** | 只有拍，沒有回彈；或完全沒有拍 | 不可通過；需診療、等待潮曆，或繞行 |

### 3.2 掌讀（橋面壓力波）

珂潾把掌心貼在橋面或接口上，讀三件事：**拍**（多久一波）、**向**（波從哪一端來）、**餘**（波尾有沒有水的回彈）。
介面上不出數字，只出三段觸感提示與一條會呼吸的亮脈。掌讀不增加感官負荷，但需要站定——霧裡站定本身就是風險。
遭遇中，掌讀是本章解鎖的**免費指令**（每回合一次）：可判定排在最前面的味符是「有水的」還是「只有拍的」（見長喉橋）。

### 3.3 燈蛾導航

霧中視距只有兩三步。燈蛾群以**方向閃**移動：群體從後往前依序亮起，像一道光往前跑。
規則只有三條，由引蛾童爍教給玩家：

1. 不看哪一隻亮，看「亮往哪裡跑」。
2. 只跟青色、成片脈動的光；白青而不脈動的是過亮的病光。
3. 光尾帶紅的不跟。

（第 6 章的「光訊號語法」在此只露出最初一格：方向。本章不教句法。）

### 3.4 光色素

從色囊果、青絨菌毯與蛾杯花取得。同一種色素依濃度分三階，承接總綱「低＝訊號、中＝藥、高＝毒」：

| 階 | 名 | 用途 | 代價 |
|---|---|---|---|
| 淡 | **引** | 塗在葉片上招引或安撫燈蛾群；在霧中標記回程 | 也會引來不該來的群 |
| 中 | **濾** | 製濾色葉：分辨病光、降低強光灌入的感官負荷；替過亮菌落遮光 | 戴著濾色葉時，嚐味讀值的「甜」會被壓低一級 |
| 濃 | **灼** | 定色（繪製部分葉帖必需） | 沾到感受器會留下味盲白斑；本章不可作為處置藥使用 |

本章新增的遭遇指令 **遮光**：消耗 1 份「濾」，使一個發光源本回合不行動、不灌入感官負荷。

### 3.5 本地藥材替代

霧冠沒有池糖囊；集露杯底的**露糖囊**可製「露糖液」，對症**澀**，效力為池糖液的八成（治療窗較寬，不易過量）。
靛乳與縫苦須向上行商隊以池糖籤或樣本換取；燼灰在本章極稀少（來源見 M2-19、S2-05）。

#### M2-02　落露底：少了一格

- **地點**：落露底（根座層）
- **時段與潮汐**：第一日・長晨後段；稜月殘潮
- **出場**：珂潾；遠處有一名擰濾幕的霧濾師（霰，暫未交談）
- **目的**：垂直移動教學；第一個「霧退」的物證（露位尺）；本章第一場遭遇
- **環境狀態**：霧濃到看不見自己的鞋。滴露聲本來應該是一片沙沙聲，現在聽得出一顆、一顆。板根上的青絨菌毯隨著她的腳步一明一暗。

**對白重點＋摘要**

珂潾沿板根之間的活土小徑前進，學會三件事：攀槽（樹幹上的活體凹槽，會在手放上去時微微收緊）、懸索、以及「霧裡站定就看不見路」。
她在一根宿主樹的根座上發現一支刻在活樹皮上的**露位尺**——霧冠人用來記每晨霧水凝到哪一格。

```
珂潾：一格一晨。上面的刻痕長了新皮，下面的還是白的。
珂潾：最新的一道……比去年同一季的低一格。
珂潾：只是一格。蒲嬤也會說「只是暖湧」。
（她把刻痕拓在葉帖邊緣。）
珂潾：我不說是什麼。我先寫是多少。
```

**遭遇（教學）：乾緣集露杯叢**

- 味序：**澀—澀—甜**
- 教學重點：以露糖液處置兩個澀；最後的甜是健康糖流，**不處置**。介面在玩家把游標移到「處置」時提示：「這個味道不是病。」若仍誤治，杯緣收縮、噴出一小口苦霧（感官負荷 +）。
- 穩定後取得：露糖囊 ×3、葉帖 **F-016〈承露杯〉** 完成。

```
珂潾：杯緣乾了一圈，中間還有水。它沒有病到底，它只是從邊上開始渴。
珂潾：最後那一口是甜的。那是它自己的。不要動。
珂潾：——記一筆：我差點動了。
```

- **抉擇與向度**：穩定 → 播 +1、霧冠連通度 +1。
- **預估時間**：12 分

#### M2-03　睡橋：拍、向、餘（全文）

- **地點**：睡橋（落露底通往中冠的第一座脈橋）橋頭
- **時段與潮汐**：第一日・午白；珂月初漲（冠層無感）
- **出場**：珂潾、絡伯
- **目的**：掌讀教學；建立「橋不是決定，是有沒有力氣」；埋下「潮拍」與絡伯的手
- **環境狀態**：橋從霧裡伸出來，寬得能並行三人，表面是絞在一起的根與菌絲，濕而溫。它每隔一陣子就整條往下沉一掌，再浮回來，伴著一聲很低的纖維摩擦。

```
（珂潾一腳踏上橋頭。橋面在她腳下慢慢繃緊。）

絡伯：腳。收回去。
（聲音從霧裡來。一個矮而寬的老人坐在橋頭的根瘤上，兩隻手掌朝上攤在膝頭，像在晾。）
珂潾：（收腳）它承不住？
絡伯：它承得住三頭馱葉的。它現在在吸氣。妳踩在它吸氣的時候。
珂潾：橋吸氣。
絡伯：妳是記脈院的。妳們管它叫什麼？
珂潾：壓力波。水被上面的葉子拉上去，橋腹的囊補一口，管壁跟著——
絡伯：吸氣。
珂潾：……吸氣。

（絡伯沒有笑。他拍了拍身邊的橋面。）

絡伯：手。不要戴那個套。
（珂潾摘下掌套，把手掌貼上去。脈紋亮起。）
絡伯：先別嚐。妳們這種舌頭好的，什麼都想先嚐。先數。
珂潾：……來了。一波。從那一頭來的，往我背後走。
絡伯：這叫「向」。再來。
珂潾：又一波。中間隔了——我呼吸四次。
絡伯：這叫「拍」。四口氣一拍，這條橋睡得很好。再來，這次摸尾巴。
珂潾：尾巴？
絡伯：波走過去以後，手底下有沒有東西頂回來。
（停頓。）
珂潾：有。很輕。像按一塊吸飽水的苔，它慢慢回來。
絡伯：這叫「餘」。有餘，橋裡有水。有水，它就有力氣把妳撐住。
絡伯：拍、向、餘。會這三樣，霧冠一半的橋妳走得了。
珂潾：另一半呢？
絡伯：另一半要認識它。

（珂潾又按了一次，閉上眼。）

珂潾：它會決定讓不讓人過嗎？外面的人是這樣傳的。
絡伯：它不決定。它只是有時候沒力氣。
絡伯：沒力氣的時候上面站了重東西，它就把身子一縮。人掉回岸上，罵它不讓過。
絡伯：妳渴了三天，有人往妳背上放一筐石頭，妳也縮。
珂潾：那我該在什麼時候走？
絡伯：兩波中間。它吐完氣、還沒吸的那一下。妳數到三，走；第四口氣站住，等它過去。
珂潾：數到三走，第四口站住。
絡伯：站住的時候不要看腳。霧裡看腳的人都以為自己要掉了。

（珂潾上橋。走三步，站住。橋沉下去、浮回來。再走。）
（絡伯跟在後面，沒有數——他的腳自己知道。）

珂潾：（走到中段）絡伯。有沒有橋，沒人走的時候自己會跳？不是這種拍子。
絡伯：（頓了一下）誰跟妳說的。
珂潾：沒有人。我只是在想，橋記不記得事情。
絡伯：我阿母說有。西冠的老橋，月亮疊在一起的時候會自己多跳幾下。她叫那個「潮拍」。
絡伯：我說阿母，這裡離潮三天的路。她說，橋又沒走過那三天，它哪知道。
珂潾：您摸過嗎？潮拍。
絡伯：摸過。很齊，很有勁。我一直當那是最健康的口。
（他把手翻過來看了一眼，又翻回去。掌心的紋裂得很深，裂口邊緣發白。）
珂潾：您的手——
絡伯：乾的。霧退以後，橋渴，摸橋的人跟著渴。過了橋再說。腳。第四口了。
（珂潾站住。橋沉下去。）
```

- **玩法**：節奏式過橋小遊戲（數拍）。失敗只會被「吐」回橋頭，體力 −5。
- **取得**：葉帖 **F-019〈活橋・橋面索〉** 觀察進度；解鎖遭遇指令「掌讀」（本章後段生效）。
- **抉擇與向度**：無。
- **預估時間**：14 分

#### M2-04　掛橋集：四樣東西都在，只是低了一格

- **地點**：掛橋集（中冠聚落節點）
- **時段與潮汐**：第一日・午白後段；珂月漲
- **出場**：珂潾、絡伯、霰（霧濾師）、聚落居民
- **目的**：建立聚落日常與四項基礎設施；以物易物；打聽奧芮；指向晾葉台
- **環境狀態**：聚落是十幾個掛在枝叉間的可拆節點，彼此以細橋相連，沒有一處把重量壓死在同一根枝上。孢子濾幕像一面面垂下的濕鬚簾，有人正在擰，擰出來的水落進壺裡，聲音很薄。

與霰的初見（關鍵句全文）：

```
霰：（擰著幕，不抬頭）記脈院的。看袖口就知道，一圈一圈的礦印，跟樹的年輪一樣。
珂潾：那是池水，不是年紀。
霰：一樣。都是泡出來的。
（她把擰下的水倒進壺，舉起來看了一眼水線。）
霰：這面幕，以前一個長晨擰三壺。現在一壺半。
珂潾：幕老了？
霰：幕是上一季才接的新鬚。老的是霧。
霰：妳會寫下來吧。
珂潾：會。
霰：我知道妳會。妳們都會。寫下來以後呢？
珂潾：……我還在找「以後」的那一段。
霰：（終於看她）這句比妳前面那個站長誠實。去晾葉台的路要過一段霧，天黑前別自己走。找那個養蛾的小鬼。
```

珂潾：（低聲）不是醜。是故意的。
珂潾：好吧，也有一點醜。老師的橋一向畫得像腸子。
```

#### M2-05　藍昏：亮往哪裡跑（全文）

- **地點**：掛橋集西緣 → 霧中細橋 → 晾葉台
- **時段與潮汐**：第一日・藍昏；珂月滿漲
- **出場**：珂潾、爍（引蛾童）、燈蛾群
- **目的**：燈蛾導航教學；第一次看見過亮的病光
- **環境狀態**：歐柯落到雲底下以後，霧不是變暗，是換了光源：樹皮上的菌毯、花、蛾，一起亮起來。霧把所有的光都泡開，每一步都像走在一杯發亮的水裡。

```
（聚落邊緣的細橋頭。一個十二三歲的女孩倒掛在懸索上，膝彎勾著索，手裡舉著一片塗了淡色的葉。）

爍：妳就是那個要去晾葉台的。霰姨說妳會自己走然後掉下去。
珂潾：她對我的評價比我預期的高。我以為她會說我先寫完筆記再掉下去。
爍：（翻身下來）會掉的人都很會講話。我叫爍。妳會跟蛾嗎？
珂潾：我會看蛾。
爍：那不一樣。看蛾是看牠。跟蛾是看牠要去哪。

（她把那片葉舉高，輕輕左右擺。霧裡先亮起一點，然後十點、一百點。翼聲像極細的玻璃互相碰。）

爍：來了。現在不要看哪一隻亮。
珂潾：我在看……左邊那一團最亮。
爍：錯。妳看的是「誰」。要看亮往哪裡跑。
（珂潾瞇起眼。群裡，後方的蛾先亮，然後是中間的，然後是最前面的——一道光沿著整群往前滾過去。）
珂潾：……從後面亮到前面。像有人沿著一排燈走過去。
爍：對。那叫方向閃。牠們是在跟彼此說：花在那邊。
珂潾：牠們怎麼知道花在那邊？
爍：前面的看得到花光。後面的看不到花，看得到前面的。一隻一隻傳回來。
珂潾：所以沒有哪一隻知道全部的路。
爍：沒有。單一隻很笨。我養過單隻的，牠繞著我的壺飛到天亮。
珂潾：（低聲，像在寫）個體易迷失。群體可選路。備註：飼養者對個體的評語不留情。
爍：妳在說我嗎？
珂潾：我在記錄。

（兩人上了細橋。爍走在前面，不數拍——她看蛾，蛾過處橋面的菌光會跟著呼吸。）

爍：第二條。只跟青色的。要一片一片地暗下去再亮起來，像喘氣的那種。
珂潾：健康的光會脈動。
爍：妳們講話都這樣。對啦，會喘的。
（霧的右上方，有一塊光不喘。它是白的，白裡帶一點青，亮得把周圍的霧都洗掉了顏色。）
珂潾：那邊。那一片不動。
爍：（聲音低下去）不要跟那個。
爍：那是上面的。霧線上面的菌毯，霧退了以後就那樣。越來越亮，越來越白。
珂潾：蛾會被它引走嗎？
爍：會。牠們自己也知道不該去。可是太亮了。
爍：上一季我有一群，四百多隻，在那種光下面繞了一整個藍昏。早上我去看，翅膀都捲起來了。乾的。
珂潾：……抱歉。
爍：妳又沒做什麼。
爍：第三條。光尾巴有紅的，不跟。這條我沒遇過，是我師父教的。師父說遇到了就回頭，不要好奇。
珂潾：我會盡量不好奇。
爍：妳做不到。妳是記脈院的。

（蛾群的方向閃往左下折。爍跟著折。霧裡浮出一棵獨立的宿主樹，樹身上一層一層掛著晾架，像一疊攤開的書頁。）

爍：到了。晾葉台。
爍：那個站長人不壞，可是她身上有一種味道，像放太久的濕皮。妳進去就知道。
珂潾：那不是她的味道。
（珂潾停在橋尾，掌心朝著那棵樹，沒有碰。）
珂潾：先是悶。然後甜——不是水足的甜，是東西放軟了的甜。後面有腥。
珂潾：是樣本。樣本在發霉。
爍：妳隔這麼遠就知道？
珂潾：我希望我不知道。
```

- **玩法**：燈蛾導航教學段（跟對方向閃三次；途中有一次白光岔路，跟錯會繞回原點並感官負荷 +10）。
- **取得**：道具「引色葉 ×2」；葉帖 **F-023〈蛾杯花〉** 觀察進度。
- **抉擇與向度**：無。
- **預估時間**：14 分

#### M2-06　晾葉台：對味（全文）

- **地點**：晾葉台（記脈院霧冠外站）・寄存龕前
- **時段與潮汐**：第一日・深夜；珂月退
- **出場**：珂潾、栩（站長，完錄派）、梢（年輕記脈者，急播派，只露一面）
- **目的**：建立外站與霉變；寄存規矩「對味」；讓珂潾嚐到蠟珠裡的題目；交代上冠頂的理由
- **環境狀態**：外站的每一層都是晾架，一張張葉帖攤開夾在活纖維繩上。站裡關著孢子濾幕，空氣不動，濕而暖。最裡面的標本室門縫底下，有一線灰白的絨。

```
（栩在燈囊下翻一張葉帖。她的指腹是白的——長年翻晾濕皮的人才有的那種白。她沒有先看珂潾的臉，先看她的手腕。）

栩：腕。
（珂潾翻出手腕內側。脈紋在跳，不太穩。）
栩：趕路趕的，還是嚐多了？
珂潾：都有。站長，您的標本室——
栩：我知道。門縫的絨我每晨量一次。今天比昨天寬半指。
珂潾：您關著濾幕。
栩：開了，裡面的活樣本一晨就乾。霧線掉到我們腳底下去了，外面的空氣現在是乾的，妳上來的路上沒覺得？
珂潾：覺得了。甜尾數到四。
栩：（第一次正眼看她）妳數甜尾。誰教的？
珂潾：奧芮。
（栩把手裡的葉帖放回繩上，夾好，才說話。）
栩：坐。

（兩人在寄存龕前坐下。龕是一格一格嵌在活樹壁裡的小室，每格口上封著一層結痂的膜。）

珂潾：奧芮兩年前經過霧冠。聚落的人記得。
栩：院裡的說法是失蹤。
珂潾：我問的不是院裡的說法。
栩：我知道妳問的是什麼。我只有寄存簿上寫的。
（她翻開一疊葉帖，手指停在一行。）
栩：前年霧季末。寄一件，封膜。對味一枚。取件人——不指名。
珂潾：不指名？
栩：不指名的意思是，誰帶得來答案，誰取。
珂潾：請開。我是奧芮的學生。
栩：我相信。我也不開。
珂潾：站長——
栩：寄存的規矩比我老。寄的人把一個味道封在蠟珠裡，取的人帶著同一個味道來。兩個味道對上，我開膜。對不上，天塌了我也不開。
栩：妳們年輕的總覺得規矩是用來擋妳們的。規矩是用來擋我的。我也想知道裡面是什麼，我想了兩年。
（停頓。）
珂潾：蠟珠裡是什麼味道，我可以嚐嗎？
栩：可以。高稀釋，一滴。這是規矩允許的——題目可以看，答案不能給。

（栩從龕旁的小格取出一枚指甲大的蠟珠，以取樣針刺出極少的一點，化進一匙露水。珂潾把匙沿抵在舌下，閉眼。）

珂潾：先是甜。
珂潾：很舊的甜。不是剛流出來的糖，是存過的，壁上刮下來的那種。
珂潾：然後——
（她的眉頭動了一下。）
珂潾：鹹。
珂潾：不是礦的鹹，沒有銅鏽。是……潮的。漲上來又退下去、留在石頭上的那種鹹。
栩：我在霧冠三十年。那個鹹我只在這顆珠子裡嚐過。
珂潾：霧冠沒有潮。
栩：沒有。
珂潾：（從束裡抽出殘葉，攤開）老師留給我這個。一座三口橋，其中一個口畫成了不可能的東西。
栩：（看了很久）……管子裡有水線。
珂潾：您認得這座橋嗎？
栩：三口橋，西冠十幾座。這張沒畫宿主樹，沒畫方位，只有剖面。奧芮是故意不讓人按圖找的。
珂潾：那要怎麼認？
栩：剖面要從亮脈認。每座橋的亮脈分岔不一樣。以前在中冠抬頭就看得見；現在霧線上面的菌光太白，亮脈被洗掉了，要到冠頂往下看，還得隔著濾色葉。
珂潾：我沒有濾色葉。
栩：冠頂的採色人有。深靛的那種，叫「濾」。
栩：妳要上去，就順便替我帶一些回來。架上護葉的青菌快燒完了，我想給它們遮一遮。
珂潾：您的意思是，我替您帶色素，您替我——
栩：我什麼都不替妳。我開不了那格。但妳帶色素回來，我讓妳進標本室看一眼，妳的舌頭比我們全站加起來都好，妳告訴我霉是從哪一架先起的。
栩：這不是交換。這是兩個人各自需要對方。
珂潾：這是交換的定義。
栩：（嘴角動了一下）奧芮也這樣回嘴。

（走廊另一頭，一個年輕人抱著一疊濕葉帖快步走過，在標本室門前停了一下，往門縫看，又看向栩。）

梢：站長。第三架今天又軟了兩匣。活的。現在拿出去種，還來得及。
栩：先編號。先畫。先對過名冊。
梢：畫完它就死了。
栩：沒畫它就沒活過。
（梢沒有再說，抱著葉帖走了。腳步很重，晾架跟著晃。）

珂潾：……您們吵多久了？
栩：從門縫有絨的那天。
栩：去睡。客架在上一層。明晨霧線會再低一點，妳從上面往下看，就知道我們是站在哪裡吵架的。
```

- **玩法**：解鎖寄存龕介面（顯示「題目：甜→潮鹹」）；解鎖支線 S2-07、S2-08（梢）。
- **取得**：關鍵資訊「對味」；葉帖 **F-028〈灰絨霉與護架青菌〉** 觀察進度（門縫取樣）。
- **抉擇與向度**：無。
- **預估時間**：14 分

**第一段小結**：珂潾約 13 級。已知：要找一座三口橋；答案是一個「甜後接潮鹹」的味道；認橋要先上冠頂。

#### M2-07　攀槽：絞得太緊的索

- **地點**：晾葉台上方的攀槽與斜橋群
- **時段與潮汐**：第二日・長晨；墨月初漲
- **出場**：珂潾；捻索獸數隻
- **目的**：垂直攀行；認識橋的照料者捻索獸；第一次把「掌讀」用在診療
- **環境狀態**：攀槽在手放上去時微微收緊，像被握回來。越往上霧越薄，滴露聲從「數得出來」變成「要等」。斜橋的橋索上，有幾處絞得發亮，像擰過頭的濕布。

**對白重點＋摘要**

珂潾循攀槽上行三層。途中的一座斜橋呈「繃」況：橋索上，幾隻巴掌大的六肢軟獸正一圈一圈把纖維往同一個方向絞。
那是**捻索獸**——平時把鬆脫的橋纖維捻回去、在裂縫裡塞進菌絲團的橋面照料者。霧退後牠們收不到「夠了」的濕度訊號，於是一直絞。

```
珂潾：背上兩片小板，曬光用的。板子邊緣捲起來了——乾的。
珂潾：牠沒有在破壞橋。牠在修。只是沒有人告訴牠修好了。
珂潾：（掌貼橋索）拍子還在，向也對。餘……餘卡在牠絞的那一圈下面。水過不去。
珂潾：勤快到把病人勒住。我認識幾個這樣的同窗。
```

**遭遇：過絞的捻索獸＋繃橋索**

- 味序：**苦—焦—澀**
- 處置：微量縫苦（鎮靜捻索獸，使其鬆開）→ 靛乳（疏通被絞窄的索內導管）→ 露糖液（補水）。
- 特殊：若先處置焦而未解苦，捻索獸會把剛疏通的那段再絞一次（焦符重新長出）。這是本章第一次教「到達順序就是處置順序」的理由。
- 隔離選項：割斷被絞的那一股索（快；橋從「繃」降為永久單人橋；霧冠連通度 −2；焚 +1）。

穩定後，捻索獸爬到珂潾的袖口上曬了一會兒板，才回橋腹。

```
珂潾：不要選我。我身上的水比橋還少。
珂潾：……好吧。曬完就回去。
```

- **取得**：葉帖 **F-019〈活橋・橋面索〉** 完成（看、採、嚐、畫四步齊）；見識 +。
- **抉擇與向度**：穩定＝播 +1、連通度 +2；隔離＝焚 +1、連通度 −2。
- **預估時間**：12 分

#### M2-08　退霧線

- **地點**：退霧線（當日晨霧邊界）
- **時段與潮汐**：第二日・長晨後段；墨月漲
- **出場**：珂潾
- **目的**：讓玩家親身穿過「霧退」的邊界；建立過亮帶的感官負荷；為外站之爭給出一個從上往下看的畫面
- **環境狀態**：霧不是漸漸變薄的。它有一個面。珂潾的頭先穿出去，肩膀還在霧裡——上面的空氣乾、清、亮得刺人。樹幹上有一圈一圈的水痕，像池子退水後留在壁上的線，最高的那一圈在她頭頂四層樹冠之上。

**對白重點＋摘要**

```
珂潾：一圈、兩圈……最上面那一圈已經長了乾皮。那是幾季以前的霧線。
珂潾：最下面這一圈還是濕的。昨天的。
珂潾：今天的霧面在這圈下面一臂。
（她低頭。霧面底下，隱約看得見晾葉台的最上層晾架——它已經露在霧外。）
珂潾：站長說，從上面看就知道他們是站在哪裡吵架的。
珂潾：站在線上。腳在濕的那邊，頭在乾的這邊。
```

霧線以上，樹皮上的**青絨菌毯**不再呼吸，白青色，持續地亮。玩家在此區域每停留一段時間，感官負荷自然上升（強光即強訊號）；介面邊緣泛白。
珂潾用一片引色葉試著安撫附近的菌毯，無效——「引」只對蛾說話。她需要「濾」。

```
珂潾：亮是在喊。喊給蛾聽：這裡，這裡有花。
珂潾：霧以前替它們把聲音傳遠。現在沒有霧，它們只好喊大聲一點。
珂潾：喊到自己先啞。
```

- **玩法**：在霧痕上拓下三圈位置（供 F-123 用）；過亮帶限時穿越。
- **取得**：葉帖 **F-021〈青絨菌毯〉** 觀察與取樣；**F-123〈霧線曆〉** 第一筆記錄。
- **抉擇與向度**：無。
- **預估時間**：10 分

#### M2-09　曬板原：三階（全文）

- **地點**：曬板原（冠頂，雲上）
- **時段與潮汐**：第二日・午白；墨月滿漲
- **出場**：珂潾、縹（採色人）
- **目的**：光色素系統教學（引／濾／灼）；讓「賣病出來的東西」這件事有一張臉
- **環境狀態**：雲在腳下，平得像一座沒有岸的池。樹冠頂端攤開一片片厚而深靛的曬板葉，全朝著歐柯。空氣乾到珂潾第一次在薇蘿覺得嘴唇會裂。

```
（一個瘦長的男人跪在一叢色囊果前，用骨片把果囊一顆顆刮進三個不同的小罐。他的十個指尖都是白的——不是栩那種泡白，是一點一點的白斑。）

縹：站在上風。妳的影子擋到我的板子了。
珂潾：（挪開）我要換「濾」。外站的站長要，我自己也要。
縹：拿什麼換？
珂潾：池糖籤。或者樣本。
縹：籤我有一把了。妳會刮嗎？
珂潾：我會取樣。
縹：差不多。蹲下。我教一次。

（他挑起一顆色囊果，果皮底下三層顏色疊在一起：最外淡青，中間深靛，芯是近乎黑的琥珀。）

縹：同一顆果，三層。泡的水多水少，出來三樣東西。
縹：淡的叫「引」。塗在葉上，蛾看見了會來。妳應該用過。
珂潾：用過。對菌毯沒用。
縹：當然沒用。引是請客。菌毯又不是客。
縹：中的叫「濾」。塗在薄葉上，舉在眼前，白的光會退下去，底下原本的青才看得出來。貼在菌毯上，它也能歇一口氣。
珂潾：濃的呢？
縹：（舉起手，十個指尖朝她）「灼」。定色用的，畫圖的人最愛。沾到指腹就是這樣。這一塊、這一塊，嚐不到東西了。
珂潾：永久的？
縹：這一塊八年了。妳說呢。
珂潾：（低聲）低是訊號，中是藥，高是毒。
縹：妳們院裡是這樣背的？我們講得比較簡單：請客、遮陽、燙手。

（珂潾接過骨片，開始刮。縹看了一會兒她的手，沒有糾正。）

縹：妳問都沒問價。
珂潾：我在等您先說今年的行情。採色人都喜歡先說行情。
縹：（短笑）今年行情太好。
珂潾：太好。
縹：霧線上面的菌毯，色素出得比往年多三倍。果也是。它們拚命亮，亮就得做色。我一個長晨刮的量，以前要刮五天。
珂潾：您的語氣不像賺到了。
縹：我十四歲上來學刮色。師父第一天就說：色是它們吃飽了以後多出來的。妳拿多出來的，它們不疼。
縹：現在這個不是多出來的。是它們在燒自己，我在旁邊接。
珂潾：您可以不接。
縹：我不接，色一樣掉在地上，乾掉。我接了，下面有人拿去遮菌毯，還能救回幾片。
縹：我想過了。我想了一整季。接是對的。
縹：可是每一罐我都記得是從哪一片上刮的。賣的時候會想。
（停頓。風把雲面吹出一道很長的紋。）
珂潾：我的老師說，記得是哪一片，是這門工作唯一不能省的步驟。
縹：妳的老師是採色的？
珂潾：記脈的。差不多。都是站在快沒了的東西旁邊，手上拿著罐子。
縹：（看了她一眼）這句話妳別在外站講。那個站長會難過。

（他把一罐深靛推過來，又加了半罐。）

縹：三份給站長，兩份妳留著。妳刮的那些抵了。
縹：還有。妳戴著濾色葉的時候，舌頭會變鈍。甜的東西嚐起來沒那麼甜。
珂潾：色素遮的是光，為什麼連味道——
縹：我不知道為什麼。我只知道我戴著它喝露糖，像喝水。妳是嚐東西吃飯的，自己小心。
珂潾：記一筆。「濾：遮光，並壓低甜。機轉不明。採色人說像喝水。」
縹：妳真的什麼都寫。
珂潾：寫錯的也寫。那一類我老師特別愛看。
```

- **玩法**：採色小遊戲（控制稀釋，把同一顆果刮出引／濾／灼；過濃時指尖提示發白，需立刻沖洗）。
- **取得**：濾 ×5（其中 3 份為栩的委託物）、引 ×3、灼 ×1；道具「濾色葉」；葉帖 **F-025〈色囊果〉**、**F-024〈曬板葉〉** 完成；**F-176〈光色素三階〉** 完成。
- **抉擇與向度**：對白選項「您可以不接」／「換作我也會接」只影響縹的支線 S2-03 開場語氣。
- **預估時間**：14 分

#### M2-10　雲上三月

- **地點**：曬板原北緣的觀月枝
- **時段與潮汐**：第二日・長昏；稜、珂同現，墨月將升
- **出場**：珂潾；遠處有看月的曇婆（支線 S2-09 委託人，此場僅點頭）
- **目的**：取得天文葉帖；算出下一次「疊潮刻」；把「潮鹹」與「潮拍」接成一個可驗證的假說
- **環境狀態**：歐柯貼著雲面往下沉，把雲染成橙的。三顆月裡的兩顆已經在天上，一大一小；雲底下開始透出青光，一塊一塊，像有人在水下點燈。

**對白重點＋摘要**

在霧階池站，三月是隔著霧猜的；這是珂潾第一次同時、清楚地看見稜與珂，並看著墨從雲面升起。
玩家操作三圈可轉動的月盤（稜／珂／墨的相位），對齊觀測到的位置，得到下一次三月引力疊加的時刻。

```
珂潾：稜在這裡。珂落後它一掌半。墨剛出雲面。
珂潾：三個疊在一起的時候，鐘潮環的潮會漲到最高。霧冠沒有潮。
珂潾：可是蠟珠裡有潮的鹹。絡伯的阿母說老橋會跳「潮拍」。
珂潾：假設：有一座橋，以前接著一條通到潮邊的管。管不通了，橋還記得那個拍子。
珂潾：如果是，疊潮的那一刻它會跳得最明顯。如果不是，我就在橋上白趴一個長昏。
珂潾：老師趴了很多天。我至少知道該趴哪一刻。
（她把月盤轉到位。）
珂潾：後天。長昏第三刻。
珂潾：寫「假設」。不要寫「答案」。
```

觀測中她注意到天邊那顆紅星——歐墨——比她記憶中的亮。她沒有下結論，只在葉帖邊緣點了一個紅點。

- **取得**：葉帖 **F-122〈雲上三月〉**、**F-124〈疊潮刻〉** 完成；關鍵資訊「後天長昏第三刻」。
- **抉擇與向度**：錄 +1（完成觀測）。
- **預估時間**：12 分

#### M2-11　中頭目 A：〈假晨〉

- **地點**：曬板原南緣，一株獨立的冠燈樹
- **時段與潮汐**：第二日・藍昏；三月同現
- **出場**：珂潾；縹（在場外喊話，不進指令列）；燈蛾大群
- **目的**：把「過亮」做成一場遭遇；教「遮光」指令；產出本章對策葉帖
- **環境狀態**：藍昏應該是暗下來再亮起來。這裡沒有暗。一株冠燈樹的十幾個燈囊白得像把一小塊白晝釘在枝上，從雲底下升上來的燈蛾一群接一群撞進那團白裡，繞，不停，翼聲從玻璃聲變成乾葉聲。

**對白重點＋摘要**

```
縹：（遠遠地）那棵三天前還是青的！
珂潾：燈囊十四個。亮的十一個。底下三個還在喘。
珂潾：蛾的方向閃亂了——後面亮，前面也亮，沒有「往哪裡跑」，只有「這裡」。
珂潾：牠們不是迷路。是每一隻都覺得自己到了。
```

**遭遇：冠燈樹〈假晨〉＋迷航燈蛾大群**（詳見遭遇圖鑑 E-11）

- 味序：**苦—澀—焦—苦—澀**
- 對象行動：每回合，仍亮著的燈囊向珂潾灌入感官負荷（每個亮囊 +3）；蛾群撲光使樹再釋出一個苦符的機率上升。
- 遮光：每用 1 份「濾」遮住一個燈囊，該囊本回合不灌負荷，且蛾群有一部分恢復方向閃。遮滿六個後，蛾群整體轉向底下那三個健康燈囊，苦符不再重生。
- 味序重排：每當一個燈囊因過勞爆裂（第 4、第 7 回合），剩餘味符順序打亂。
- 隔離選項：割下所有過亮燈囊（兩回合內結束；失去冠燈樹樣本與 F-018 的完整觀察，只能畫「殘株」版；曬板原南緣此後藍昏無蛾；連通度 −3；焚 +1）。
- 撤離：蛾群損失約三成，樹在次日全白；之後可再來，但味序多一個焦。

穩定後：

```
（十一個燈囊裡有七個暗下去，再亮起來時是青的，慢慢地，一明一暗。蛾群的光從後往前滾了一次——又一次。）
珂潾：會喘了。
縹：（走近，看著自己的色罐）妳用掉了我半季的濾。
珂潾：我知道。我會寫是從哪一片上刮的。
縹：……那倒不必。
```

- **取得**：葉帖 **F-018〈冠燈樹〉**、**F-196〈霧退應變方〉**（星號配方：遮光＋補露＋引蛾歸群的順序）；見識大量。
- **抉擇與向度**：穩定＝播 +2、錄 +1、連通度 +3；隔離＝焚 +1、連通度 −3；撤離＝無向度，連通度 −1。
- **預估時間**：16 分

#### M2-12　冠頂的夜：別太相信圖（全文）

- **地點**：曬板原，縹的採色棚旁
- **時段與潮汐**：第二日・深夜；墨月高
- **出場**：珂潾；奧芮（回憶）
- **目的**：休息點；以回憶建立奧芮「畫錯器官」的習慣與教法，為線索③鋪底；珂潾的感官負荷第一次被當成問題說出來
- **環境狀態**：雲上的夜沒有霧，星很多，冷。雲底下的青光隔著雲透上來，像一整片在睡的東西。珂潾的舌根還留著假晨的苦，洗了三次沒洗掉。

```
（珂潾把今天的葉帖一張張攤在曬板葉上晾。她沖了第四次掌心，把手翻過來看。脈紋還在亮，不肯暗。）

珂潾：苦還在。假的。樹已經不苦了，是我的舌頭還在替它苦。
珂潾：記一筆：殘留，約半夜。下一個讀值的第一位不可信。
（她拿起那張殘葉，對著星光看那根不該存在的管子。）

（回憶——霧階池站的繪圖桌，多年前。聲音比畫面清楚。）

奧芮：妳這張畫得很漂亮。
珂潾（年幼）：謝謝老師。
奧芮：我不是在誇妳。漂亮的圖，看的人不會懷疑。
奧芮：這株的根，妳畫了七條。妳數過嗎？
珂潾（年幼）：……我覺得是七條。
奧芮：「覺得」寫在哪裡？
珂潾（年幼）：沒有寫。
奧芮：那看的人就以為是七條了。一百年以後還是七條。
（紙上有筆尖移動的聲音。）
珂潾（年幼）：老師！您在我的圖上畫了一朵花——這種草不開這種花！
奧芮：對。
珂潾（年幼）：那是錯的！
奧芮：是錯的。現在這張圖上有一個妳一眼就看得出來的錯。
奧芮：以後每次妳看這張圖，妳都會想：這裡有一處是假的，那別的地方呢？
奧芮：不知道的，就不要寫成答案。寫不下「不知道」的時候，就畫一個錯的。
珂潾（年幼）：……別人會以為我畫錯。
奧芮：會讀的人不會。
（回憶止。）

珂潾：會讀的人不會。
珂潾：所以這根管子是寫給會讀的人的。
珂潾：問題是，老師，我會讀到哪一層，連我自己都不確定。
（她把殘葉壓回束裡。雲底下，某一塊青光暗了一下，又亮回來。）

#### M2-20　中頭目 B：〈遲步〉

- **地點**：黑帶東側的寬橋

```

珂潾：牠在修剪。同一塊地方，剪了又剪，已經沒有東西可以剪了。
珂潾：牠不是要過去。牠是不知道除了過去還能做什麼。
```

**遭遇：卡線的拱背亞成獸〈遲步〉**（詳見 E-12）

- 味序：**苦—澀—苦—腥—澀—甜**（末位的甜是牠自己的糖流，不處置）
- 對象行動：踱步使橋轉「繃」，珂潾每回合須先掌讀再行動，否則被橋吐回（體力 −）；苦符存在時有機率衝向黑帶，撞擊使帶內的鹹滲出（珂潾感官負荷 +，味序前端臨時插入鹹）。
- **穩定**：清空味序後，以「引」塗葉招來燈蛾群，沿一座較窄的舊橋鋪出一條光路，把牠引向獸群折返的方向（消耗引 ×2；耗時；穩定後牠在舊橋口停了一下，才跟著光走）。
- **拆線**（`c2_line`＝拆開）：在黑帶上解開一掌寬讓牠通過。立即結束遭遇；播 +1；霧冠連通度 +2；但帶內的鹹外滲——章末長喉橋的味序前端多一個鹹符，且 S2-05 的選項受限。珂潾的話：

```
珂潾：一掌。牠過去以後我封回來。
珂潾：我知道「封回來」跟「沒開過」不是同一件事。寫上去。
```

- **隔離**：以灰把黑帶往東延長一段，牠會退走（`c2_ash`＝乙時可用；焚 +1；連通度 −3；獸群此後不再走西冠）。
- **撤離**：牠繼續踱，橋在兩日後降為「閉」。

- **取得**：葉帖 **F-029〈長喉橋・降根〉** 的前置觀察（舊橋口的降根）；見識大量。
- **抉擇與向度**：穩定＝播 +2、連通度 +2（`c2_line`＝繞行）；其餘如上。
