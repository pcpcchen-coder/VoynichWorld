## 2. 本章主題與一句話

**一句話**：她把裂開的東西重新接上，然後發現接上的地方再也不會是原來的樣子——而那不一定是壞事，也不一定是好事。

**主題**：修復的倫理。三個問題貫穿全章：

1. 一段被判死的脈，誰有資格說「再一次」？（珂潾 × 燼，互相驗證）
2. 止痛到哪裡為止是藥，從哪裡開始是聽不見？（縫苦；F4b）
3. 如果讓五種葉都活下來的方法，是讓它們不再是五種——那救的是什麼？（F4）

**脈況階段**：流慢 → 封脈。全章可見狀態機：

| 階段 | 縫林裡看得見的樣子 |
|---|---|
| 流慢（M4-01～M4-12） | 沉木道水位差消失、黑水表面起細泡、汲蟲亮點稀疏；癒合縫發亮（分流壓力上升） |
| 封脈（M4-13～M4-25） | 東北側長出骨白色硬化斷面「硬門」；門外縫葉自裂、門內縫葉互相遮光 |
| 依 F4 分歧（M4-26 以後） | 全林：灰葉漸多、硫味被吃掉／局部：一條灰帶／不傳：硬門內推、外三分之一失守 |

**環境母題**

- **光**：五種葉把歐柯的橙光篩成五種斑——拾光葉下是靛、羽息葉下是碎青、蠟守葉下是暗紫、篩風葉下是一粒一粒的琥珀孔光、刺苦葉下幾乎沒有光。走十步換五次顏色。癒合縫在壓力下發亮，像皮膚底下的白線。
- **聲**：沒有鐘管草。取而代之的是纖維繃緊的細吱聲、縫線撕開時的濕響、慢流沼的氣泡。安靜的時候聽得見自己吞口水。
- **味**：五層不同的苦（五葉的縫苦比例各異），健康時像五個聲部；自裂時五種苦同時到，分不出先後。沼底偶爾翻上蛋臭。

## 3. 本章新系統規格

### 3.1 嫁接（手技，味序清空後或獨立觸發）

對象帶有結構狀態「**裂口**」時，味序清空只算「止住」，須完成嫁接才算**穩定**。三步：

| 步 | 操作 | 判定 | 失誤後果 |
|---|---|---|---|
| ① 對齊維管 | 轉動接穗，把斷面的色環對上：水束（青）、糖束（琥珀）、訊號絲（銀白）。可用舌下微嚐確認——對上時甜味「接續」不斷 | 三束對上幾束 | 少對一束：接口存活但該功能減半；糖束對錯：三潮後排斥 |
| ② 纖維固定 | 以韌皮纖維或紉蟲絲纏繞，按住調鬆緊（太緊勒斷糖流、太鬆錯位） | 鬆緊落在綠區的時間 | 太緊：對象長出新味符「澀」；太鬆：裂口回彈 |
| ③ 礦物封合 | 塗封泥（礦泉結晶粉＋菌絲膠），控制厚度；要留氣孔 | 厚度與氣孔數 | 太厚：縫口悶出「腥」；太薄：感染（下次來時味序 +1 苦） |

完成後有「**脈紋回饋**」：珂潾掌心脈紋亮起的節奏與對象糖流同步＝接通。這是無介面確認。
嫁接最佳時段是**靜潮**（接口不受池潮拉扯）；非靜潮可做，但 ② 的綠區變窄。

### 3.2 性狀交換（配置解謎）

- 每株縫葉有五條「葉系」，每條葉系帶一項功能（拾光／羽息／蠟守／篩風／刺苦）與一個當前配比。
- 玩家可在砧園的交換台或現場，把一條葉系的枝段從 A 株移到 B 株，讓一片林地的配比回到「可承受範圍」。
- **沒有單一最佳解**：每個解都讓某一株變強、某一株變弱。結算畫面只顯示「誰讓了什麼」。
- 交換一律要完成一次嫁接手技。

### 3.3 治療窗（劑量撥盤）

- 調劑時出現撥盤：低＝訊號、中＝藥、高＝毒。窗寬取決於藥材來源葉型、接合年齡、對象體型。
- 縫苦的窗最窄。取自刺苦葉的最烈、窗最窄；取自蠟守葉的最緩、窗稍寬但起效慢。
- 劑量落在「訊號」：對象警覺上升（味序首位重排）；落在「毒」：對象失衡上升並留下「不可逆傷害」記錄（寫進該葉帖的筆記，無法消除）。

### 3.4 縫苦依賴（F4b）

| 狀態 | 效果 |
|---|---|
| **未用** | 無變化。裂縫帶一類高苦區域的環境負荷照常累加；需較多味覺沖洗液。M4-10 改為漣教「導壓分擔」（漣指令〈導壓〉可替珂潾卸除少量負荷，冷卻較長） |
| **使用中** | 感官負荷上限 +25%；高苦區域的環境負荷減半。代價：每場遭遇第一次嚐味有約兩成機率「**遲鈍**」（首位味符延後一回合才顯示，或顯示為「？」）；苦與澀較易混讀；每過三個薇蘿日，維持同樣效果所需的苦籤 +1（耐受）。斷用會「回湧」：一日內負荷上限 −15% |
| **已戒** | 本章不可達成。支線 S4-04 完成後取得「苡的減量表」（戒法知識），第 5 章起可執行 |

道具名：**苦籤**（一小段浸過蠟守葉縫苦稀液的韌皮纖維，含於舌側）。

### 第一段：入林（M4-01～M4-06｜80 分）

#### M4-01〈沒有聲音的渡口〉（全文｜12 分）

- **地點／時段**：斑光渡前的最後一段水路 → 斑光渡｜長晨，珂月漲潮
- **出場**：珂潾、漣、撐篙人（無名）
- **目的**：承接第 3 章末的失聲；讓玩家第一次嚐到 F3 在下游的味道；建立縫林的光與聲。
- **環境狀態**：池舟滑進林緣的瞬間，橙色的天被葉子切成五種顏色，落在珂潾手背上像五塊不同的瘀青。水很慢，篙插下去，拔起來的泥是溫的。

```
（黑畫面。只有篙入水的聲音。三次。）
珂潾：三天。我還在等它響。
漣〔訊號：水壓輕拍兩下—停—青光一短〕（珂潾譯：「聽／沒有」。牠用的是「池不回答」那個詞，尾音收得很短。大概是：別再聽了。）
珂潾：我沒有在聽。我在確認它沒有響。這是兩件事。
漣〔訊號：苦——很大一口，誇張的苦〕（珂潾譯：牠把我剛才那句話用我自己的苦味註記回送給我，放大三倍。意思很清楚：妳嚐嚐妳在說什麼。）
珂潾：收到。很苦。謝謝。
（畫面亮起。舟進入林緣，光斑開始在船板上換色。）
撐篙人：鐘潮那邊下來的？
珂潾：對。
撐篙人：那邊的草，真的都不叫了？
珂潾：……不叫了。不是慢慢小聲。是一個拍子還沒唱完，就沒有了。
撐篙人：我們這裡本來就沒幾株。可是它們一停，林子裡別的聲音就變大了。妳把手放水裡。不要嚐，先聽。
（玩家互動：掌心貼水面。）
珂潾：水流的聲音……沒有。太慢了。有別的。很細，像——
撐篙人：像線繃緊。
珂潾：像線繃緊。很多條。
撐篙人：那是縫。以前要爬到縫層、耳朵貼著樹才聽得到。現在坐在船上就有。嫁接師說那叫「在商量」。我看不像商量。
```

（教學提示：取樣。玩家以滴管取一滴入林的水，選高稀釋。）

```
【若 F3＝疏通】
珂潾：先是甜。薄的。然後——焦。很細，像磨碎的。不是這裡的焦。是渣。
珂潾：……是我沖下來的。
漣〔訊號：焦—水壓向下游—停頓—觸她的腕內〕（珂潾譯：「焦／往下」。最後那個觸碰不在詞彙表裡。可能是「知道」。也可能是「妳的」。）
珂潾：管通了，渣要有地方去。我那時候說渣會稀釋。稀釋不是消失。稀釋是分給比較多的池。
撐篙人：妳在跟誰說話？
珂潾：跟一滴水。牠回答得比我想的清楚。

【若 F3＝切除】
珂潾：先是甜——少。比葉帖上記的少一半。不是病。是沒有來。
珂潾：上游那一刀，在這裡的味道是「少」。
漣〔訊號：內光收斂—黏液在船舷留下一小片—水壓：遠離岸〕（珂潾譯：牠在掉黏液。牠緊張的時候會這樣，掉下來的那片上面有牠帶了很久的東西。）
（珂潾用葉片把那一小片黏液接起來，放回水裡。漣沒有看她。）
珂潾：線守住了。我嚐得出來——沒有焦跟過來。我不喜歡這個證據。但它是證據。
撐篙人：水是少了。上一個靜潮開始，水位尺每天讓一格。嫁接師罵了三天，不知道該罵誰。
珂潾：罵我可以。我在場。

【若 F3＝改道】
珂潾：先是鹹。舊的鹹，像放了很久的礦。水是從西北來的——縫林的水不該從西北來。
珂潾：是那條舊路。
漣〔訊號：舊—鹹—水壓繞一圈—背冠最外層微暗〕（珂潾譯：「以前的水／繞」。牠背冠最外面那一層還沒亮回來。開那條路牠付了什麼，我到現在只譯出一半。）
珂潾：水到了。帶著別的池的舊帳一起到。栓還在原地，我們只是不走那扇門。

```
（舟靠岸。渡口的水位尺是一根活的砧木，刻痕被樹皮吃掉了一半。）
珂潾：（對漣）我以為安靜會比較不痛。

#### M4-02〈五種影子〉（12 分）

- **地點／時段**：斑光渡上方的第一段砧道（縫層）｜長晨後段
- **出場**：珂潾、漣（在砧道下的水裡同行）、梭
- **目的**：見到健康的縫葉；葉帖 F-040；認識學徒梭；預告自裂。
- **環境狀態**：砧道是活的，踩上去往下沉半指再托回來。腳邊一株縫葉的五種葉各晃各的，主莖卻只有一個節奏。

**對白重點**

```
梭：記脈者！真的記脈者！妳那個是葉帖對不對？一張一則、不縫的那種？
珂潾：一張一則。不縫。你們縫葉子，我們不縫紙。算是扯平。
梭：妳畫它幹嘛？這株是好的。
珂潾：所以要畫。壞掉的大家都會記。好的沒有人記，等它壞了，就沒有人知道它本來該是什麼味道。
梭：甜的啊。
珂潾：幾股？
梭：……甜還分股？
珂潾：五股。拾光的最淡，刺苦的最短，蠟守的來得最晚。你舌頭底下那一下，其實是五下。
梭：（把葉片塞進嘴裡，很久）……我只有三下。
珂潾：三下很好了。我第一次也只有三下。我老師說，剩下兩下不是嚐不到，是還沒學會等。
```

```
（梭指著自己正在纏的那道縫——縫線比其他的亮。）
梭：這條三天前開始亮。師父說亮就是在吵。我纏緊一點，它就安靜一下。
珂潾：（舌尖極輕）苦。在甜前面。……它不是在吵。是刺苦葉先拿了。
漣〔訊號：兩股水壓合一—其中一股忽然變細〕（珂潾譯：「接上的／有一邊少了」。牠在水下也嚐得到——根那一頭，有一路糖沒下來。）
梭：水裡那個是——
珂潾：漣。牠不是「那個」。牠比你師父的師父年紀都大，而且牠剛剛比我早說對。

- **取得**：葉帖 **F-040〈縫葉·五葉全株〉**。
- **四向度**：錄 +1（記錄健康原型）。

#### M4-03〈五葉埠〉（15 分）

- **地點／時段**：五葉埠｜正午（葉隙光最碎的時候）
- **出場**：珂潾、梭、紉、綰、苡、聚落居民；漣在埠下的引水槽
- **目的**：建立聚落與四位核心當地角色；交代脈況；埋下兩難；葉帖 F-041～F-045 的採集委託。

**對白（關鍵段全文）**

```

珂潾：水位尺的讀數、五條葉系各一段脫落枝，還有一張能攤開紙的桌子。我會還。桌子會還得比較乾淨。
紉：（看了她一會兒）……梭，給她東棚那張。那張反正也沒有人坐了。
珂潾：上一個記脈者——

珂潾：有可能寫了。先讓我嚐東圃的水。我不想用別的地方的答案回答妳的圃。
紉：（停了一下）……這句倒是像個幹活的人說的。
```

```
（苡把浸好的纖維夾起來晾，朝珂潾看了一眼——看的是她的喉嚨。）
苡：妳一路吞口水。從渡口到這裡，我數了，十一次。
珂潾：林子的苦是常駐的。我的舌頭沒有門。
苡：我這裡有門賣。很小的門，開關都要付錢。等妳想買的時候再來。不想買最好。
珂潾：妳對每個客人都這樣推銷？
苡：我對每個客人都先勸退。會回來的，都是真的需要的。還有需要過頭的。兩種我都得看著。

（綰削完一枝，舉到光下轉。五種光斑依序爬過接穗的斷面。）

#### M4-04〈第一道縫〉（15 分）

- **地點／時段**：砧園｜午後，稜月與珂月互抵的短靜潮
- **出場**：珂潾、綰、梭；漣在砧園的引水槽
- **目的**：嫁接三步教學；讓玩家第一次親手把一道裂口接上；本章標題句的第一次變奏。
- **環境狀態**：靜潮。引水槽的水面平得能照出葉影；砧木的根不再被潮拉扯，縫口短暫地不亮了。綰說，這種時候樹才肯讓人碰。

**摘要**：綰挑了一株縫線剛裂開兩指寬的幼縫葉，讓珂潾動手。遭遇（教學）：味序「苦→澀」，清空後出現「裂口」。三步手技依序教學。第一次固定必定略緊（腳本），對象長出一個「澀」，綰才示範怎麼讓手鬆。

**對白（全文）**

```
綰：先看斷面。三圈顏色。青的走水，琥珀的走糖，最裡面那幾根銀的——
珂潾：走話。
綰：我們叫「訊絲」。走話也行。妳們記脈者講話比較省。
（步驟①：玩家轉動接穗。對上糖束時，舌下的甜「接續」不斷。）
珂潾：對上了。甜沒有斷。……水束偏了半圈。
綰：那就再轉。妳急什麼？它裂了三天，不差妳這三口氣。
（步驟②：纏纖維。腳本：第一次必定偏緊。）
珂潾：澀。剛剛沒有的。——是我綁的。
綰：是妳綁的。妳怕它再開，所以勒它。糖下不來，它就乾給妳看。
綰：手給我。
（綰用右手覆住珂潾的手背。那隻手的後三指是硬的，沒有溫度變化。）
綰：這三根沒感覺了。四十年，刺苦葉的汁滲的。所以我現在纏線不靠指頭，靠聽。——鬆。再鬆。聽到它不吱了沒有？
珂潾：……聽到了。
綰：那就是了。它不是要妳把它綁回去。它是要妳扶著，等它自己長。
（步驟③：封泥。留氣孔。）
梭：氣孔要留三個！我第一次封滿，隔天整道縫都悶臭了，師父叫我用舌頭——
綰：梭。
梭：——用舌頭反省。我閉嘴。
（完成。脈紋回饋：珂潾掌心的青紋亮起，一下、一下，和樹的糖流同拍。）
珂潾：通了。五股。第四股比較細。
綰：會細一輩子。那一道縫以後就是它的一部分，新葉子會繞著它長。妳摸那邊那株老的——疤都比幹粗。
珂潾：所以它不會回到原來的樣子。
綰：誰跟妳說修好是回到原來的樣子？回到原來的樣子，叫沒發生過。發生過了。
```

```
漣〔訊號：兩股水壓合為一股—甜，很淡—水壓停在她掌下〕（珂潾譯：新詞。兩股合一——「接上了」？牠把那個甜停在我手底下。我先記成「縫」。也可能只是「靠近」。）
```

- **玩法**：嫁接三步教學。之後所有帶「裂口」的對象皆可施作。解鎖砧園交換台（M4-08 使用）。
- **取得**：葉帖 **F-046〈癒合縫·剖面〉**、**F-180〈封泥·礦物封合劑〉**（綰口述配方，珂潾在味診台調出第一份即入帖）。
- **四向度**：播 +1（完成第一次修復）。漣詞彙 +1（縫）。

#### M4-06〈讀風〉（全文｜13 分）

- **地點／時段**：東圃外側的慢流沼｜藍昏前，風由沼面往林內
- **出場**：珂潾、燼、漣（水下）

```
燼：停。風。

燼：不耐問。

```

**遭遇：黑膜毯**（味序：鹹→腥→鹹→焦）

```
珂潾：先是鹹。銅的那種。底下——腥。有東西死在膜下面。汲蟲，很多。

珂潾：收到。先取，再架。
（玩家依序：燼灰中和鹹→清淤處理腥→燼灰→靛乳疏通焦。燼遞來的灰不是散的，是一小包一小包摺好的葉包，每包上壓著一行很小的字。）
燼：半錢一包。硯包的。出發前包了四十包。
珂潾：上面寫什麼？
燼：「多了水會澀。手別抖。」
珂潾：我的手沒抖。是砧道在動。
燼：字條沒寫砧道。
```

```
（黑膜縮回岸邊，露出底下的水道。一點一點的淡青亮點重新在管壁上排成列——汲蟲。）

#### M4-07〈裂縫帶〉（12 分）

- **地點／時段**：裂縫帶｜次日長晨，霧薄
- **出場**：珂潾、燼、梭（帶路）；漣走根沼層
- **目的**：見到縫葉自裂的全貌；讓玩家親身經歷感官負荷逼近上限、讀值失真；為縫苦鋪路。

**摘要**：裂縫帶的環境負荷每十秒 +1。連續兩場「自裂縫葉」遭遇（味序：苦→澀→苦／苦→苦→澀→甜，後者的甜是陷阱）。第二場時負荷必定越過 70%，讀值出現假味符；腳本安排珂潾誤把假的「鹹」當真，用了燼灰——反噬。燼的隔離膜擋住外溢，鄰株沒事。珂潾在林間空地嘔吐，沖洗掌心三次，仍分不出苦與澀。

燼：第三次了。同一片葉。
珂潾：我要確認。
燼：妳確認過兩次。兩次一樣。
珂潾：兩次一樣，不代表第三次——（停）……對。我在重複。

```
（誤治之後。珂潾跪在空地邊緣，額頭抵著砧木。）
珂潾：鹹是假的。那是上一株留在我舌頭上的。我把殘留當成讀值。
燼：膜擋住了。旁邊三株沒吃到灰。沒有東西因為這個壞掉。
珂潾：這一次。

梭：（小聲，湊到燼旁邊）她是不是……每一株都嚐得到？它們撕的時候？
燼：每一株。
梭：那她走在這裡面，不就像——
燼：像站在火裡，還要報火的顏色。去裝水。

```
漣〔訊號：撕——一股水壓忽然分岔＋短促的辛——重複，很多次——然後觸她的腳踝，很輕〕（珂潾譯：新詞，我希望我不必學的一個。「裂開」。牠在水下數給我聽，這一帶的根有多少處正在分岔。我數到十九就沒辦法再數。牠碰我的腳踝。那不是詞。）

#### M4-08〈性狀交換〉（12 分）

- **地點／時段**：砧園交換台｜同日午後
- **出場**：珂潾、梭、紉；燼在砧園外緣看風
- **目的**：性狀交換解謎教學；「傳閱」一詞的日常用法；埋下 F4 的核心問句。
- **環境狀態**：交換台是一截橫放的老砧木，台面上密密麻麻全是舊接口的疤，摸起來像一張被反覆修改的地圖。台邊六株待調的縫葉，其中一株的刺苦葉長得比其他四種加起來還多。

**摘要**：紉交給珂潾一小片林地（六株）的配比表。其中「抑葉株」的刺苦葉失控，壓制了同株其他四葉；鄰株卻缺防禦，被菌膜啃。玩家把一條刺苦葉系從抑葉株移到缺防禦的鄰株。結算顯示「誰讓了什麼」——無論怎麼解，總有一株變弱。

**對白重點**

```
紉：我每天做的就是這個。決定誰少一點。
珂潾：沒有誰都不少的解？
紉：有。水夠的時候。水夠，五種葉自己會讓。現在水不夠，就得有人替它們讓。那個人是我。
珂潾：您怎麼決定？
紉：誰死了旁邊的會跟著死，就先保誰。……妳那個臉，是覺得這樣不對。
珂潾：我沒有覺得不對。我在想，您那套規則，跟灰棚那位隊長的，差多遠。
紉：差一把火。我用刀，他們用火。刀下去還能接回來。
燼：（從園外，沒有回頭）刀慢。
紉：火不長回來！
燼：對。兩個都對。
```

```
梭：其實好用的東西會自己傳。上上個霧季，北圃有一株學會把蠟長厚，隔一季，整片東坡的蠟守葉都厚了。沒有人接，是根底下自己遞過去的。我們叫「傳閱」——像一張紙大家輪著看。
珂潾：紙輪完，還是同一張紙。葉子輪完呢？
梭：就都會了啊。
珂潾：都會了。還是都一樣了？
梭：……這有差嗎？
珂潾：我不知道。所以我問你。
```

- **玩法**：性狀交換教學關（之後砧園另有四題選做題，計入支線外的自由探索）。

- **四向度**：依解法——把強者削弱以救弱者：播 +1；直接移除弱株保全其他：焚 +1。

#### M4-09〈苦籤〉（全文｜15 分）

- **地點／時段**：砧園最低一座浮基上的調劑室｜藍昏初
- **出場**：珂潾、苡
- **目的**：治療窗（劑量撥盤）教學；珂潾**第一次**使用縫苦（玩家可選不用）；F4b 起點。第 3 章她婉拒過一次——這一場要讓「這次為什麼不同」說得出口。

```

珂潾：上一次有人遞這個給我，我說不用。
苡：那時候為什麼不用？
珂潾：那時候痛的是一條管。我分得出哪裡在痛，就能繞著它工作。這裡是一整片林。沒有「繞」。
苡：好。我講三件事。講完妳再決定。中間不要點頭，點頭的人都沒在聽。
苡：一。它不是把苦拿走。苦還在，是妳離它遠一步。遠一步，妳撐得久；遠一步，妳也會慢半拍。妳的讀值有時候會晚到。不是每次。妳不會知道是哪一次。

苡：三。停的那天，林子會比妳記得的更吵。吵一整天。那不是林子變壞，是門拆了。
珂潾：您講得像自己走過。
苡：走過。走進去兩個清季，花四個清季走回來。我的舌頭現在比以前鈍一成，回不來的那種。所以這個室歸我管——全埠只有我知道哪一句勸是廢話。

```

#### M4-11〈第三沉木段〉（全文｜20 分｜互相驗證之一：燼判死，珂潾救回）

（停頓。）
珂潾：再一次。

#### M4-16〈硫滲窪〉（14 分）

**對白重點**

```
燼：三步。停。……再兩步。停。蹲。
珂潾：你連我蹲不蹲都管。

## 6. 支線任務（10 條｜180 分）

### S4-01〈聽縫的人〉（20 分）

- **委託人**：箜，鐘潮環來的脈聽者。鐘管草不叫之後，她的耳朵沒有東西可聽，一路走到縫林。
- **起因**：她發現縫繃緊的吱聲有高低，想證明「聽縫」能比嚐更早找到下一株要裂的樹。
- **步驟**：①陪她在三處砧道貼耳記音；②玩家以嚐味驗證她標的五株（四中一誤）；③那一誤是一株健康株——它在長新葉，聲音和快裂的一樣。
- **對白重點**
  ```
  箜：長和裂，聽起來一樣？
  珂潾：都是縫在受力。一個往外長，一個往外撕。妳的耳朵沒錯，是這兩件事本來就像。
  箜：那我這雙耳朵還是沒用。
  珂潾：四中一。我的舌頭在裂縫帶裡，三中一。
  ```
- **抉擇**：把她的方法寫進葉帖旁註（錄 +1；此後地圖顯示「將裂株」標記，偶有誤報）／勸她別把未驗完的方法教給嫁接師（無標記；箜離開縫林，第 5 章濕原口可再遇）。
- **獎勵**：見識；「縫鳴圖」或池糖籤 ×3。

### S4-02〈靜潮砧時〉（18 分）

- **委託人**：晷，埠上的曆手，管一根刻滿光斑記號的曆柱。
- **起因**：水位亂了之後，曆柱報的靜潮老是差半刻，嫁接師接在錯的時辰，接口被潮扯開。
- **步驟**：①在冠層三個葉隙記下稜、珂、墨三月的光斑落點；②回曆柱比對——不是月亂了，是冠層的葉換了朝向，光斑的位置跟著偏；③重刻曆柱。
- **對白重點**：晷「月亮沒錯過。錯的是我們拿來看月亮的葉子。」
- **抉擇**：照現在的葉向重刻（實用；日後葉向再變又要重刻）／另立一根不靠葉隙、只靠水面倒影的新柱（多花一倍時間；播 +1）。
- **獎勵**：葉帖 **F-130〈縫林光斑曆·靜潮砧時〉**；此後地圖顯示下一次靜潮倒數。

### S4-03〈一池幼體〉（20 分｜M4-15 後）

- **委託人**：洄，淺鏡池的池守。
- **起因**：救出的幼潾暫養在引水槽，但補菌到一半中斷，需要一座有儲水瘤木的新池。
- **步驟**：①與漣沿沉木道找三處候選池；②逐池嚐味（一處太鹹、一處太靜、一處有緩鰭巡游但離聚落遠）；③搬遷——幼體離水時要靠珂潾掌心的水膜。
- **對白重點**
  ```
  洄：妳不用因為那件事來幫我。
  珂潾：我是因為那件事來的。我不想假裝不是。
  洄：……那就別只搬這一趟。明年清季牠們回來，妳人在哪裡？

### S4-05〈家葉株〉（18 分）

- **委託人**：茉，九歲，埠上的孩子。
- **起因**：她家門口的縫葉，每個孩子出生就接上一枝。現在七枝擠在一株上，縫開始亮。
- **步驟**：①診斷——養不起七枝，得取下兩枝；②取哪兩枝：最老的那枝（曾祖的，最耗糖）、最新的（茉的弟弟的，還沒癒穩）、或已遷走的姑姑的；③嫁接手技，把取下的枝移到別株。
- **對白重點**：茉「取下來的還是我們家的嗎？」／珂潾「它會長在別人家門口。妳可以去看它。它不會記得妳，但是妳記得它。」
- **抉擇**：三選二。每種組合，家中不同的人會來跟珂潾說一句話（無對錯）。
- **獎勵**：葉帖 **F-055〈家葉株·七枝砧〉**；錄 +1。

### S4-06〈護送一整套〉（18 分）

- **委託人**：杼，種源護送者，背著一只要用雙手抱的濕匣。
- **起因**：要把一套完整的縫葉配方送過沉木道到斑光渡——不是種子，是一段軸、五枝穗、一團根座菌、一小匣汲蟲休眠囊，缺一樣到了那邊都組不起來。
- **步驟**：護送關卡（三段沉木）。每段有一樣東西出狀況：菌團過熱、休眠囊受震、一枝穗開始排斥。玩家逐一處理。
- **對白重點**：杼「人家都說我送種子。我從來沒送過種子。我送的是一桌人，少一個就開不了飯。」
- **抉擇**：途中若必須捨一樣，捨哪樣（捨穗：到了剩四葉；捨休眠囊：到了要等當地汲蟲慢慢住進來）。全保需耗兩份池糖液。

### S4-07〈濾幕上的病〉（15 分）

- **委託人**：籮，霧濾師。

- **步驟**：①取濾幕樣本，嚐（苦—停—苦—停：病原訊號）；②查出源頭是篩風葉下的孔光菌毯生了病；③處置菌毯（味序：苦→澀→苦）。
- **抉擇**：菌毯治好前，濾幕開還是關——開（空氣通，三戶人家的縫葉染上苦；融 +0，播 +1）／關（悶兩日，一位老人搬到渡口去住；焚 +1）。

### S4-08〈灰的劑量〉（18 分｜M4-06 後）

- **步驟**：①在三處慢流各做一次燼灰中和，記下「澀」出現的時間；②與灰毯圈的「被吃掉的鹹」對照；③與銖重訂本地用量。
- **對白重點**
  ```
  銖：那位隊長的灰包，包得很仔細。仔細地錯。不是包的人錯，是水不一樣。
  燼：（看完新的用量）改。四十包全拆，重包。
  珂潾：你不辯一下？
  燼：水不一樣。有什麼好辯。……硯會想知道。寫給硯。
  ```
- **抉擇**：把新用量寄回鐘潮給硯（燼互信 +1；錄 +1）／只在本地用。
- **獎勵**：葉帖 **F-182〈燼灰與硫食·慢流用量〉**。

### S4-09〈共掌〉（15 分）

- **委託人**：沐，緩融派行腳者。
- **起因**：五位嫁接師要同時接一株老砧的五條葉系，手上的拍子對不起來，已經失敗兩次。沐提議「共掌」——五人掌心相貼一刻，分享拍子，可逆。

- **對白重點**：沐「到晚上就退了。我不騙妳，有人退得慢。我不說這是沒有代價的，我只說它是真的有用。」
- **抉擇**：珂潾參與共掌（融 +1；短暫取得他人的手感，下一次嫁接 ② 必成；當晚對詞時漣停頓較久）／只旁觀記錄（錄 +1）。
- **獎勵**：見識；紉蟲絲 ×2。

### S4-10〈偷枝的人〉（18 分）

- **委託人**：檀，記脈院駐林記錄員。

- **步驟**：①嚐龕口封泥上的掌紋殘留；②追到斑光渡——是鄰林一位嫁接師，她自己的林已在門外，想帶走三枝，到別處重起一圃；③她沒有配方菌團，只有穗。
- **對白（抉擇處全文）**
  ```
  檀：照院規，未經清點的種源不得離龕。
  偷枝者：照妳們院規，我的林是先被畫完，然後才沒的。
  檀：（很久）……那一份也是我畫的。
  珂潾：她只拿穗，到了那邊接不活。要嘛拿回來，要嘛讓她把整套帶走。

- **抉擇**：追回（錄 +1；偷枝者空手離開）／補給她整套配方後放行（播 +2；龕內存量 −1，M4-26 階段①可用的替換枝少一枝）／交由檀照院規處置（無向度；檀放了她，自己補寫一份失竊記錄）。

**1｜自裂縫葉**
- 健康原型：五葉朝同一塊光、縫不亮、甜五股先後到。替網路做：以五種葉補滿破碎光譜，五層葉面養著發光菌與汲蟲幼體。
- 斷網狀態：縫發白、刺苦葉壓住其他葉、沿縫撕開。
- 味序範例：苦→澀→苦／苦→苦→澀→甜（末位的甜是還活著的那一葉，誤治會傷它）。
- 特殊行為：「搶糖」——每回合隨機一葉抽走糖流，味序首位換成澀；帶「裂口」，須嫁接收尾。

**2｜抑葉株**
- 健康原型：刺苦葉只在被啃時釋苦。
- 失控：防禦訊號停不下來，持續抑制同株四葉與鄰株。
- 味序：苦→苦→焦→甜。
- 特殊行為：每次誤治，苦擴散到鄰株（鄰株味序 +1 苦）；最佳解常是性狀交換而非用藥。

**3｜紅縫**
- 健康原型：見 1。此為縫葉轉燼冠的中間型：冠頂暗紅、微熱，葉形仍在。
- 味序：鹹→苦→鹹→焦→甜。
- 特殊行為：每三回合「升溫」，灌入體力傷害；有流動水時每回合自消少量鹹；拖過十回合進入不可逆（冠須切除）。燼的判定在此為「邊緣」。

**4｜灰縫株（友善）**
- 縫內住著來自硫食毯的吃硫夥伴；五葉俱全。
- 味序：甜→甜→甜（任何處置皆為誤治；教玩家「不處置」）。
- 特殊行為：周圍一圈無毒氣；取閱芽須用縫苦落在「藥」區讓縫鬆開。

**5｜黑膜毯**
- 健康原型：沼底可食的薄菌毯，替慢流濾去碎屑，是汲蟲幼體的苗床。
- 中毒狀態：缺氣後浮起、變黑、吐蛋臭的泡。
- 味序：鹹→腥→鹹→焦。
- 特殊行為：泡破時依風向灌毒（〈讀風〉可預告）；膜下常藏活的汲蟲幼體，整張掀掉會一併流失。

**6｜亂縫紉蟲**
- 健康原型：紉蟲，指節長、多足柔軟，在新接口上吐韌絲幫忙固定，並刮食縫口的菌膜。腹內有淡青共生光。替網路做：天然的「纖維固定」。
- 失控：收不到「接好了」的訊號，見縫就纏——把葉纏死、把珂潾的掌套纏在樹上。
- 味序：苦→腥→苦。
- 特殊行為：「纏掌」——下一回合無法嚐味（須以防護掙開）；穩定後可取紉蟲絲，為嫁接②的上等材料。

**7｜縫光誤導的燈蛾群**
- 健康原型：以篩風葉下的青色孔光認路授粉。
- 失調：自裂株的白縫比花還亮，群體繞著裂口打轉，脫水。
- 味序：澀→澀→苦（群體讀值）。
- 特殊行為：不攻擊體力，只灌感官負荷（亂閃）；以池糖液霧化補水後，用遮光葉把白縫蓋住即可引離。不可大量驅散——散了的個體回不了群。

**8｜病孔光菌毯**
- 健康原型：篩風葉孔洞下的發光菌落，替燈蛾指路。
- 病態：光色偏黃，釋放反覆回返的苦。
- 味序：苦→澀→苦。
- 特殊行為：「回返」——清掉的苦兩回合後再生一次；須連續兩次對症才算清除。

**9｜銜芽獸（離群單隻）**
- 健康原型：前臂長的樹棲共生獸，尾有一片半透的光合膜，白日攤開曬光。銜著芽在樹與樹之間移動，把合適的芽放在縫口，用尾膜蓋住等它癒合——林中一半的自然傳閱出自牠們。
- 失控：分不清「合適」，什麼都接。
- 味序：苦→澀→甜→苦。
- 特殊行為：會搶走玩家手上的接穗；穩定後偶爾把一枚好芽放在珂潾手心（取得稀有枝段）。

**10｜攪泥者（裂獸型緩鰭）｜中頭目**
- 健康原型：緩鰭，慢流沼的大型兩棲濾食者。寬背上兩排藻板（半自養；長晨會浮到水面曬板），尾鰭緩慢畫圓，把上層的水捲到沼底——替網路做：替不流動的水「換氣」，沉木道的汲蟲全靠牠。
- 裂獸狀態：藻板半暗、在原地狂拍、揚起沼底的硫泡。仍保留原型輪廓與動作殘影。
- 味序：苦→苦→澀→腥→甜。
- 特殊行為：每兩回合一次「畫圓」（原生動作）——該回合對症效果加倍，且不可用隔離膜（會打斷牠）；拍水每回合傷體力並往漣的方向推硫泡；縫苦過量則沉底（事件失敗，須撤離重來，連通度 −2）。
- 穩定結果：恢復巡游，第三沉木段汲蟲回歸。

**11｜亂接群（裂獸型銜芽獸群）｜中頭目**
- 健康原型：見 9。群體單位，十餘隻。
- 裂獸狀態：在毒氣中不停嫁接，把芽接在石頭、枯枝、彼此的尾膜上；尾膜破損、轉暗紅。
- 味序：苦→澀→苦→甜→苦（群體共用一串；每清一符有兩三隻安靜下來）。
- 特殊行為：戰場受「風窗」限制——每回合可行動格由〈讀風〉決定；縫苦須用低窗（體型小），過量者會從枝上墜落（留下不可逆記錄）；「亂接」——把一枚隨機芽接到玩家裝備上，使下一次取樣讀值多一個假味符。
- 穩定結果：其中一隻示範放芽、蓋膜、等待——灰縫株的來歷由此得到一個可能的解釋（不確證）。

**12｜淺鏡池幼潾（救援）**
- 健康原型：幼體貼附在儲水瘤上補菌，藻脈初生，光弱而快。
- 危機：黑膜上浮，池水轉鹹腥。
- 流程：限六回合；以池糖液穩住幼體（澀）、以清淤開出水道（腥），漣逐隻引導。救出五至九隻。
- 特殊行為：幼體會往光亮處聚——燼把膜架在進水口後，那一側變暗，牠們會自己往漣的方向游。

**13｜千縫｜章末首領事件**
- 健康原型：縫林最老的一株縫葉，根座環抱閱脈井；全林縫葉的協調節律以它為準。
- 事件狀態：全身縫亮、五冠互遮、主縫三處同時裂。
- 味序（階段②）：苦→澀→鹹→苦→焦→澀→甜，每兩回合重排前三位；依 F4 不同——全林版多兩個甜陷阱，不傳版鹹加倍。
- 特殊行為：「落冠」（大枝墜落，〈讀風〉預告）；「井湧」（井水翻硫，〈架隔離膜〉擋井口）；「同拍」（階段③三處須在同一拍內封合）。
- 結果：必定存活，形狀永久改變。不是擊敗，是接住。

### 9.6 與總綱的出入／待總監裁決

1. **硯、炟不在場**：依總監補充，本章燼獨行；硯僅以灰包字條與 M4-30 的託帶字條出現，炟僅被提及。任務書原列「燼的小隊也進了縫林環」，已改。
2. **「淺鏡池必失」為腳本事件**：比照 F1「至少失去一階」的作法，M4-14／15 無法迴避；玩家只決定救出幾隻幼體與事後態度。若總監希望可迴避，需另給條件。
3. **F4b 本章不可達「已戒」**：依總綱「後續可戒除」，本章只提供戒法知識（苡的減量表）與一次自願的「吐籤對詞」（M4-29）。
4. **F4 的決定權**：設計為聚落三方各三票、由珂潾投最後一票。若總監認為主角不宜直接替聚落決定，可改為「珂潾的讀值報告決定哪一方多一票」，對白幾乎不必動。
5. **自創生物**：紉蟲、緩鰭、銜芽獸、硫食毯、儲水瘤木、孔光菌毯皆為本章 C 層新增，各附健康原型與網路功能；裂獸型僅作症候群使用，未設「裂獸王」。
6. **「兩結／三結」**：本章不知其在第 3 章的確切含義，故只引用其存在，未賦義；另加未解釋的「四結」作為伏線，含義請第 5 章或總監決定。
