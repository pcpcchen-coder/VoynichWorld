## 2. 本章主題與一句話

**一句話**：她把裂開的東西重新接上，然後發現接上的地方再也不會是原來的樣子——而那不一定是壞事，也不一定是好事。

**主題**：修復的倫理。三個問題貫穿全章：

1. 一段被判死的脈，誰有資格說「再一次」？（珂潾 × 燼，互相驗證）
2. 止痛到哪裡為止是藥，從哪裡開始是聽不見？（縫苦；F4b）
3. 如果讓五種葉都活下來的方法，是讓它們不再是五種——那救的是什麼？（F4）

**脈況階段**：流慢 → 封脈。全章可見狀態機：

| 階段 | 縫林裡看得見的樣子 |
|---|---|
| 流慢（M4-01～M4-12） | 沉木道水位差消失、黑水表面起細泡、汲蟲亮點稀疏；癒合縫發亮（分流壓力上升） |
| 封脈（M4-13～M4-25） | 東北側長出骨白色硬化斷面「硬門」；門外縫葉自裂、門內縫葉互相遮光 |
| 依 F4 分歧（M4-26 以後） | 全林：灰葉漸多、硫味被吃掉／局部：一條灰帶／不傳：硬門內推、外三分之一失守 |

**環境母題**

- **光**：五種葉把歐柯的橙光篩成五種斑——拾光葉下是靛、羽息葉下是碎青、蠟守葉下是暗紫、篩風葉下是一粒一粒的琥珀孔光、刺苦葉下幾乎沒有光。走十步換五次顏色。癒合縫在壓力下發亮，像皮膚底下的白線。
- **聲**：沒有鐘管草。取而代之的是纖維繃緊的細吱聲、縫線撕開時的濕響、慢流沼的氣泡。安靜的時候聽得見自己吞口水。
- **味**：五層不同的苦（五葉的縫苦比例各異），健康時像五個聲部；自裂時五種苦同時到，分不出先後。沼底偶爾翻上蛋臭。

## 3. 本章新系統規格

### 3.1 嫁接（手技，味序清空後或獨立觸發）

對象帶有結構狀態「**裂口**」時，味序清空只算「止住」，須完成嫁接才算**穩定**。三步：

| 步 | 操作 | 判定 | 失誤後果 |
|---|---|---|---|
| ① 對齊維管 | 轉動接穗，把斷面的色環對上：水束（青）、糖束（琥珀）、訊號絲（銀白）。可用舌下微嚐確認——對上時甜味「接續」不斷 | 三束對上幾束 | 少對一束：接口存活但該功能減半；糖束對錯：三潮後排斥 |
| ② 纖維固定 | 以韌皮纖維或紉蟲絲纏繞，按住調鬆緊（太緊勒斷糖流、太鬆錯位） | 鬆緊落在綠區的時間 | 太緊：對象長出新味符「澀」；太鬆：裂口回彈 |
| ③ 礦物封合 | 塗封泥（礦泉結晶粉＋菌絲膠），控制厚度；要留氣孔 | 厚度與氣孔數 | 太厚：縫口悶出「腥」；太薄：感染（下次來時味序 +1 苦） |

完成後有「**脈紋回饋**」：珂潾掌心脈紋亮起的節奏與對象糖流同步＝接通。這是無介面確認。
嫁接最佳時段是**靜潮**（接口不受池潮拉扯）；非靜潮可做，但 ② 的綠區變窄。

### 3.2 性狀交換（配置解謎）

- 每株縫葉有五條「葉系」，每條葉系帶一項功能（拾光／羽息／蠟守／篩風／刺苦）與一個當前配比。
- 玩家可在砧園的交換台或現場，把一條葉系的枝段從 A 株移到 B 株，讓一片林地的配比回到「可承受範圍」。
- **沒有單一最佳解**：每個解都讓某一株變強、某一株變弱。結算畫面只顯示「誰讓了什麼」。
- 交換一律要完成一次嫁接手技。

### 3.3 治療窗（劑量撥盤）

- 調劑時出現撥盤：低＝訊號、中＝藥、高＝毒。窗寬取決於藥材來源葉型、接合年齡、對象體型。
- 縫苦的窗最窄。取自刺苦葉的最烈、窗最窄；取自蠟守葉的最緩、窗稍寬但起效慢。
- 劑量落在「訊號」：對象警覺上升（味序首位重排）；落在「毒」：對象失衡上升並留下「不可逆傷害」記錄（寫進該葉帖的筆記，無法消除）。

### 3.4 縫苦依賴（F4b）

| 狀態 | 效果 |
|---|---|
| **未用** | 無變化。裂縫帶一類高苦區域的環境負荷照常累加；需較多味覺沖洗液。M4-10 改為漣教「導壓分擔」（漣指令〈導壓〉可替珂潾卸除少量負荷，冷卻較長） |
| **使用中** | 感官負荷上限 +25%；高苦區域的環境負荷減半。代價：每場遭遇第一次嚐味有約兩成機率「**遲鈍**」（首位味符延後一回合才顯示，或顯示為「？」）；苦與澀較易混讀；每過三個薇蘿日，維持同樣效果所需的苦籤 +1（耐受）。斷用會「回湧」：一日內負荷上限 −15% |
| **已戒** | 本章不可達成。支線 S4-04 完成後取得「蒔的減量表」（戒法知識），第 5 章起可執行 |

道具名：**苦籤**（一小段浸過蠟守葉縫苦稀液的韌皮纖維，含於舌側）。

### 第一段：入林（M4-01～M4-06｜80 分）

#### M4-01〈沒有聲音的渡口〉（全文｜12 分）

- **地點／時段**：斑光渡前的最後一段水路 → 斑光渡｜長晨，珂月漲潮
- **出場**：珂潾、漣、撐篙人（無名）

**遭遇：黑膜毯**（味序：鹹→腥→鹹→焦）

```
珂潾：先是鹹。銅的那種。底下——腥。有東西死在膜下面。汲蟲，很多。
漣〔訊號：腥—水壓向下—輕快三下—停〕（珂潾譯：「死的／下面」……後面三下很輕，是新的。小的？「小的也在下面」。牠說的是汲蟲的幼體。膜下面還有活的。）
珂潾：膜底下還有活的幼體。不能整張掀。
燼：膜。
（教學：〈架隔離膜〉。燼把一道半透的菌絲膜插進黑膜與漣所在的水道之間。）
燼：兩回合。膜下面的東西妳取不到。先取，再叫我架。順序。
珂潾：收到。先取，再架。
（玩家依序：燼灰中和鹹→清淤處理腥→燼灰→靛乳疏通焦。硯在岸上報燼灰的量。）
硯：這一勺是半錢。再多，水會澀。記脈者，妳手不要抖，我秤給妳。
珂潾：我的手沒抖。是砧道在動。
硯：那就請砧道不要抖。
```

```
（黑膜縮回岸邊，露出底下的水道。一點一點的淡青亮點重新在管壁上排成列——汲蟲。）
燼：那邊。那株。
（岸邊有一株半泡在水裡的縫葉殘樁。教學：〈不可逆判定〉。燼用管夾夾住殘樁基部，數到五，放開；換一片新試片貼在斷面，再用完好那側的手背去靠。）
燼：夾了不回彈。斷面不出汁。溫的——不是活的那種溫。不可逆。
珂潾：讓我嚐。
燼：嚐。
（珂潾取樣，高稀釋。）
珂潾：……沒有甜。沒有苦。沒有焦。什麼都沒有。不是壞掉的味道，是沒有人在的味道。
珂潾：你是對的。
燼：這次。
珂潾：你自己加了「這次」。
燼：加了。判定會錯。錯的時候妳要說。
珂潾：我會說得很大聲。
燼：正常聲就好。
```

- **玩法**：三指令教學。判定正確示範一次（殘樁可取「空樣本」，作為日後對照）。
- **取得**：見識；珂潾 28 級。汲蟲幼體保住 → 連通度 +1。
- **四向度**：播 +1。若玩家無視漣的提示整張掀膜：遭遇較快結束，但幼體流失，連通度 −1、漣在下一場的回應變短。

### 第二段：互相驗證（M4-07～M4-15｜120 分）

#### M4-07〈裂縫帶〉（12 分）

- **地點／時段**：裂縫帶｜次日長晨，霧薄
- **出場**：珂潾、燼、硯、炟、栒（帶路）；漣走根沼層
- **目的**：見到縫葉自裂的全貌；讓玩家親身經歷感官負荷逼近上限、讀值失真；為縫苦鋪路。
- **環境狀態**：這裡的縫全都亮著，白得刺眼，整片林像被人用石灰描過一遍接縫。每隔一陣就有一聲濕響——不是斷，是撕，像把一張泡過水的皮慢慢拉開。五種葉不再朝同一塊光：刺苦葉壓在拾光葉上面，把它的影子蓋成黑的。

**摘要**：裂縫帶的環境負荷每十秒 +1。連續兩場「自裂縫葉」遭遇（味序：苦→澀→苦／苦→苦→澀→甜，後者的甜是陷阱）。第二場時負荷必定越過 70%，讀值出現假味符；腳本安排珂潾誤把假的「鹹」當真，用了燼灰——反噬。燼的隔離膜擋住外溢，鄰株沒事。珂潾在林間空地嘔吐，沖洗掌心三次，仍分不出苦與澀。

**對白重點**

```
珂潾：苦。……苦。這一片也是苦。等一下，我再——
燼：第三次了。同一片葉。
珂潾：我要確認。
燼：妳確認過兩次。兩次一樣。
珂潾：兩次一樣，不代表第三次——（停）……對。我在重複。
```

```
（誤治之後。珂潾跪在空地邊緣，額頭抵著砧木。）
珂潾：鹹是假的。那是上一株留在我舌頭上的。我把殘留當成讀值。
硯：膜擋住了。旁邊那三株沒吃到灰。沒有東西因為這個壞掉，記脈者。
珂潾：這一次。
（她用了燼的那個詞。燼聽到了，沒有說話，把自己的水囊放在她手邊，走開兩步，站到上風處。）
炟：（小聲，對硯）她是不是……每一株都嚐得到？它們撕的時候？
硯：每一株。
炟：那她走在這裡面，不就像——
硯：像妳站在火裡面，還要報火的顏色。別問了，去把水囊裝滿。
```

```
漣〔訊號：撕——一股水壓忽然分岔＋短促的辛——重複，很多次——然後觸她的腳踝，很輕〕（珂潾譯：新詞，我希望我不必學的一個。「裂開」。牠在水下數給我聽，這一帶的根有多少處正在分岔。我數到十九就沒辦法再數。牠碰我的腳踝。那不是詞。）
```

- **玩法**：高苦環境負荷教學；假味符；誤治與隔離膜的互補。栒在此提到聚落調劑師蒔「有讓舌頭關小一點的東西」。
- **取得**：葉帖 **F-047〈自裂株·裂縫帶〉**。漣詞彙 +1（撕）。
- **四向度**：無。

#### M4-08〈性狀交換〉（12 分）

- **地點／時段**：砧園交換台｜同日午後
- **出場**：珂潾、栒、紉；燼在砧園外緣看風
- **目的**：性狀交換解謎教學；「傳閱」一詞的日常用法；埋下 F4 的核心問句。
- **環境狀態**：交換台是一截橫放的老砧木，台面上密密麻麻全是舊接口的疤，摸起來像一張被反覆修改的地圖。台邊六株待調的縫葉，其中一株的刺苦葉長得比其他四種加起來還多。

**摘要**：紉交給珂潾一小片林地（六株）的配比表。其中「抑葉株」的刺苦葉失控，壓制了同株其他四葉；鄰株卻缺防禦，被菌膜啃。玩家把一條刺苦葉系從抑葉株移到缺防禦的鄰株。結算顯示「誰讓了什麼」——無論怎麼解，總有一株變弱。

**對白重點**

```
紉：我每天做的就是這個。決定誰少一點。
珂潾：沒有誰都不少的解？
紉：有。水夠的時候。水夠，五種葉自己會讓。現在水不夠，就得有人替它們讓。那個人是我。
珂潾：您怎麼決定？
紉：誰死了旁邊的會跟著死，就先保誰。……妳那個臉，是覺得這樣不對。
珂潾：我沒有覺得不對。我在想，您那套規則，跟灰棚那位隊長的，差多遠。
紉：差一把火。我用刀，他們用火。刀下去還能接回來。
燼：（從園外，沒有回頭）刀慢。
紉：火不長回來！
燼：對。兩個都對。
```

```
栒：其實好用的東西會自己傳。上上個霧季，北圃有一株學會把蠟長厚，隔一季，整片東坡的蠟守葉都厚了。沒有人接，是根底下自己遞過去的。我們叫「傳閱」——像一張紙大家輪著看。
珂潾：紙輪完，還是同一張紙。葉子輪完呢？
栒：就都會了啊。
珂潾：都會了。還是都一樣了？
栒：……這有差嗎？
珂潾：我不知道。所以我問你。
```

- **玩法**：性狀交換教學關（之後砧園另有四題選做題，計入支線外的自由探索）。
- **取得**：葉帖 **F-048〈抑葉株〉**。
- **四向度**：依解法——把強者削弱以救弱者：播 +1；直接移除弱株保全其他：焚 +1。
