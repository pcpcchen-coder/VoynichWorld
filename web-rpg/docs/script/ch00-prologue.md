## 1. 本章主題與一句話

**一句話：** 珂潾在自己長大的池子裡嚐到了別人嚐不到的三個味道，順著它們往下走，走到了一隻全站都認得的動物、一段被親長偷偷封掉的脈，和一張早她兩年就站在這裡的人留下的葉帖。

**主題：** 「先嚐，再治」——診斷先於處置，證據先於答案；以及它的反面：**一個人可以因為害怕而把一件事封起來，封的手法甚至是對的，代價卻落在看不見的地方。**

**脈況階段：** 味變（開場）→ 流慢（汲蟲死亡、三把水位尺同高）；橋腹舊接口局部已是封脈＋野化（被人為提前）。

**環境母題：**

| 感官 | 開場（長晨） | 中段（午後→藍昏） | 洞內 |
|---|---|---|---|
| 光 | 橙色低角度晨光穿過青綠孢霧 | 光轉平，霧邊界後撤一個棚寬；藍昏時發光花與燈蛾接手 | 只有汲蟲亮點與發光花；亮點越往裡越稀 |
| 聲 | 鐘管草隨潮互答，偶有一株慢半拍 | 低鳴變成不換氣的單音 | 低鳴、喘鳴、刮壁聲；最後是一段安靜 |
| 味 | 鹹 → 苦 → 焦 | 腥加進來 | 硫（臭蛋味）、澀，以及最後一個甜 |
| 水位 | 初階池七刻，緩漲 | 三把尺同為七刻（不該一樣） | 西池深、東池淺，靠活瓣對調 |

- 升級時體力回滿、感官負荷歸零，畫面顯示手技說明。
- 劇情學會的手技（不看等級）：**清淤**（M0-10，老聆教）、**隔離／切除**（M0-07，取得重要物品「封脈夾」後出現在指令列）。
- 遭遇外，感官負荷每走 5 格自然 −1；在種源龕或床休息時體力與負荷全部回復。
- 體力歸零＝撤離：回到最近一次碰過的種源龕，體力回復一半，未入庫的診斷樣本失去一半（無條件捨去）。

### 4.2 遭遇指令與數值

| 指令 | 效果 | 代價 |
|---|---|---|
| **嚐味·高稀釋** | 揭示味序中「最前面一個尚未揭示」的味符 | 感官負荷 +4 |
| **嚐味·低稀釋**（等級 2 起） | 揭示最前面 2 個尚未揭示的味符（等級 5 起 3 個） | 感官負荷 +10；30% 機率留下**味覺殘留** |
| **處置** | 對「目前排在最前面的味符」用藥：燼灰→鹹、縫苦（微量）→苦、靛乳→焦、池糖液→澀。對症：該味符消除，對象失衡 −10。不對症：誤治（見下） | 消耗 1 份處置藥 |
| **清淤** | 最前面是「腥」時消除它，對象失衡 −10；不是腥則誤治 | 體力 −4 |
| **防護** | 封掌套：本回合受到的體力傷害與感官灌入各減半（無條件捨去）；清除味覺殘留；等級 3 起負荷 −6 | 佔一回合 |
| **回沖**（等級 4 起） | 感官負荷 −15 | 每場 1 次，佔一回合 |
| **隔離／切除**（需封脈夾） | 一般對象 1 回合結束遭遇；中頭目、首領需連續 2 回合（架夾→收口） | 失去該對象的診斷樣本；連通度與四向度變化見各對象 |
| **物品** | 使用消耗品（沖洗液、餅等） | 佔一回合 |
| **撤離** | 離開遭遇，對象回到原位、味序與失衡重置 | 無（首領處撤離會回到下層舊龕） |

**甜的規則：** 甜＝健康糖流，不可處置。甜排到最前面時，只要該回合玩家沒有對它「處置」或「清淤」（也就是嚐味、防護、回沖、用物品都算「收手」），回合結束時甜符自動流走。對甜處置＝誤治，失衡 +20，且穩定後的樣本獎勵少 1 件。

**誤治：** 對象失衡上升（各對象數值見第 9 節，一般 +15），該回合對象的行為傷害 ×1.5。

**味覺殘留：** 下一次嚐味揭示的第一個味符，顯示為「上一次嚐味最後讀到的味」（假讀值）。防護一回合或使用味覺沖洗液可清除。

**感官負荷門檻：** 負荷 ≥ 上限的 70% 時，每次嚐味有 25% 機率其中一個讀值是假的（讀值文字會輕微晃動）；負荷到 100% 時，該回合「嚐味」指令變灰。

**失衡：** 每個對象有失衡值（0–100）。味序清空＝**穩定**（最佳結果）。失衡到 100＝**失穩**（對象自閉、逃散或塌陷，沒有樣本，見識只給三成，連通度 −1）。

**回合順序：** 玩家指令 → 結算 → 對象依行為表擲一次行動 → 特殊規則（長新味符、重排）→ 下一回合。

**可見遭遇：** 所有對象都站在地圖上看得見，走到相鄰格按互動鍵才觸發，先跳出「靠近／先不要」的確認；沒有隨機踩雷。穩定後對象留在原地變成健康外觀，可再互動讀一句描述。

### 6.3 慢拱（首領的健康原型）

| 項目 | 內容 |
|---|---|
| 名 | **慢拱**（孩子們叫牠「慢慢」） |
| id | `npc.slowarch`（遭遇 id：`enc.p0.boss_slowarch`） |
| 物種 | 拱背獸，亞成體；依 `ip-bible/05-fauna.md`，裂獸是斷網後的症候群而非另一物種——牠是「拱背型裂獸·初期」 |
| 健康時 | 肩高只到成人胸口；六肢，左中肢微跛，所以兩個霧季前沒跟上北遷的獸群，留在了霧階。每個長晨沿脈橋橋面走一趟，把長過界的灌叢修平，糞液落在橋縫裡。背園是矮鐘管草、兩叢池糖囊和幾朵發光花；芽芽會把燈蛾放在牠背上。牠偶爾鑽進橋腹吃菌毯。 |
| 三個月前 | 蒲嬤封脈的那個靜潮夜，牠正在橋腹下層。封口長成之後，牠被關在封死管段與滲硫痂口之間，收不到綠脈的飽足與停食訊號。 |
| 現在 | 背園的鐘管草枯了大半，主莖轉成病紅；光合板有裂；肋間看得出消瘦，肢體顯長；代謝熱沿背脊浮成一道暗紅的線。牠還在「修剪」：把前廳裡六叢枯鐘管草一遍遍啃到同一個高度。牠還在刮封死的管段，朝著站的方向。 |
| 殘影 | 背園最裡面還有一叢池糖囊是飽的（味序最後的那個「甜」）；牠聽見霧罩搖動的聲音會停一下；穩定時左中肢還是先落地。 |
| 站上的說法 | 蒲嬤對大家說：「跟著過路的獸群走了。」多數人信了。篙不太信。芽芽每天去橋頭看。 |
