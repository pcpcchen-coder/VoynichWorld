## 2. 本章主題

**一句話**：線擋得住硫，也擋得住園丁——珂潾陪一群牽不動的生命走到線前，然後必須決定這條線該不該有口。

**主題**：隔離的長期代價。
前四章的「封脈」是綠脈自己關的門；這一章的門是人替它關的，而且關得有憑有據。珂潾第一次面對一個她在診斷上挑不出錯的對手。

**標題的三層意思**

1. 拱背獸不騎、不駕、不上韁繩；玩家只能伴隨。
2. 鉚的隔離帶是套在整片地上的韁繩。
3. 漣也不是珂潾牽著走的嚮導；這一章牠會鬆手。

**脈況階段（分區）**

| 區 | 階段 | 說明 |
|---|---|---|
| 廊道西段、中段（帶內） | 健康（偶見味變） | 糖流是甜的，但被切成一段一段 |
| 帶間（東一、東二島） | 健康→悶壞 | 不是脈枯五階段的任何一階；是「沒有園丁」造成的過熟、閉冠、失拍 |
| 帶間（東三島） | 味變→流慢 | 外帶曾被越過一次，硫停在這裡 |
| 外帶以南（硫側） | 封脈→乾化 | 往硫裂環方向，骨白乾區逐日靠近 |

**環境母題**

- **光**：霧是平的，貼著濕原；橙色低光下，一條炭黑直線橫過整片靛藍。背園的青光稀疏、隨呼吸起伏。
- **聲**：六肢踩濕土的波浪拍子、胸腔低聲、背園葉片互相摩擦。走上灰帶時，聲場會空掉一塊——帶上沒有蟲、沒有水、沒有根的摩擦。
- **味**：甜，但分段；灰帶是澀；帶間是悶甜（熟過頭的甜，尾巴發酸）；外帶以南是鹹→苦→焦。

## 4. 本章新系統

### 4.1 伴隨遷徙

獸群是一個**會移動的關卡**。玩家不能下指令給任何一頭獸。可做的只有：

- **走位**：側邊、下風、與中足同速。走到幼體與成體之間、正面擋路或從後方逼近，都會讓該獸「轉園」（把背園轉離玩家）並使**同行值**下降。
- **先行**：比獸群早半日探路，清除直線障礙、補水槽、標示軟泥。
- **路標**：以修園漿與糞液標（照料者收集的腹腺漿）在前方補上氣味標。這不是命令，是把「路還在」這件事重新說一遍；獸群可以不理。
- **停等**：獸群停，玩家就停。催不動。部分事件只在停等時發生。

介面只顯示兩個量：**步調**（獸群今日走了多少、落後季節多少）與**同行值**（單一個體把玩家「算進去」的程度；不是好感度，不會因送禮上升，只因可預期的重複行為上升）。

### 4.2 背園檢修

背園是遭遇系統的延伸：對象是「一頭獸背上的一片園」，味序 3–6 符。

- 只有**已放肩**的個體可以檢修；未放肩者只能遠觀讀色（資訊少一半）。
- 修剪是手技（耗體力），對應「腥」以外的新用法：**剪**可消除一個「苦」而不用縫苦，但只在該獸放肩時可用，且剪錯植株會令園失拍。
- 修園漿（F-183）可延長一次處置的效果；劑量過高會讓背園只長苔、不長花。
- 檢修完留下**種源註記**（一個可脫落的結），不是所有權標記。

### 4.3 園丁路線修復

每修好一項，該段連通度 +1～+3。四種修復項：**足跡水槽鏈**（補水、移入槽緣藻毯；乾槽會困住潾者幼體）、**脊橋橋面**（清除過厚橋面絨，否則獸群不上橋）、**修剪站**（林島冠層開窗）、**氣味路標**（補糞液標；路標菌長出來才算完成）。

### 4.4 連通度地圖

M5-09 起，暫停選單多出一張**連通度圖**（葉帖 F-166 的活頁版）：
各格以色深表示連通度，格與格之間的線段標示「通／慢／斷／人為斷」。
此後全作沿用；其他章的隔離、修復都會回寫到同一張圖上。

#### M5-01〈平的霧〉（全文）

- **地點／時段與潮汐**：縫林環東緣出林坡 → 渡脊坡；長晨；珂月小潮，慢河水位低。
- **出場**：珂潾、漣（在坡下的慢河裡）。
- **目的**：建立脊園環的「健康」與「破碎」同時成立；讓玩家意識到燼不在。
- **環境狀態**：出了縫林，頭頂第一次沒有葉子。風是橫的。霧不往上走，貼在濕原上像一層沒攪開的乳。

```
（畫面：最後一排縫葉在身後。坡下，靛藍的濕原一路平到天邊，幾座低矮林島浮在霧上。）

珂潾：這裡的霧是平的。
珂潾：縫林的霧會爬樹。這裡沒有東西給它爬。

（她蹲下，掌心貼上坡腳的活土。回彈很慢，很深，像按在一頭睡著的大動物身上。）

珂潾：回彈四息。厚。底下有水。
珂潾：取樣。稀釋到三。

（她把滴管移到舌下。）

珂潾：……甜。
珂潾：長尾。
珂潾：我從霧階出來之後，就沒嚐過長尾。

（停頓。她又滴了一次，這次沒有稀釋那麼多。）

珂潾：等一下。
珂潾：甜，斷。甜，斷。每一段都對，段跟段之間是空的。
珂潾：像有人把一句話剪開。每一截都還通順，只是接不上下一截。

漣〔訊號：甜—斷—甜—斷；內光每斷一次暗一格；水壓平，沒有方向〕
（珂潾譯：「水是好的，路是碎的。」或者「好水，壞路」。牠的語序我一直分不清誰在修飾誰。）

珂潾：我嚐到的也是這樣。斷的地方沒有苦，沒有焦。不是脈自己關的。
珂潾：是切口。切得很齊。

（她站起來，往坡下看。很遠的地方，橙色的光底下有一條黑線橫過濕原。直的。濕原上沒有任何別的東西是直的。）

珂潾：那不是河。河不會那麼有把握。

（她習慣性地往下風處偏了一下頭，像在等人報風向。沒有人報。）

珂潾：……
珂潾：沒有人先說「退」。
珂潾：我發現我在等。

（她把滴管沖乾淨，收好。）

珂潾：記一筆。同伴條目，缺失器官一項：風向。
珂潾：暫時由我自己長。

漣〔訊號：短促的薄荷苦—立刻收掉—尾鰭拍水一下〕
（珂潾譯：牠在學我剛才的語氣。苦味放得比我的大三倍。這是嘲笑。這個我很確定。）

珂潾：謝謝。很有幫助。
```

- **玩法**：自由步行下坡；首次嚐味為固定演出（味序：甜—〔空〕—甜，「空」是本章新出現的讀值，代表人為切斷，不可處置）。坡腳可取得第一份活土樣本。
- **F1 條件句**（坡腳獨白追加一句）：
  - F1＝0：「上階那次一階都沒留住。我到現在看見直線還是會先數它燒掉幾階。」
  - F1＝1～3：「上階那次我們留住了〔一／兩／三〕階。那時候我以為線是用來討價還價的。」
- **抉擇與向度**：無。
- **時間**：12 分。

#### M5-02〈渡脊站〉（重點）

- **地點／時段**：渡脊站（浮基池站，拴在慢河渡口）；長晨後段。
- **出場**：珂潾、池守**菖**、站上的種源護送者**藜**（支線 S5-04 委託人，此處先露面）、漣（站下水中）。
- **目的**：交代鉚的召令、燼的去向、帶的存在；補給；F4b 檢查。
- **環境狀態**：水位尺上有兩道刻痕，一道是「封線前」，一道是「現在」，差了一掌。味診台上晾著別人留下的試片，全是乾淨的淡青。

對白重點：

```
菖：記脈院的？妳晚了。焚脈的人九天前過站，就一個，臉上有疤，一句話沒多說，換了濾巾就走。
珂潾：往哪？
菖：往帶上。現在所有人都往帶上，不然就是被帶擋回來。
菖：（指水位尺）看這個。封線以後，慢河矮了一掌。沒有變鹹，就是矮。
珂潾：水沒壞，只是來的路少了。
菖：對。妳們嚐得出來的人說話就是省事。
菖：我不罵鉚。我先說。外帶那邊她擋下來的東西，我去看過，我寧可矮一掌。
菖：但是獸群快到了。牠們不知道有帶。牠們只知道路。
```

- 藜坐在站緣，守著一只封好的大濕匣，不時把手背貼上去量溫度；此時只有一句：「別碰。裡面是一整套，少一樣都不算數。」
- **F4b 檢查**：
  - 未用：味診台自檢通過，菖給「乾淨舌」便條（本章池站交易 −1 籤）。
  - 使用中：自檢時讀值首位延遲半拍。菖：「妳的舌頭慢了。不是累。是有東西在替妳擋。」珂潾：「微量。在治療窗裡。」菖：「我沒問妳窗子多大。我是說，等會兒見了獸，把手洗乾淨。牠們不喜歡那個味道。」（預告 M5-07 與 S5-07。）
- **玩法**：補給、以樣本換池糖籤、調劑台（新配方欄位「修園漿」此時為灰色）。可與漣在站下交接，確認牠披層上的載荷（依 F4：全林＝帶著單一的抗硫繁殖體，量多；局部＝兩種並存；不傳＝五種葉系的繁殖體各一小份，量少而雜）。
- **時間**：10 分。

#### M5-03〈四十一〉（全文）

- **地點／時段與潮汐**：寬廊西段；午後長光；稜月漲潮，足跡水槽滿水。
- **出場**：珂潾、修園手**柢**、獸群（遠景 41 頭，含幼體 6）、漣（沿水槽鏈並行）。
- **目的**：獸群初登場；伴隨的三條規矩。
- **環境狀態**：地面先動，然後才聽見聲音。活土把四十一副身體的重量傳過來，像一陣很慢的心跳。

```
（地平線上，幾座「林島」在移動。）

珂潾：……那幾座島在走。

（靠近之後才看清：六肢，低重心，背上是多孔的拱架，拱架裡是整叢的靛藍植群。走起來是波浪——前一對落地，中一對抬起，後一對還在推。）

珂潾：六肢。波浪步。前中後差三分之一拍。
珂潾：背園隨呼吸起伏。起，兩息。伏，三息。
珂潾：頭貼地。口器在剪，不是拔。剪過的地方留一掌高。

（一頭成體經過一叢過高的植株，口器橫掃，然後腹側滴下一線濃稠的漿液。牠沒有停。）

珂潾：剪。施肥。走。
珂潾：一個動作做完三件事。記脈院的外勤津貼應該發給牠。

（她往前走了幾步，直直朝著最近的一頭。）

柢：站住。

（一個中年人從側面的矮叢後起身，肩上掛著一捲纖維索和一把彎口剪。他沒有看珂潾，看的是獸。）

柢：別從正面。
柢：牠看見正面有東西站著，會停。牠一停，後面的全停。四十一頭停一次，今天就少走三百步。
珂潾：我不知道。
柢：現在知道了。也別從後面。後面是幼的。
珂潾：那從哪？
柢：側邊。下風。跟牠中間那對腳一樣快。牠抬，妳抬。牠落，妳落。

（珂潾繞到側邊。走了十幾步，節奏對上了。那頭獸的背園本來微微偏向另一側，慢慢轉了回來。）

柢：行。牠把園轉回來了。
珂潾：轉回來是什麼意思？
柢：意思是妳不是障礙了。還不是別的。就只是不是障礙。
珂潾：這在我遇過的初次見面裡，算前段。

（柢這才看了她一眼。）

柢：記脈院的。
珂潾：珂潾。
柢：柢。修園的。規矩三條，我只說一次。
柢：不擋。不趕。沒放肩的不摸。
珂潾：「放肩」？
柢：妳看到就知道。沒看到之前，手收在袖子裡。

（水槽鏈裡，漣游過一個剛踩出來的足印。足印已經蓄了水，槽底有細小的東西在動。）

漣〔訊號：清涼微甜—青光長亮—水壓輕輕往前推了三下〕
（珂潾譯：「好水。新的。往前還有。」……牠很少連著給三個肯定。）

柢：（看見水裡的漣，停了一下，把手腕內側露出來，朝水面。）
柢：妳帶著老的來。
珂潾：是牠帶著我。
柢：那更好。
```

- **玩法**：伴隨教學一：側邊、下風、同速。以節拍條顯示中足的抬落，玩家步伐對上三次即過關。失敗無懲罰，獸只是轉園。
- **抉擇與向度**：無。
- **時間**：14 分。

#### M5-04〈隨脊帳〉（全文）

- **地點／時段**：隨脊帳（當日扎在西一島下風處）；藍昏前。
- **出場**：珂潾、帳首**蓑**、柢、學徒**秧**；漣在帳旁的水槽。
- **目的**：背園照料者的生活與倫理；標題第一次出現；埋下連通度結繩。
- **環境狀態**：帳子是幾片可捲的菌絲氈，支在浮基上，一刻鐘就能拆完。帳裡沒有一樣東西比一個人背得動的更重。帳柱上掛著一大串打了結的繩，結有大有小，有幾段被染黑。

```
蓑：坐下風那邊。妳身上有縫林的味道，別讓牠們以為林子追過來了。

（蓑年紀很大，手指關節粗，掌套磨到看得見底下的脈紋。她一邊說話一邊把一團漿揉進纖維布裡。）

蓑：柢說妳走得上拍子。
珂潾：第三次才上。
蓑：第三次算快。秧走了一季才上。

秧：我那時候才十一！

（秧是個少年，膝蓋上全是泥。他蹲在帳口，眼睛沒離開過外頭的獸群。）

秧：記脈院的人都會畫圖對不對？妳能不能幫我畫那頭小的？背上只長了兩撮苔的那頭。牠今天第一次自己剪到東西了。
珂潾：可以畫。牠有名字嗎？
秧：我想叫牠——
蓑：沒有。

（秧閉上嘴。）

蓑：我們不取名。記園，不記名。那頭小的是「雙苔」，等牠長出第三撮，就不叫雙苔了。
珂潾：為什麼不取？
蓑：取了名，妳就會開始替牠想。牠今天累不累、想不想走、是不是該歇一天。
蓑：牠不需要妳替牠想。牠需要妳把牠背上那片修好，然後讓開。
珂潾：那領頭的那一頭呢？我聽見柢叫牠——
蓑：老脊。那不是名字，是位置。走在脊線上的那一頭。上一頭老脊走不動的時候，這一頭就走上去了。
珂潾：位置會空出來，名字不會。
蓑：（看了她一眼）妳說話像在寫字。

（秧忍不住了。）

秧：可是嬤，帶就在前面了。九天。九天就到了。柢叔說牠們看見直線不會轉彎。
秧：我們為什麼不給老脊上一條索？就一條。牽牠繞過去。牠走了，後面的就會跟。
柢：秧。
秧：我是說真的！一條索就——

蓑：過來。

（蓑把手上的漿布放下，拿起帳柱上那串結繩，抓住其中一個大結。）

蓑：這是老脊。妳拉。

（秧拉了。整串繩跟著晃，但其他的結各自掛在各自的位置上，一個都沒移。）

蓑：繩子牽得動一頭。牽不動路。
蓑：路不在老脊腦袋裡。路在四十一副身體裡，在牠們去年留下的糞標裡，在今年等著被剪的那幾座島裡。
蓑：妳牽走老脊，剩下四十頭會站在原地等一頭不在位置上的老脊。然後第二頭走上脊線。然後妳手上有一頭牽著的獸，跟一群不認得牠的獸。
秧：……那怎麼辦？
蓑：不知道。

（她說得很平。）

蓑：我跟了五十個遷季，沒有一季前面有帶。

（安靜。帳外，獸群的胸腔低聲一陣一陣傳過來。）

珂潾：這串結，每一個是什麼？
蓑：池。島。橋。水槽鏈的頭跟尾。大結是牠們每季一定會停的地方。
珂潾：染黑的呢？
蓑：去不了的。
珂潾：（數）……十四個。
蓑：去年是零個。

（珂潾伸手，又停住，把手背朝上。）

珂潾：我可以摸嗎？
蓑：妳問了，所以可以。

（她的指腹沿著繩走。結與結之間的繩段有粗有細。）

珂潾：粗的是走得通的。細的是——
蓑：走得慢的。斷的我就剪掉，留個線頭。
珂潾：妳在記的是連得上連不上。
蓑：不然還有什麼好記？

（珂潾把葉帖束解開，抽出一張空的。）

珂潾：我想把它畫下來。不是替妳們記，是我需要看見它。
珂潾：我一路上嚐到的都是一口一口的。我沒有一次看過整張。
蓑：畫可以。畫完給我摸一遍。妳們的字我不認得，但我認得我的結。妳畫錯我會知道。
珂潾：這是我聽過最好的校對條件。
```

- **玩法**：開放隨脊帳據點：委託板、修園台（調劑台的本章版本，解鎖「修園漿」配方，進度 1／3）、帳內休息（降感官負荷）。
- **抉擇**：對秧的提議可回應——
  - 「我也想過用索。」（秧好感 +；蓑：「想過不丟臉。做了才丟。」）
  - 「我不知道，但我可以先去看那條帶。」（解鎖先行探路的選項提前一場。）
  - 沉默，只畫圖。（錄 +1。）
- **向度**：錄 +1（三項皆有：開始抄錄結繩）。
- **時間**：14 分。

#### M5-05〈走一天〉（重點）

- **地點／時段與潮汐**：寬廊西段 → 西二島；整個白晝（32 小時日的長晨到藍昏）；稜、珂兩月同漲。
- **出場**：珂潾、柢、秧、獸群；漣在水槽鏈。
- **目的**：伴隨遷徙的完整一日循環；園丁路線修復教學。
- **環境狀態**：獸群走過的地方，活土上留下一串蓄了水的深足印，每一個都映著一小塊橙色的天。沒走過的地方，草高到遮住膝蓋，底下是悶的。

**一日循環（玩法）**

1. **晨·先行**：與柢比獸群早出發，沿古道檢查前方三處。
   - 一段水槽鏈乾了四槽（去年獸群因暖湧提前離開，這段沒踩到）→ 補水、移入槽緣藻毯（取得 F-063）。
   - 一塊軟泥：插標示枝。獸群會自己繞軟泥，但幼體不會。
   - 一處舊糞標淡了：補標。柢示範，用的是照料者收集的腹腺漿，摻修園漿。
2. **午·同行**：在獸群側邊走，觀察誰剪什麼。秧教玩家看背園顏色：深靛＝足；偏灰＝渴；葉緣翻白＝該剪沒剪。
3. **昏·停等**：獸群在西二島停下修剪。玩家只能等。等的時候可以畫圖、採自然脫落的樣本、看牠們**互剪**。

對白重點：

```
秧：看那兩頭。左邊那頭把肩放下去了。
珂潾：右邊那頭在剪牠的背。
秧：牠們剪不到自己的。脖子轉不過去。所以一定要有另一頭。
珂潾：……所以一頭單獨的獸，背園不會有人修。
秧：會有我們啊。
柢：我們剪得到葉。剪不到拍子。
珂潾：拍子？
柢：牠們一邊剪一邊哼。聽。

（兩頭獸的胸腔低聲疊在一起，一高一低，慢慢靠攏，最後是同一個音。被剪的那片背園，青光跟著那個音一明一暗。）

柢：園是照那個音在長的。我們哼不出來。
珂潾：同步是從外面給的。
柢：妳要那樣講也行。我們講「對拍」。
```

```
（補糞標時。）

珂潾：這個標，牠們聞到會跟著走？
柢：不會「跟著」。牠們聞到，知道去年這裡有路。走不走是牠們的事。
珂潾：所以我不是在指路。
柢：妳是在幫路說話。路自己會說，只是今年說得小聲。
```

- 西二島林底可取得 **F-064 蓋葉木**（健康態）與 **F-065 剪生芽**（獸剪過的切口上新萌的芽）。
- 完成三處先行修復：寬廊西段連通度 +3；修園漿配方進度 2／3。
- **時間**：12 分。

#### M5-06〈斜坡園〉（重點）

- **地點／時段**：西二島下風處；藍昏。
- **出場**：珂潾、柢、一頭年輕成體（照料者稱「斜坡園」，背園左高右低）。
- **目的**：背園檢修教學（第一場背園遭遇）；升至 35 級。
- **環境狀態**：藍昏，背園的青光接手照明。斜坡園的右側暗了一塊，暗處的葉緣是翻白的。

對白重點：

```
柢：這頭肯放肩。牠從小被我們修到大，妳是誰牠不太在意。先拿牠練。
柢：手背先過去。停。等牠的園不動了，再翻掌。
珂潾：（手背貼近）……園在縮。
柢：等。
珂潾：停了。
柢：翻。

（掌心貼上拱架的邊緣。拱架是溫的，多孔，孔裡有水。）

珂潾：取樣。稀釋到四。
珂潾：先是澀。……苦在後面，很淺。最後是甜。
柢：甜的別碰。
珂潾：我知道。甜是牠自己的。
```

- **遭遇設計**：對象「拱背獸成體·背園失拍（輕）」，味序 **澀—苦—甜**。
  - 澀 → 池糖液。
  - 苦 → 教學提示可用「剪」取代縫苦：剪掉翻白的三株脊籬草（取得 **F-059 脊籬草**）。剪錯（剪到健康的馱露杯）則味序長出一個新的「澀」。
  - 甜 → 不處置。按下任何處置都會觸發柢的制止與獸的轉園。
- 穩定後留下**種源註記**：

```
珂潾：這個結三天會自己鬆。鬆了就掉。
柢：妳們記脈院不都愛釘牌子？
珂潾：釘牌子的那種我不熟。我的老師教的是結。
珂潾：老師說，會掉的標記才不會被誤認成所有權。
```

- **F4b＝使用中**追加：斜坡園在翻掌時多縮一次。柢：「妳手上有苦。牠忍得住，老的那幾頭忍不住。」
- **向度**：播 +1（穩定）；若以「隔離」（用膜罩住該片背園）結束：焚 +1、該獸三日內不放肩。
- **時間**：12 分。

#### M5-07〈牠沒有把妳算進去〉（全文）

- **地點／時段**：西二島與西三島之間的夜停地；長夜前段，墨月升起。
- **出場**：珂潾、蓑、老脊；漣在近旁水槽。
- **目的**：老脊初次近距離；信任的起點是「沒有」。
- **環境狀態**：老脊站在群的最前緣，面朝東。牠的背園比別頭都高、都密，最老的一層已經木質化，上面疊著新的。左肩有一片是暗的。

```
（珂潾從側邊、下風、照著規矩走過去。離老脊六步時，她看見了那片暗處。）

珂潾：左肩坡。一掌半寬。葉緣沒有翻白，是整片垂下來。
珂潾：不是該剪。是萎。

（她又走近兩步。手背朝上，慢慢伸出去。）

（老脊沒有看她。牠的六肢一動也沒動。但整座背園——連同拱架——往右傾了過去。不快。像一扇很重的門自己掩上。）

珂潾：……
珂潾：牠把園轉開了。

（她停住。手還舉著。）

（老脊的胸腔發出一個很低的音。不是對著她。群裡有兩頭回了同樣的音。然後老脊繼續面朝東，站著。）

珂潾：沒有噴氣。沒有退。沒有逼近。
珂潾：就只是轉開。

（她把手收回來。）

蓑：（不知道什麼時候站到了後面）妳的手收得比我想的快。
珂潾：牠拒絕了。
蓑：沒有。
珂潾：牠把背園轉走了。
蓑：牠要是拒絕妳，妳現在會坐在泥裡。牠拒絕過焚脈的人，那人飛出去四步。
蓑：牠沒有拒絕妳。牠沒有把妳算進去。
珂潾：差在哪裡？
蓑：拒絕是有妳。沒算進去是沒有妳。妳對牠來說跟一陣風差不多，風來了，牠把園偏一下，風過了，偏回來。

（老脊的背園果然慢慢正了回來。那片暗處還在。）

珂潾：那片是什麼時候開始垂的？
蓑：上一個靜潮。牠不讓我碰那裡。
珂潾：連妳都不讓？
蓑：我跟了牠二十個遷季。牠讓我碰右邊、後面、脊線上。左肩不讓。
蓑：那邊有個舊疤。很久以前有人在那裡取過東西。

（珂潾轉頭看她。）

珂潾：取過什麼？
蓑：我沒看見。我那時候還在跟上一頭老脊。

（安靜。）

珂潾：怎樣才會被算進去？
蓑：妳想聽好聽的，還是真的？
珂潾：真的。
蓑：同一個時間，同一個位置，做同一件事。做到牠不用再確認妳是什麼。
蓑：沒有捷徑。餵牠沒用，牠自己會吃。摸牠沒用，牠不讓。對牠說話沒用，牠聽不懂，我也不確定牠想聽。
珂潾：要多久？
蓑：柢用了兩季。
珂潾：我沒有兩季。帶在九天以外。
蓑：那就九天。算不進去就是算不進去。牠不欠妳。

（蓑走了。珂潾站在原地，看著那片暗處看了很久。）

漣〔訊號：平淡的微鹹—等長的三次青光—沒有水壓〕
（珂潾譯：「等。等。等。」……或者牠只是在數月亮。三個。今晚三個都在。）

珂潾：我知道。
珂潾：我只是不擅長等一個不欠我的東西。
```

- **F4b＝使用中**的差異演出：老脊除了轉園，還會從腹側噴出一口短氣，群裡的幼體隨之被圍進內圈。蓑：「妳手上有苦味。對牠們，苦就是『有東西在咬園子』。去洗。洗到我聞不到。」→ 開啟支線 S5-07〈手上的苦味〉。在該支線完成前，M5-11 的同行值累積速度減半。
- **玩法**：無遭遇。此場之後 UI 出現老脊專屬的**同行值**（起始 0），旁邊沒有任何數字，只有一排會慢慢亮起的小結。
- **抉擇**：收手之後可選——
  - 留在原地站到墨月過頂（同行值 +1；感官負荷自然下降）。
  - 回帳畫老脊的背園遠觀圖（錄 +1；取得 **F-058 拱心苔墊**的「看」階段）。
- **時間**：12 分。

#### M5-08〈橋面是剪出來的〉（重點）

- **地點／時段與潮汐**：脊橋；長晨；三月錯潮，慢河水位忽高忽低。
- **出場**：珂潾、柢、秧、獸群前緣；漣在橋下。
- **目的**：園丁路線修復第二課；漣的同伴指令仍可用（對照之後的失去）。
- **環境狀態**：脊橋是一整條根—菌絲複合體，從這岸長到那岸。橋面本該是短絨，現在長到腳踝高，踩下去會滑。獸群走到橋頭，停了。

對白重點：

```
柢：橋面絨太厚。去年牠們早走了半個月，沒剪到這裡。
秧：牠們不上橋？
柢：牠們上。但是六隻腳在長絨上會打滑，滑一次，老脊就不走了。牠不走，妳知道的。
珂潾：所以要有人先替牠們把去年沒做的做完。
柢：我們剪橋面。底下的妳們去，橋腹我們下不去。
```

```
（橋下。漣貼著橋腹游了一圈。）

漣〔訊號：腥—腥—短停—青光往橋中段點了兩下—水壓在那一點「凹」下去〕
（珂潾譯：「死的。死的。那裡。水在那裡陷下去。」……中段有東西堵著，後面是空的。）

珂潾：橋腹中段。汲蟲沉在彎道裡。
珂潾：漣，妳能把上游的壓導過來嗎？我清的時候需要有水推。

漣〔訊號：清涼—青光長亮—水壓穩穩地往前〕
（珂潾譯：「可以。」這是牠最乾脆的一種。）
```

- **遭遇**：「脈橋腹汲蟲層·沉屍彎」，味序 **腥—焦—腥—甜**。
  - 漣指令**導壓**：消除一個「焦」而不耗靛乳（之後 M5-26 沒有這個指令，設計上讓玩家在這裡先習慣它）。

- 橋面修剪為節奏小遊戲：照獸群留在舊橋面的剪痕高度（一掌）修剪，剪太短露出導管會扣連通度。取得 **F-067 橋面絨**。

- **時間**：12 分。

### 第二段　信任與地圖（M5-09～M5-14）

#### M5-09〈整張〉（全文）

- **地點／時段**：隨脊帳（扎在脊橋東岸）；靜潮前夜。
- **出場**：珂潾、蓑、柢、秧。
- **目的**：**連通度地圖首次對玩家可見**；取得葉帖 F-166 與證據①。
- **環境狀態**：珂潾把一張對摺犢皮整張攤平在蓑的膝上，四角用四只種莢匣壓著。池水調開的靛藍還沒乾，帳裡有礦物顏料的涼味。

```
（犢皮上，一個不規則的長環。環裡是一格一格的色塊，深淺不一；格與格之間是線，有的粗，有的細，有的只剩一個點。一條很粗的黑線斜斜切過右半邊，黑線旁邊還有一條。）

珂潾：畫好了。照妳的結，加上我這八天嚐到的。
珂潾：顏色深的，是連得好的。淡的，是慢的。白的是我沒去過，不敢填。

（蓑沒有看。她把雙掌放上去，左右各按一半，閉上眼。）

蓑：……這裡。西二島到橋。妳畫粗了。
珂潾：我們修過水槽鏈，我嚐到它通了。
蓑：通了三天。三天不算粗。等牠們回頭那一季還通，才算。
珂潾：（改）中等。
蓑：這裡對。這裡對。……這裡是什麼？

（她的右掌停在兩條黑線之間。）

珂潾：帶間。我還沒進去，是照妳染黑的結畫的位置。三個結，三座島。
蓑：妳把它們畫成跟外面一樣的顏色。
珂潾：因為我不知道裡面現在是什麼顏色。我畫的是妳最後一次看到的。
蓑：那就寫上去。寫「這是去年的」。
珂潾：……我寫。

（她在三座島旁邊加了一行小字。蓑的掌心在那行字上停了一下。）

蓑：我不認得字。但是這一筆妳下得比別的重。
珂潾：因為我不喜歡這一筆。

（秧湊過來。）

秧：所以整個脊園環現在是……幾分？
珂潾：我沒有打分數。
秧：可是妳都上色了，上色不就是——
珂潾：……
珂潾：五十四。

（秧看著她。）

珂潾：如果滿的是一百。如果沒有那兩條黑線，我估計在八十五上下。
珂潾：這是估計。我把估計寫在頁邊，不寫在圖上。
柢：差三十。
珂潾：差三十一。
柢：那條帶值三十一。
珂潾：那條帶擋住的東西，我還沒算。算完之前，這個數字只有一半。

（蓑把手從犢皮上拿開。）

蓑：妳比我以為的公道。
珂潾：我只是還沒看到另一半。看到之後我可能就不公道了。
蓑：到時候再說。

（她指了指黑線左邊，獸群現在的位置，然後指了指黑線右邊、兩線之間的那三座島，然後是更右邊、環的缺口。）

蓑：牠們要從這裡，到這裡，過這兩座島，從這裡出去。五十個遷季都是。
珂潾：穿過帶間。
蓑：牠們不知道那叫帶間。牠們知道那裡有兩座該剪的島。

（珂潾低頭看著圖。看了很久。）

珂潾：我以前一口一口嚐，每一口都是「這裡」。
珂潾：我沒有想過「這裡」跟「那裡」中間的那條線，本身是一樣東西。會粗，會細，會被人剪掉。
珂潾：……我的老師一定早就知道。老師的圖裡，接口永遠畫得比器官大。我以為那是畫風。
```

- **系統**：暫停選單新增「連通度圖」。首次開啟有短教學：格色＝連通度；線＝通／慢／斷／**人為斷**（黑色，本章首見）。往後各章的修復與切除都會回寫此圖。
- 取得 **F-166〈脊園環·連通度圖（線前）〉**、**證據①**。
- **抉擇**：圖上帶間三島的顏色——

- **時間**：12 分。

#### M5-10〈圈〉（重點）

- **地點／時段**：脊橋東岸草原；藍昏，燈蛾出來的時候。
- **出場**：珂潾、秧、幼體「雙苔」、獸群。
- **目的**：第二種遭遇（幼體離圈）；看見獸群怎麼處理自己的危機。
- **環境狀態**：一群背蜜蛾繞著雙苔背上那兩撮苔打轉，雙苔追著光跑，跑出了群。成體的胸腔低聲一頭接一頭響起來，整群開始收攏成一個圈，圈上留了一個口。

```
秧：牠跑出去了！我去——
珂潾：別去。你看圈。
秧：圈怎麼了？
珂潾：有口。牠們留了一個口，對著牠。那不是給我們走的。
```

- **遭遇**：「拱背獸幼體·離圈」，味序 **苦—澀—甜**。苦不是病，是幼體自己的驚慌訊號；用縫苦會把牠鎮在原地、回不了圈（反噬：成體收口）。正解是**不處置苦**，以防護擋在幼體與軟泥之間，等牠自己聞到圈口的氣味。兩回合後苦自行消退，再補池糖液處理澀。
- 教給玩家：本章有些味符的對症處置是「等」。
- 穩定後：雙苔回圈，圈口合上。同行值 +1（老脊在圈合上後，背園朝玩家的方向正了一下——蓑日後會說那只是牠在確認圈外還有沒有東西）。
- **向度**：播 +1。若以縫苦強行鎮靜後抱回：幼體三日不離成體腹下，秧：「牠現在怕妳了。」
- **時間**：10 分。

#### M5-11〈同一個位置〉（重點）

- **地點／時段**：寬廊中段，連續三日；每日長晨。
- **出場**：珂潾、老脊、蓑、柢、秧；漣沿水槽鏈。
- **目的**：以玩法累積「長期行為」；升至 36 級前的鋪墊。
- **環境狀態**：霧每天早上退到同一道草線。老脊每天早上站在同一個位置。第三天，珂潾的靴印和牠左中足的足印之間，隔著的距離跟第一天一模一樣。

**玩法：三日循環**

每日有三件事可做，但只有「在長晨站到老脊左中足的下風側、做同一項工作」會點亮同行值的小結：

| 日 | 固定工作（點亮） | 會扣分的捷徑 |
|---|---|---|
| 一 | 補牠前方的三個水槽 | 把池糖液倒在牠面前（牠繞開，同行值 −1） |
| 二 | 修牠會經過的一段糞標 | 模仿胸腔低聲（群體短暫失拍，蓑會罵人） |
| 三 | 剪牠前方過高的脊籬草，留一掌 | 趁牠低頭時碰左肩（轉園，歸零重來） |

對白重點：

```
（第二日。）
珂潾：牠今天比昨天早停了四十步。
蓑：牠在量前面。老脊每天早上會把前腳壓進土裡，等。
珂潾：等什麼？
蓑：等土回話。水夠不夠，底下通不通。我看了二十季，只看得出牠在等。
珂潾：（看著老脊的前足）壓。停。八息。抬。
珂潾：牠在讀回彈。跟我用手掌讀的是同一件事，只是牠用的是整副體重。
```

```
（第三日，收工時。）
秧：牠今天沒有轉園耶。妳走到三步牠都沒轉。
珂潾：牠今天沒有注意我。
秧：那不是很好嗎？
珂潾：我花了三天，讓一頭獸成功地不注意我。
珂潾：這是我做過最慢的一份田野紀錄。也是最乾淨的。
```

- 這三日同時取得 **F-060 馱露杯**、**F-061 蜜梯花**（獸停等時遠觀＋自然脫落樣本）、**F-131〈三月遷徙曆〉**（蓑口述，珂潾繪：三月疊潮與獸群啟程、停站的對照）。
- **F4b＝使用中且未完成 S5-07**：每日只能點亮半個結；第三日結束時同行值不足，M5-12 延後到 M5-13 之後才發生（演出相同，但地點改在直線前，蓑多一句：「牠等到站在線前面沒事做了，才有空理妳。」）。

#### M5-12〈放肩〉（全文）

- **地點／時段與潮汐**：寬廊中段；第四日長晨；靜潮，水槽面像一塊一塊磨平的石。
- **出場**：珂潾、老脊、蓑、秧（遠處）；漣在最近的水槽裡，一動不動。
- **目的**：信任確立；取得老脊背園樣本；奧芮的回聲（不是編號線索）。
- **環境狀態**：靜潮。沒有水聲。四十一頭獸的呼吸是整片濕原上唯一在動的東西。

```
（珂潾站在老位置。左中足，下風，三步。她在剪一叢脊籬草，留一掌。）

（老脊沒有往前走。）

珂潾：……牠沒走。平常這時候牠已經走了。

（她沒有抬頭，繼續剪。剪完，直起身。）

（老脊的左前肢屈了。一節。兩節。巨大的肩線慢慢沉下來，像一座坡自己矮了。整片左肩背園降到她胸口的高度，停住。）

珂潾：牠停了。
珂潾：左前肢屈兩節。肩線降到我胸口。
珂潾：園沒有轉。
珂潾：……我沒有伸手。牠沒有動。

（遠處，秧倒抽一口氣，被柢一把按住嘴。）

珂潾：我在數。十。二十。
珂潾：三十。牠還在。
珂潾：四十。

（她把剪子放在地上。手背朝上，伸出去。停在拱架邊緣一指之外。）

珂潾：園不動。
珂潾：翻掌。

（掌心貼上去。拱架是溫的。比斜坡園的粗糙得多，孔緣全是一層疊一層的舊癒合。）

珂潾：……好老。
珂潾：這一層是木的。底下還有一層。再底下——我的掌心讀不到底。

（她取樣。很小心。只取那片萎垂葉叢自己滲出來的液，沒有割。）

珂潾：稀釋到五。牠這麼老，我不想冒險。
珂潾：先是澀。
珂潾：然後苦。苦是分層的，會回來。這是病原那一種苦，不是驚慌那一種。
珂潾：然後……焦。很淺。一小段管子塞住了。
珂潾：最後是甜。甜很長。甜是牠的。

（她收回滴管，沖掌，吐掉沖洗液。）

珂潾：澀，苦，焦，甜。四個。我處理前三個。第四個我一下都不會碰。

（——此處進入遭遇，見下。穩定後演出接續——）

（那片垂著的肩坡蕨沒有立刻挺起來。但葉根的顏色從灰轉回了靛。）

珂潾：好了。不會今天就站起來。三天。也許五天。
珂潾：我留一個結。會掉的那種。

（她把種源註記繫上去。繫的時候，指腹碰到了別的東西。）

珂潾：……這裡有疤。

（左肩坡最老的那一層木質上，有一個癒合很久的取樣痕。小，圓，邊緣收得很乾淨。疤旁邊纏著一圈已經被新組織吃進去一半的纖維。）

珂潾：取樣口。刀是斜進的，只取了皮層以下一點點。
珂潾：旁邊這個——這是結。會掉的那種。只是牠長得比結鬆得快，把它包進去了。

（她的手停在那裡。）

珂潾：這個繫法是三繞一回。
珂潾：記脈院教的是兩繞。三繞一回只有一個人這樣繫，那個人說兩繞「掉得太聽話」。

（蓑走近了。她走得很慢，走到老脊看得見她的地方才停。）

蓑：我說過那邊有個舊疤。
珂潾：妳說很久以前有人在這裡取過東西。妳說妳沒看見。
蓑：我沒看見取。我看見人。那時候我跟的是上一頭老脊，這一頭還走在第三位。
蓑：記脈院的。跟我們走了一整個遷季。話少。畫圖的時候會故意畫錯一處。
珂潾：……哪一處？
蓑：把蜜梯花畫到肚子底下去。我說妳畫錯了。那人說：「妳看出來了，所以妳是真的看過。」
珂潾：（很輕）對。就是這樣說話的。

（她的掌心還貼在疤上。）

珂潾：那個人取的是什麼？
蓑：不知道。只知道取完以後，在這頭旁邊坐了三天，什麼都沒畫。
蓑：走的時候往暮口那頭去。沒說去哪。
珂潾：沒說就對了。

（老脊的肩動了。肩線開始往上升。珂潾把手收回來，退了一步。牠站直，背園正了，然後——像前三天一樣——往東走。沒有回頭看她。）

珂潾：牠走了。
蓑：牠該走了。靜潮要過了。
珂潾：牠讓我碰了連妳都不讓碰的地方。
蓑：別想太多。牠不是喜歡妳。
蓑：牠是把妳算進「會修剪的東西」裡了。妳這四天身上全是修園漿的味道，站的位置跟另一頭獸會站的一樣。
蓑：這比喜歡久。喜歡會變。算進去的東西，牠不會再重算。
珂潾：……我可以接受被歸類成一種修剪工具。
珂潾：我被歸過更差的類。

（她蹲下，撿起剪子。老脊剛才屈肢的地方，地上落著一小塊自己脫落的東西：拱架最底層剝下來的一片，指甲大，乳白，沒有形狀。）

珂潾：這不是葉。不是根。不是苔。
珂潾：它還沒有決定要當什麼。

（她把它放進濕囊，沒有放進乾的種莢匣。停了一下，從葉帖束裡抽出那張縫林的殘葉。頁邊那行字。）

珂潾：「不是種子，是能力。」
珂潾：……我不寫。這是假說。我先記我看到的：老獸，最老的一層，有一塊沒有定形的東西。有人來取過。
珂潾：就這樣。剩下的不是我現在能寫的。

漣〔訊號：一種我沒嚐過的味——像很淡的池糖，但沒有尾巴；青光極暗地亮了一下；水壓向牠自己收〕
（珂潾譯：……我不知道。詞典裡沒有這一條。牠朝著濕囊的方向。「那個」？「我的」？「老的」？我只確定牠認得它。）
```

- **遭遇**：「老脊·左肩坡」，味序 **澀—苦—焦—甜**。
  - 澀 → 池糖液。苦 → 微量縫苦（此處不可用「剪」：病原性的苦，剪了會擴散）。焦 → 靛乳，或漣**導壓**（靜潮時效果減半，需兩回合）。甜 → 不處置。
  - 特殊規則：老脊不會反擊。任何一次錯置，牠只會起身離開，遭遇以「未完成」結束，隔日可再試（同行值不扣，但當日步調損失）。
- 取得 **F-062 肩坡蕨**、**F-058 拱心苔墊**完成；取得關鍵物**未定形芽墊**（濕囊；M5-23 會用到）。升至 36 級。
- **此段的定位**：奧芮回聲，不計入線索鏈編號，不新增指向；與線索④的關係只以珂潾的假說呈現。
- **向度**：播 +2、錄 +1。
- **時間**：15 分。

#### M5-13〈直線〉（全文）

- **地點／時段**：寬廊中段·內帶西緣；第九日，午後長光。
- **出場**：珂潾、蓑、柢、秧、獸群；遠處帶上有人影。
- **目的**：獸群撞見隔離帶；獸群拒絕改道。
- **環境狀態**：草在某一步突然沒有了。前面是一條炭黑的地，寬得要走上四百步，上面什麼都不長。黑地的邊緣拉著一道隔離索，索外是一條灰白的淺槽。風從帶上吹過來的時候，沒有帶任何聲音。

```
（老脊在離索十五步的地方停下。牠的前足壓進土裡。等。）

珂潾：壓。停。八息。……十二息。十六。
珂潾：牠沒有抬。
蓑：土沒有回話。帶底下的管子是燒封的。

（老脊終於把腳抬起來。牠沒有轉向。牠就站在那裡，面朝東，面朝黑地對面看得見的那座林島。）

（後面的獸一頭一頭跟上來，在牠兩側排開。四十一頭，一字排在黑線前面。沒有一頭往左或往右多走一步。）

秧：牠們……在等帶自己打開嗎？
柢：牠們在等路。
秧：路沒了啊。
柢：牠們不知道「沒了」。牠們只知道「還沒到」。

（一頭年輕成體往前走了三步，口器碰到隔離索，退回來。又走上去。又退回來。）

珂潾：那頭在試。
蓑：會有幾頭試。試完了回去站著。妳看牠們的背。

（背園的青光本來是各自起伏的。現在一片一片地，慢慢對成同一個拍子。四十一座園，同起，同伏，全部朝著東。）

珂潾：……同步了。
珂潾：牠們把整群對成一個音，朝著那座島。
蓑：那是在叫路。老獸遇到漲水過不去的河，也這樣叫。水退了，路就回話。
珂潾：這次不會退。
蓑：對。

（很久沒有人說話。）

珂潾：牠們會站多久？
蓑：不知道。沒有一季站超過五天。水最久五天就退。
珂潾：五天以後呢？
蓑：五天以後牠們背上的園子開始吃自己。這裡的草三天就會被剪完，剪完就沒有東西可以剪。沒得剪，就沒得對拍。
蓑：然後就是妳們記脈院有字、我們沒有字的那個狀態。

（珂潾沒有把那個詞說出來。）

珂潾：我去看那條帶。
蓑：去。帶上的人不咬人。帶才咬。
```

- **玩法**：場末解鎖區域 7。此後「步調」表凍結，改顯示**停滯日數**（影響 F5 各線的獸群狀態：第 5 日起每日有一頭背園進入失拍）。
- **時間**：14 分。

#### M5-14〈一次都沒有〉（全文）

- **地點／時段**：內帶西緣·帶所（架在焦土上的浮基台）；同日藍昏前。
- **出場**：珂潾、**鉚**、測線員**鋌**；獸群在索外。
- **目的**：鉚初登場。她必須一開口就讓玩家明白：這不是一個可以被罵醒的人。
- **環境狀態**：帶所沒有牆，只有一張長桌，桌上壓著成排的試片，按樁號排好，每一片底下寫著日期。試片全是淡青的。只有最右邊一排，由淡青而黃而褐。

```
（一個寬肩的女人站在隔離索內側，手裡拉著一條打了等距結的繩，一端踩在腳下，一端朝著獸群。她在量。左手戴著一只無孔的膜手套，戴得很緊。）

鉚：四十一頭。離索十二步。
鉚：（對身後）鋌，記。昨天探子報十五。
鋌：記了。

（她收繩，這才轉過來。五十上下，炭黑層衣，肩上一道鏽橙的截斷線紋。她看珂潾的方式跟看那條繩一樣。）

鉚：記脈院的。跟在召令後面來的那一個。
珂潾：珂潾。
鉚：我知道。燼的報告裡有妳，三次。

【F3＝疏通】
鉚：鐘潮那條主導管，妳通的。通得漂亮。三個月後，我的人在下游量到它帶下來的東西。不多。但不是零。
【F3＝切除】
鉚：鐘潮那條主導管，燼切的，妳在場，妳沒攔到底。那份切面報告我引用過兩次。乾淨。
【F3＝改道】
鉚：鐘潮那條主導管，潾者改的道。現在沒有人知道那邊的水往哪裡走。我的線圖上，那裡是一個問號。我不喜歡問號。

珂潾：妳讀得很細。
鉚：我讀所有經過我的線的人。
鉚：妳要問我能不能開。不能。
鉚：妳要問為什麼。來，我帶妳看。看比我說快。
珂潾：我還沒問。
鉚：妳會問。嚐得出味道的人都會問。嚐不出來的只會罵，罵的我比較好應付。

（她往長桌走。珂潾跟上去。鋌讓開，手上還抱著線冊。）

鉚：左邊這些，內帶。每樁每三天換一片。從畫線到今天，沒有一片變色。
鉚：右邊，外帶。南二樁。妳自己看。

（最右一排：淡青，淡青，淺黃，黃，褐，褐，然後又是黃，淺黃，停在淺黃。）

珂潾：……變過。然後退回來一點。
鉚：外帶被過了一次。四十天前。硫從南二樁底下一條我們沒找到的舊管子鑽進來，進了帶間，到東三島。
鉚：然後停在內帶前面。
鉚：外帶，一次。內帶，零次。
鉚：我要是只畫一道，妳今天早上嚐的那口甜，是鹹的。

（珂潾看著那排試片。她的手往滴管移了一下，又停住。）

珂潾：我可以自己嚐嗎？
鉚：可以。全部。帶所沒有不給看的讀值。鋌會帶妳去任何一樁。
珂潾：妳不怕我嚐出跟妳不一樣的東西？
鉚：妳嚐出不一樣的，我就多一筆讀值。我不會嫌讀值多。
鉚：我只是先告訴妳：我畫過十一道線。被罵太寬的有九道。被越過的，沒有。
鉚：一次都沒有。

（她說這句話的時候沒有得意。比較像在報一個她自己也不太舒服的數字。）

珂潾：外面那四十一頭，會站在那裡，站到背上的園子壞掉。
鉚：我知道。
珂潾：妳量牠們離索幾步，量得比照料牠們的人還勤。
鉚：因為牠們每靠近一步，我就要重算一次。四十一頭，一頭少說兩千斤。牠們要是一起往前走，那條索擋不住。
鉚：到那時候我只有一個做法。我不想用那個做法。所以我量。
珂潾：……什麼做法？
鉚：在牠們和帶之間，再燒一道。

（外頭，獸群的背園還在一起一伏，朝著東。）

珂潾：牠們只是要去剪兩座島。
鉚：牠們會踩出一串蓄水的腳印，從帶外連到帶間，從帶間連到帶內。四十一頭，一頭六隻腳。
鉚：妳是記脈院的，妳告訴我，那叫什麼。

（珂潾沒有馬上回答。）

珂潾：……水槽鏈。
珂潾：那是一條路。水的路。
鉚：也是硫的路。
鉚：明天長晨，鋌帶妳走外帶。看完了，妳還想問我能不能開，我聽。

（她把左手的膜手套又往上拉緊了一點，轉身回去看那條結距繩。）

鉚：還有。妳帶著一隻潾者。
珂潾：是。
鉚：別讓牠進帶間的水。不是命令。是牠身上背的東西比妳我都值錢，那裡的水我不敢替牠保證。
```

- **玩法**：帶所成為可訪據點（試片桌可自由查閱＝之後證據④的一半）。與鋌對話可預約外帶巡視。
- **抉擇**（鉚說完「一次都沒有」之後的回應）：
  - 「那第十二道呢？」（鉚：「第十二道就是這一道。妳現在站在上面。」）
  - 「沒被越過，也可能是畫得太寬，根本沒被考驗。」（鉚：「對。我分不出來。所以我不敢畫窄。」→ 之後 M5-16 鉚多說一段；鉚態度 +1：她欣賞有人把這句話當面說出來。）
  - 沉默，只記試片。（錄 +1。）
- **時間**：16 分。

#### M5-15〈守〉（全文）

- **地點／時段**：內帶西段哨（西二樁）；長夜前段。

```
珂潾：一個人。
燼：一個。硯跟炟留在鐘潮。那邊的切面要有人看。
燼：這裡的人是鉚撥的。兩個。會量，不會問。

（燼沒有站起來，繼續量。）

珂潾：槽深多少？
燼：一掌半。寬帶的規矩。我會挖一掌。
珂潾：帶寬呢？
燼：四百步。我會畫一百二。
珂潾：你覺得她畫太寬。
燼：覺得。
珂潾：你還是在守。
燼：守。命令是守。
燼：線是她的。她的線沒破過。我的破過。
```

**抉擇（影響本章代理互信）**

- 「你走的時候一句話都沒留。」→ 燼：「留了。留給硯。硯沒跟來。」（停）「算我沒留。」（互信 +0）
- 「你在這裡，我比較知道風往哪吹。」→ 燼看了她一眼：「東南。二級。帶上沒遮，會變。」（互信 +1）
- 不談離隊，直接把這九天的獸群紀錄遞過去。→ 燼接了，翻到背園失拍那頁，看了很久：「這個她沒有。她只有步數。」（互信 +1）

```
（共通收尾。）

珂潾：那四十一頭，五天以後會開始壞。
燼：看見了。
珂潾：我想再等一下。等我把帶間看完，等我——
（燼的手停了。管段夾懸在槽上，沒有落下去。很久。）
珂潾：……燼？
燼：量。
燼：妳去量。量完給我。別說等。
```

- 設計註：燼對「再等一下」的反應在此只呈現為安靜，不解釋；第 8 章處理。
- **時間**：12 分。

#### M5-16〈外帶〉（全文）

- **地點／時段**：外帶·南一樁至南三樁；長晨，乾霧。
- **出場**：珂潾、鉚、鋌。
- **目的**：數據站在鉚那邊。玩家要親口嚐到。取得證據④的另一半。
- **環境狀態**：外帶以南，靛藍在兩百步外開始褪成骨白。霧是乾的，不沾衣服。風一轉向，鼻腔裡先到的是臭蛋味，然後才是別的。

```
鉚：封掌。濾巾拉上。妳要嚐，嚐我叫鋌取回來的，不要自己伸手到帶外。
珂潾：稀釋到六。

（帶外樣本。）
珂潾：鹹。……苦。焦。後面還有腥。四個全到，沒有甜。
鉚：帶間，東三島水緣。
珂潾：鹹。只有鹹。很淺。後面是……悶的甜。
鉚：內帶以內，西二樁。
珂潾：甜。長尾。
（她沖了兩次掌。）
珂潾：我嚐到的跟妳的試片一樣。
鉚：我知道會一樣。我從來沒懷疑過妳的舌頭。
鉚：我懷疑的是妳嚐完以後想做的事。

（鉚走到南二樁。樁腳的焦土上有一道癒合得很難看的溝。）

鉚：就是這裡。一條舊管子，圖上沒有，探桿沒探到。硫從底下過來，四天走到東三島。
鉚：我們花了九天才把它找出來燒封。九天裡，它一步都沒過內帶。
鉚：不是因為我厲害。是因為兩道線中間有四百步什麼都不通的地。

（珂潾蹲下，掌心貼著那道溝的邊緣。沒有回彈。）

珂潾：這裡的土不會回話了。
鉚：不會了。我燒的。
珂潾：妳說這句話的時候沒有停。
鉚：停了它也不會長回來。

（珂潾站起來，朝北，朝帶間那三座島。）

珂潾：東一島，東二島。我還沒進去。但我的掌心在帶所就讀得到：那裡是悶的。
鉚：鋌。清冊。

（鋌翻開線冊後半。字很密，每九天一欄。）

鉚：東一島。封線那天冠層透光四成。現在一成半。林底的東西在黃。
鉚：東二島。封線時困在裡面三頭獸，一個不肯走的照料者。三頭的背園都失拍，其中一頭開始掉板。
鉚：東三島。鹹。
鉚：每九天我自己走一遍。妳以為我不知道？

（安靜。乾霧從兩人中間過去。）

珂潾：妳知道，然後妳還是不開。
鉚：孤島會壞。壞得慢。硫過了線，壞得快。
鉚：慢的我可以記，可以等，可以等到有人想出我想不出的辦法。快的我只能燒。
鉚：我選慢的。
珂潾：慢到什麼時候，算壞完了？
鉚：不知道。
鉚：這是我整本冊子裡唯一不知道的數字。

【若 M5-14 選了「可能是畫得太寬，沒被考驗」】
鉚：妳昨天說，沒被越過也可能只是太寬。我想了一夜。
鉚：南二樁就是考驗。它過了一道，沒過第二道。我要是聽人勸畫窄，就沒有第二道。
鉚：所以我還是分不出來：是我對，還是我只是寬。但我知道窄的那個我，現在在燒內環。

珂潾：我會把妳的讀值全抄下來。包括南二樁。
鉚：包括對妳不利的？
珂潾：那幾筆最重要。少了它們，我寫的東西只是在替我自己說話。
鉚：（頭一次停頓）……鋌。把四十天前那九天的原始片給她看。不要抄本。
```

- **玩法**：三樁試片比對（把試片色階排回日期順序的小謎題）；取得**證據④的前半**（完整與否要到 M5-19 決定）。可在南三樁外取得 **F-068 灰上紅**的「看」（帶緣的燼冠苗；完成於 S5-06 或 M5-21）。
- **向度**：錄 +1；若抄錄時略去南二樁的越線紀錄（選項存在）：錄 −1，證據④永久不成立。
- **時間**：15 分。

#### M5-17〈悶〉（重點）

- **地點／時段**：帶間·東一島（經內帶檢疫口：沖洗、換掌套；人可過，獸與水不可）；午後。
- **出場**：珂潾、鋌。
- **目的**：隔離的長期代價，第一次用身體感覺到。取得證據②。

#### M5-18〈左禿〉（重點；中頭目 1）

- **地點／時段**：帶間·東二島；藍昏。
- **出場**：珂潾、鋌、老照料者**苫**、三頭被困的拱背獸（照料者記為「左禿」「高拱」「三疊」）。
- **目的**：孤島上的背園沒有獸群修剪會怎樣；中頭目；取得證據③；升至 37 級。
- **環境狀態**：三頭獸在島緣走一個很小的圈，圈已經被踩成一道溝。牠們互剪——但三頭輪不過來，「左禿」的左背整片沒人剪到，過長的植株倒伏、發黑。牠的胸腔低聲高了半個音，另外兩頭對不上。

對白重點：

```
苫：別靠那頭太近。牠四天沒對上拍了。
珂潾：妳在這裡多久？
苫：封線那天我在島上修牠們。人可以走，鉚的人來問過我三次。我說我走了牠們怎麼辦。
苫：三頭不夠。妳知道一頭的背要幾頭來剪嗎？至少四頭輪。三頭，永遠有一塊背是沒人顧的。我一個人顧不來，我哼不出那個音。
珂潾：牠在轉圈。
苫：牠在走遷徙。牠以為牠在走。圈走滿四十一個，牠會停下來等後面的。後面沒有。

（「左禿」停下，回頭，對著空無一物的身後發出低聲。等。沒有回應。牠的背板裂開一道縫，縫裡透出暗紅。）

珂潾：背板在裂。紅的。
珂潾：苫，這已經是——
苫：不要說那個字。牠還認得我。
```

- **中頭目遭遇**：「孤島拱背獸·前裂（左禿）」，味序 **苦—苦—澀—焦—腥—甜**（6 符）。
  - 第一階段：牠未放肩，只能遠觀讀色與嚐地上滴落的漿。苦用縫苦（劑量要比照體型加倍，逼近治療窗上緣——F4b＝使用中者此處有「手邊存量不足」的額外壓力）。
  - 第二階段：兩個苦消除後，牠會**把肩放低一半**——對著苫，不是對著玩家。由苫扶住拱架，玩家才能「剪」與清淤。

  - 結束方式：**穩定**（背板裂縫收合，紅退為暗褐；取得證據③；播 +2）／**隔離**（鋌依規程提出：以膜圈把左禿與另兩頭分開；快，焚 +1，但苫從此不與玩家交談，另兩頭三日內開始失拍）／**撤離**（無證據）。
- 穩定後：

```
苫：牠今晚不會裂了。
珂潾：今晚。
苫：妳們這種人說話都留一截。
珂潾：因為後面那一截我不能保證。三頭還是三頭。我修好的是今天的背，不是「沒有人來」。
苫：我知道。我比妳早知道四十天。
鋌：（一直在記，筆停了）……這個我會寫進清冊。原話。
```

- 苫的支線 S5-09 開啟；本區可得葉帖見第 8 節。
- **時間**：16 分。

#### M5-25〈用腳讀〉（重點）

- **地點／時段**：直線前的獸群停滯地；午後；獸群停滯第四日。
- **出場**：珂潾、老脊、蓑。
- **目的**：不靠漣讀水——從老脊身上學。解鎖指令**槽讀**。
- **環境狀態**：老脊還是每天早上把前足壓進土裡，等。帶前的土不回話，牠就把腳挪半步，再壓。四天，牠在同一小塊地上壓出了一排十幾個槽，每個槽的水位都不一樣高。

對白重點：

```
珂潾：牠壓的這一排，水位不一樣。靠帶的淺，離帶的深。
蓑：我看了二十季，只看到牠在等。
珂潾：牠不只是等。牠每壓一次，就多一個讀值。牠在畫一張圖，用水畫。
珂潾：水位差就是底下的壓差。牠讀得到水想往哪邊走。
蓑：妳要學牠？

珂潾：牠有牠的理由。我譯不出來的理由。
蓑：譯不出來，妳就不去了？
珂潾：去。只是這次我得自己把水讀完。
蓑：（把一團修園漿塞到她手裡）牠們每一頭都是自己讀的。沒有一頭問過別頭腳底下是什麼。問的是「妳讀到的跟我讀到的對不對得上」。
```

- **玩法**：槽讀小遊戲——在一排足跡槽間量水位（以指節為尺），推出地下壓差方向。完成後取得同伴欄的替代指令**槽讀**（耗時一回合、耗體力，可讀出水下味符中的「方向」而非「內容」）。

#### M5-26〈暗渠〉（重點；中頭目 2，環境型）

- **地點／時段與潮汐**：暗渠內；藍昏，稜月急漲。
- **出場**：珂潾（獨行）。
- **目的**：不靠漣做完一段。取得證據⑤；升至 39 級。
- **環境狀態**：水到腰。頂上是燒封過的焦硬土層，偶爾掉下一小塊。沒有光，她把一片發光菌落貼在領口。水壓貼著小腿，一陣朝東，一陣朝西。

```
珂潾：水到腰。溫的。頂距頭兩掌。
珂潾：表層，甜，悶。……底下那個「？」，平常是漣替我填的。
珂潾：用腳。站定。等。
珂潾：左小腿先涼。左是東。水從東邊來。
珂潾：等一下——又換了。西邊來。……是潮。稜月在拉。
珂潾：我要讀的不是這一下往哪走。是拉來拉去之後，淨的往哪走。
```

- **中頭目遭遇**：「暗渠回湧」，味序 **？—鹹—？—焦—腥**（7 符中有 2 個水下符以「？」顯示；全長隨回合增減）。
  - 機制一：每回合開始，潮向切換。向東的回合，首位味符退到隊尾；向西的回合，從東三島方向湧來一個新的「鹹」。
  - 機制二：**槽讀**可把一個「？」讀成方向（東／西）而非內容——玩家要靠方向推理：自東來的未知符必為鹹，自西來的必為甜（不可處置）。猜錯而對甜下藥＝反噬（頂層掉土，體力大損）。
  - 機制三：無漣導壓，焦只能用靛乳；靛乳在密閉渠內會讓感官負荷上升加倍。
  - 穩定條件：在三次完整潮向循環內清空味序，並在渠中段插下三支水位籤記錄淨流向。
- **結果（固定事實，不隨表現改變）**：帶間西緣的深水，**靜潮時不動；漲潮時淨向東；只有稜、墨兩月同退的那一刻，會向西回吸一小段，約一百息。**

```
珂潾：淨向東。……一天裡有一百息向西。
珂潾：鉚說「算成有」。有。一天一百息。
珂潾：燼說「沒有讀值說它往西」。現在有了。也是一百息。
珂潾：兩個人都對了一部分。我最不喜歡這種結果。
珂潾：但這是可以寫進案裡的東西。靜潮開，靜潮關——靜潮的時候它不動。
珂潾：……漣，妳一進來就會知道。妳是不是早就知道？
（水沒有回答。）
```

- 以穩定結束：取得**證據⑤**、**F-071 暗渠白絲**、**F-132〈雙退回吸刻〉**（天文葉帖：稜、墨同退的時刻表）。以撤離結束：只知道「大致向東」，無證據，潛越線的安全判定少一項。

## 6. 支線任務（10 條，合計 180 分）

#### S5-01〈水槽不能斷〉｜池守 菖｜18 分
- **起因**：渡脊站下游一段足跡水槽鏈乾了，菖在站上數到的潾者幼體一天比一天少。
- **步驟**：沿鏈檢查九槽 → 遭遇「足跡水槽·乾槽」三次（其中一槽困著幼潾）→ 補水、移藻毯 → 請漣把幼潾帶到下一個活槽（M5-24 後接此支線，則須自己用濕囊一隻一隻捧過去，耗時加倍）。
- **對白重點**：菖：「牠們踩一腳，就是一個池。我守一輩子站，守的其實是牠們的腳印。」
- **抉擇**：乾得最深的一槽——挖通（快，但挖破底下的儲水共生體，連通度 +1／−1 相抵）／一勺一勺補到它自己回彈（多 6 分鐘，連通度 +2、播 +1）。
- **獎勵**：池糖籤 ×6、味覺沖洗液 ×2；見識中量。

#### S5-02〈秧想取名〉｜學徒 秧｜15 分
- **起因**：秧偷偷在一片葉上替六頭幼體各寫了一個名字，被柢看見。
- **步驟**：陪秧跟幼體群走半日 → 幼體之一陷軟泥，秧喊了牠的「名字」，牠沒有反應；成體的低聲一響，牠就自己出來了 → 與秧談。
- **抉擇（全文）**：

```
秧：牠不認得那個名字。
珂潾：牠認得的是音高，和誰的園是什麼味道。
秧：那我取的算什麼？
```
  - 「算你的。你需要它，牠不需要。兩件事不衝突。」→ 秧留下那片葉，夾進珂潾的葉帖束當襯紙。錄 +1。
  - 「把名字換成園的樣子來記，你會看得更準。」→ 秧學會讀背園顏色，之後 M5-29 多一名幫手（群體味序首位自動提示）。播 +1。
- **獎勵**：修園漿 ×2；秧的襯紙或幫手效果。

#### S5-03〈染黑的結〉｜帳首 蓑｜22 分
- **起因**：連通度圖上還有四格是白的。蓑：「白的比錯的好。但是妳都走到這裡了。」
- **步驟**：探索型。走訪西三島背風面、慢河下游彎、內帶北端、環脊腳泥灘（M5-27 後泥灘亦自由開放），各做一次嚐味與槽讀，把白格填色。泥灘可取得 F-070。
- **對白重點**：每填一格，蓑以掌校對。填到內帶北端：「妳畫的線頭比我的結多一個。」珂潾：「帶在這裡沒有接到環脊。差六十步。鉚大概還沒補。」蓑：「那六十步，獸過得去嗎？」珂潾：「過得去。水也過得去。」（＝繞路線成立的依據，也是鉚的一個真洞；玩家可選擇是否告訴鋌。）
- **抉擇**：告訴鋌（焚 +1；鉚態度 +1；之後 A 線泥灘入口多一道檢疫，行程多一日）／不說（播 +1）。
- **獎勵**：F-166 補完版（線後圖更精確）；見識大量。

#### S5-04〈少一樣都不算數〉｜種源護送者 藜｜20 分
- **起因**：藜護送一整套共生配方（光合株、管器官幼體、發光菌落、固氮囊）往燈沼方向的種源站，被帶擋在渡脊站十九天。濕匣裡的菌落開始暗了。
- **步驟**：診斷濕匣（味序 **澀—苦—澀—甜**，對象是「一套配方」）→ 穩定後只能再撐六天 → 決定去處。
- **抉擇與向度**：
  - 就地種在西三島（播 +2；配方活，但不在它該去的站。C 過線時此島被燒，藜的對白改變）。
  - 經鋌走人員檢疫口，由藜徒步背過帶間（慢；需完成 M5-17；錄 +1、播 +1；發光菌落損失三成）。
  - 拆開，只留能乾存的兩樣交給珂潾帶走（錄 +2；藜：「那就不是一套了。妳帶走的是零件。」——第 7 章失活主題的伏筆）。
- **獎勵**：池糖籤 ×8；藜的護送結（往後各章種源護送委託報酬 +1）。

#### S5-05〈灰的鹹〉｜測線員 鋌｜18 分（須 M5-21 選覆算灰量）
- **起因**：帶邊的活土起了一層脆殼。不是硫，是灰下太多。
- **步驟**：遭遇「帶邊活土·鹽殼」兩處 → 與鋌重算窄口與現行帶的最小灰量 → 決定怎麼報。
- **對白重點**：鋌：「我要是把這個數字寫上去，等於說她的帶寬了兩成。」珂潾：「妳不是說她錯。妳是多給她一筆讀值。她說過她不嫌多。」
- **抉擇**：鋌具名上報（鋌取得聯署資格；鉚：「具名的我會讀。」焚 +1、錄 +1）／只在自己的班上私下減量（帶邊殼化停止，但無紀錄；播 +1）／不改。
- **獎勵**：燼灰 ×4；灰衡小秤（調劑時劑量誤差 −1 級）。

#### S5-06〈灰上新紅〉｜巡線兵 釦｜15 分（須 M5-21 選陪釦守槽）
- **起因**：釦在焦土上發現一排泛紅的小苗。帶本身長出了燼冠。
- **步驟**：遭遇「帶緣燼冠苗」（味序 **鹹—焦—苦**）→ 取樣 → 決定處置。完成 F-068。
- **抉擇（全文）**：

```
釦：照規程，帶上長東西要報。報了就是整段重燒一遍。
釦：可是重燒完，明年長得更多。我看過。
```
  - 報（焚 +1；帶重燒，停滯日數 +1）。
  - 手拔、燒成灰，交給鋌當中和劑（播 +1；釦：「所以它是藥。」珂潾：「它是病人。病人燒完剩下的東西剛好有用。這兩句不要連著講。」）。
  - 留一株標記觀察（錄 +1；第 8 章燼冠條目多一筆早期紀錄）。
- **獎勵**：燼灰 ×3；釦之後在 C 線乙版的偵查中「剛好」晚轉身十息。

#### S5-07〈手上的苦味〉｜修園手 柢｜18 分
- **F4b＝使用中**：老脊對珂潾噴氣之後開啟。柢帶她到水槽邊洗手，洗三次都還有。

```
柢：洗不掉。不是在手上。是從妳皮底下出來的。
珂潾：微量。在治療窗裡。它讓我嚐完還站得住。
柢：我沒說妳錯。我說牠聞得到。
```
  - 步驟：連續三場次在每次嚐味前不補縫苦（感官負荷上限暫時 −15%，讀值出現一個假音符）→ 第三場末再見老脊。
  - 抉擇：**戒**（F4b→已戒；上限恢復原值、失去縫苦加成；播 +1）／**減量續用**（F4b 維持使用中；學會以修園漿遮味，同行值不再減半；錄 +1）。
- **F4b＝未用**：改為柢的版本——他年輕時被踩傷的膝蓋，二十年來靠微量縫苦走路；請珂潾替他重新算劑量。抉擇：照舊劑量／減半並教他用池糖液熱敷（播 +1）。
- **獎勵**：柢的彎口剪（「剪」的體力消耗 −1）。

#### S5-08〈追紅的蛾〉｜學徒 秧｜16 分
- **起因**：獸群停在線前後，背蜜蛾一到藍昏就往帶上飛——焦土邊緣的燼冠苗在發紅光。背園的蜜梯花沒有蛾來。
- **步驟**：以兩片濾色葉遮住紅光、在背園一側補出青光節律 → 遭遇「背蜜蛾群·追紅」（味序 **苦—甜—苦**，苦以「遮光」處置而非下藥）→ 蛾群回到背園。
- **對白重點**：珂潾：「牠們不是笨。牠們只是相信最亮的那一個。」秧：「那邊黑黑的地方，蛾也是這樣嗎？」珂潾：「我還沒去過。聽說那邊的光會講整句的話。」
- **獎勵**：濾色葉 ×2（第 6 章光語系統的預備道具）；F-061 補完；連通度 +1。

#### S5-09〈苫不走〉｜老照料者 苫｜20 分（須 M5-18）

#### S5-10〈唯一不知道的數字〉｜鋌 → 鉚｜18 分（須 M5-17）
