# 薇蘿：葉帖紀行

**VELLORA — The Loose Folios · HTML 網頁 RPG**

以薇蘿世界（路線 B）為設定的單人 RPG。你扮演能「嚐」懂綠脈化學語言的年輕記脈者**珂潾**，
在脈枯逼近的池環之間採樣、診斷、調劑，一張一張畫下自己的葉帖——那疊葉帖，就是日後的《伏尼契手稿》。

> 本子專案全部內容為**原創虛構**（C 層製作提案，僅限本遊戲的改編），不是對《伏尼契手稿》的翻譯、解讀或學術主張，
> 也不回寫 `ip-bible/` 正典。葉帖與手稿掃描頁的配對是遊戲設計。與 `roblox-game/` 是互相獨立的兩個改編。

## 怎麼玩

純靜態網頁，沒有外部相依，不需要安裝或建置。

- **直接開**：下載或 clone 之後，用瀏覽器雙擊開啟 `web-rpg/index.html`。
- **本機伺服器**：在倉庫根目錄執行 `python3 -m http.server 8000`，開 <http://localhost:8000/web-rpg/>。
- **GitHub Pages**：倉庫開啟 Pages（`main` / root）後，網址是 `/web-rpg/`。

| 操作 | 鍵盤 | 觸控 |
|---|---|---|
| 移動 | 方向鍵／WASD | 虛擬方向鍵 |
| 確認、互動、對話前進 | Z／Enter／空白 | A 鈕，或直接點對話框與選項 |
| 取消、開選單 | X／Esc | B 鈕、右上角 ≡ |

存檔寫在瀏覽器的 `localStorage`（3 個手動欄位＋自動存檔）；在種源龕可以存檔並回復。
畫面左上角會顯示目前目標的地點與方向，可在設定中關閉。

## 核心玩法

- **嚐味診療**：遭遇對象不是敵人，是中毒或野化的生命。牠身上有一串隱藏的「味序」（鹹、苦、焦、澀、腥、甜），
  你要先**嚐**出順序（稀釋度越低讀得越多，但感官負荷越高、讀值越可能失真），再對最前面的味符用**對症**的藥：
  燼灰解鹹、縫苦解苦、靛乳解焦、池糖液解澀，腥要徒手清淤，甜是健康的不能動。用錯會反噬。
- **沒有擊殺**：結束方式是穩定、隔離／切除或撤離。隔離很快，但會失去樣本、降低連通度。體力歸零只是撤回種源龕。
- **葉帖即進度**：觀察、取樣、診斷三項齊備後畫下一張葉帖，頁面是對應的手稿掃描圖，旁邊是珂潾的田野筆記。
- **抉擇有後果**：修復與隔離、說與不說，會累積成四個隱藏向度（播／焚／融／錄），在章末以文字呈現傾向。

```
├── index.html                  # 遊戲入口

│   ├── 00-master-outline.md    # 企劃總綱：系統、章節骨架、線索鏈、抉擇旗標、葉帖頁碼配額
│   ├── ENGINE.md               # 資料格式文件：如何把劇本做成可玩內容

└── tests/                      # Playwright 自動測試
```

## 開發與測試

需要 Node.js 與 Playwright（僅測試用；遊戲本身不需要）。

```bash
node web-rpg/tools/validate-data.js        # 驗證正式資料（加 --demo 驗證測試房）
node web-rpg/tests/smoke.js --official     # 冒煙測試：桌機與手機尺寸
node web-rpg/tests/playthrough.js          # 從新遊戲自動玩到章末
node web-rpg/tests/routes.js               # 分歧路線：隔離、失敗重來、支線、章末抉擇、存讀檔、無本機儲存
node web-rpg/tests/cutscene-visibility.js  # 過場的旁白、全幅圖與對話不會被淡出的黑幕蓋住
node web-rpg/tools/estimate-playtime.js    # 依對白字數、步行格數與遭遇回合估算遊玩時間
```

要把後續章節做成可玩內容：依 [`docs/ENGINE.md`](docs/ENGINE.md) 在 `js/data/` 新增資料檔並列入 `js/data/manifest.js`，
內容以 [`docs/script/`](docs/script/) 對應章節為準。
