## 2026 年 11 月增補

新增〈頁序之謎〉一章，收錄 Layfield & Davis（2026，*Digital Medievalist* 19，doi:10.4000/16k0a）的
頁序錯裝假說：以 LSA 統計方法發現「同一張對摺紙兩半」比「翻開相對頁」更相似，主張手稿原為依序閱讀的
獨立對摺紙、後遭錯誤套疊裝訂。章內說明證據、提出的原始順序、限制與外部評論，並澄清兩個常見誤會：
它**不是大型 AI 模型**的成果，也**沒有翻譯出任何文字**。

同步修正：封面、目錄、流傳史時間軸、可信度表、常見說法核對、閱讀方法與筆記模板、資料庫欄位、
驗收說明、名詞表（Bifolio／Quire／Conjoint／Singulion／LSA）與參考資料。原始 14 頁版本保留在 git 歷史中。
