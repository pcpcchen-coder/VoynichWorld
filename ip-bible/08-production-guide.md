# 08｜敘事、遊戲、動畫與授權製作規格

## 一、IP 主張

### 對外一句話

> 在一顆把所有生命連成同一張共生網的星球上，一位能嚐懂世界的記錄者，必須在焚燒、融合與重播之間決定：為了讓生命延續，我們可以失去多少差異？

### 三個不可替代賣點

1. **伏尼契圖像變成可驗證的生態機制**：怪植物不是亂想，而是嫁接、基因轉移、共生器官和病態同源異位。
2. **嚐味診斷**：氣味、味道、濃度和節奏是語言，也是核心遊戲與敘事感官。
3. **沒有無代價結局**：切除保整體、合一消孤立、重播保差異、記錄送未來，每條路都救了什麼也失去什麼。

## 二、正典 QA

新資產進入正典前，依序回答：

### 世界

- 是否仍環繞 K 型橙矮星歐柯？
- 是否保留 32 小時日長、12° 左右小軸傾與三月潮汐？
- 長冬是否透過生物泵、水循環、硫化與栓塞表現，而不是普通冰河期？

### 生物

- 這個物種接上綠脈的接口在哪？
- 至少兩個譜系如何合作？
- 半自養或化能來源怎麼留下可見痕跡？
- 斷網後會怎麼壞？是否保留健康原型？

### 人物

- 行動是否由角色的價值與感官限制推出？
- 是否讓反對者也說出真實、可辯護的代價？
- 是否避免用天選、魔法、純邪惡反派跳過系統問題？

### 伏尼契邊界

- 是否清楚標示「世界內虛構」而非現實翻譯？
- 是否把實際手稿圖版的觀察與創作推演分開？
- 是否避免宣稱解開 Voynichese？

## 三、遊戲規格

### 核心循環

`探索池環 → 觀察／採集 → 嚐味診斷 → 比較圖鑑 → 嫁接、疏通、隔離或放棄 → 種源入庫 → 世界狀態改變`

### 四層資訊

| 層 | 玩家看見什麼 | 例 |
|---|---|---|
| 無介面環境層 | 霧、光、聲、水位、動物行為 | 鐘管草音高下降 |
| 感官層 | 味覺序列與化學強度 | 鹹 → 苦 → 焦 |
| 圖鑑層 | 器官、共生夥伴、來源頁面 | 縫葉五葉功能 |
| 決策層 | 時間、種源、連通與傷亡代價 | 救一池可能讓硫化跨線 |

### 嚐味診斷

- 不做成單純按鍵掃描。
- 玩家先取樣、稀釋、選擇感受器、辨認順序，再與環境證據交叉驗證。
- 高濃度樣本會造成珂潾感官殘留，短期扭曲後續讀值。
- 漣可補足水下與遠距水路訊號，燼可提供風向、火線與不可逆現場判斷。

### 生態選擇

- **修復**：慢、耗種源，保留連通；可能來不及。
- **切除**：快、降低傳播；破壞長期韌性。
- **移種**：保存差異；離開共生環境可能失活。
- **接入**：立即共享資源與鎮痛；增加個體邊界代價。
- **記錄**：提升未來選項；當下不一定救命。

### 敵對遭遇

- 裂獸不是唯一威脅；毒氣、脆活土、錯潮、死汲蟲栓塞與訊號誤讀同樣重要。
- 非致命選項必須真有成本，不能只是「好人按鈕」。
- 擊殺裂獸不應讓區域自動恢復，屍體甚至會加重硫化。

### 結局一致性

| 結局 | 玩家此前應累積的系統行為 |
|---|---|
| 重播 | 多樣種源、潾者信任、可用原脈線索、分散小網 |
| 焚脈 | 隔離成功率、核心區存活、長期孤島代價 |
| 融脈 | 匯流節點、群體同意／異議紀錄、共享負擔能力 |
| 記錄 | 圖鑑完整度、送出路徑、種源封存與跨世界留白 |

## 四、小說與劇集規格

### 建議敘事格式

- 珂潾第一人稱田野筆記。
- 第三人稱現場章節承載她未能記下的情感與政治。
- 圖鑑條目不只補設定，也要在後文被推翻、修訂或染污。
- 漣的訊息以味—色—壓力翻譯呈現，保留「珂潾可能翻錯」。

### 每章最小組合

1. 一個可感的環境狀態。
2. 一個具體生物或器官。
3. 一段資料與角色信念衝突。
4. 一個不可完全復原的選擇。
5. 一筆會回到手稿頁面的記錄。

### 避免

- 大段百科全書式對話。
- 角色在危機中忽然忘記取樣衛生、毒氣與感官負荷。
- 用奧芮留信把所有謎題一次說完。
- 把地球學者寫成愚蠢，只為凸顯世界設定。

## 五、動畫與影像規格

### 動態母語

- 健康綠脈：呼吸、壓力波、緩慢癒合、不同器官協調。
- 脈枯：拍點失同步、液體停滯、膜塌陷、局部過熱。
- 織脈者：手掌、頸側、吞嚥、沖洗感受器等細節比大動作重要。
- 潾者：水中連續曲線；岸上較慎重，保持濕膜。
- 拱背獸：六肢波浪步態與背園呼吸。
- 燈蛾群：群體閃光有句法。

### 聲音母語

| 對象 | 聲音 |
|---|---|
| 綠脈 | 水壓低鳴、纖維摩擦、遠距脈衝 |
| 鐘管草 | 多管低頻、潮位改變音高 |
| 潾者 | 水下短鳴、皮膚脈衝、黏液細泡 |
| 拱背獸 | 胸腔低聲、背園葉摩擦、濕土腳步 |
| 燈蛾群 | 細翼振與短促玻璃音 |
| 汲蟲 | 微小刮濾、群體水流沙聲 |
| 脈枯 | 聲場逐步變空；失聲比爆音可怕 |

## 六、品牌與授權品

### 適合

- 偽手稿圖鑑、標本卡、池環地圖。
- 鐘管草桌面聲音雕塑。
- 縫葉可組合模型，五葉可換但接口固定。
- 漣半透明材質公仔，內部藻脈分層。
- 拱背獸與背園可拆模型。
- 三勢力工具與色板設定集。

### 不適合

- 把裂獸做成脫離悲劇背景的純酷怪獸品牌。
- 以潾者裸體或幼態性感化吸引注意。
- 把燼冠做成「火焰系寵物」。
- 在宣傳中暗示本作真的破解伏尼契手稿。

## 七、資產命名

`{序號}-{類別}-{英文 slug}-{用途}.{ext}`

例：

- `06-flora-lineup.png`
- `08-lian-naiadin-character-sheet.png`
- `12-story-key-art.png`

物種資料 ID：

- 天體：`celestial.oq`
- 世界系統：`system.chlora`
- 物種：`species.bellpipe`
- 人物：`character.korin`
- 勢力：`faction.vein_archive`
- 物質：`substance.indolk`
